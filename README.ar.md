يوفّر EPUB Browser وضعين بمسؤوليات منفصلة بوضوح:

| | `ssg` | `server` |
| --- | --- | --- |
| النشر | استضافة ثابتة، وPages، وتخزين كائنات، وNginx | خدمة قراءة خاصة ودائمة |
| الحسابات | لا توجد | حسابات محلية |
| التقدّم والتعليقات ورف الكتب | في هذا المتصفح فقط | بيانات الحساب المسجّل دخوله في SQLite |
| تحديث المصادر | تشغيل `ssg` مرة أخرى | إعادة تشغيل الخدمة أو استخدام `--watch` |
| قاعدة بيانات وقت التشغيل | لا توجد | مطلوبة |

استخدم `ssg` عندما تريد نشر ملفات ثابتة عادية. واستخدم `server` عندما تحتاج إلى حسابات، أو بيانات مشتركة بين الأجهزة، أو التحكم في الوصول إلى الكتب، أو المراقبة التلقائية للمصادر.

## القراءة الأصلية بالذكاء الاصطناعي (Server فقط)

تبني ميزة القراءة بالذكاء الاصطناعي طبقة تعليمية مشتركة وقابلة للمراجعة فوق النص الأصلي، بدلاً من وضع ملخص عام منفصل بجوار الكتاب. وتشمل مساراً قبل القراءة، ونظرة عامة اختيارية للفصل، وشروحاً مرتبطة بالاقتباسات، وملاحظات عن وظيفة الفقرات، وتوضيحات للمفردات، وشرحاً مبسطاً في النهاية، وأسئلة لمواصلة التفكير.

تُنشأ النتائج عبر مهام في الخلفية، وتُحفظ في SQLite، ويشاركها القرّاء الذين يملكون حق الوصول إلى الكتاب. وتبقى محادثات المتابعة خاصة بكل حساب. يجب على المسؤول إعداد مزوّد متوافق مع OpenAI ومنح كل عضو الإذن صراحةً. يُرسل نص EPUB المحدد إلى ذلك المزوّد، لذلك لا تفعّل الميزة إلا بموافقة القرّاء. لا تتضمن مخرجات SSG حسابات أو عناصر تحكم للذكاء الاصطناعي أو مهاماً أو إعدادات المزوّد.

## المتطلبات والتثبيت

- Python 3.9 أو أحدث
- ملف `.epub` واحد أو أكثر، أو مجلدات متداخلة تحتوي على EPUB، أو مكتبة بنمط Calibre

```bash
pip install epub-browser

# المساعدة الكاملة لكل وضع
epub-browser --help
epub-browser ssg --help
epub-browser server --help
```

## بدء سريع

### إنشاء موقع ثابت

```bash
epub-browser ssg /path/to/books \
  --output-dir /path/to/dist
```

قدّم `dist/` عبر HTTP، ولا تفتح الصفحات المنشأة مباشرةً باستخدام `file://`. للنشر تحت مسار فرعي، أضف `--base-path /my-repository/`؛ يغيّر هذا الخيار عناوين URL المنشأة لا مجلد الإخراج.

### تشغيل مكتبة Server دائمة

```bash
epub-browser server /path/to/books \
  --server-dir /path/to/epub-browser-state \
  --watch
```

افتح `http://127.0.0.1:8000/`. في الزيارة الأولى أنشئ المسؤول الأول؛ لن تُفحص المكتبة أو تُنشر قبل إكمال هذا الإعداد. يمنع `--no-browser` الخدمة من فتح المتصفح المحلي تلقائياً فقط.

## البيانات والحسابات وحدود الوصول

لكل كتاب `book_id` ثابت. يحفظ `--book-id-storage sidecar` الهوية بجوار ملف EPUB افتراضياً من دون تغيير وحداته الثنائية. أما `--book-id-storage embedded` فيكتبها في بيانات OPF الوصفية ويتطلب مصدراً قابلاً للتعديل.

في وضع Server، يُعد `--server-dir` الموقع الموثوق لقاعدة SQLite وذاكرات التخزين المؤقت ونسخ الترحيل الاحتياطية. كما تُحفظ فيه الحسابات ورفوف الكتب والتقدّم والتعليقات ونتائج الذكاء الاصطناعي والمهام. يدير المسؤولون المستخدمين والأدوار والجلسات وأذونات الكتب؛ ولا يستخدم الأعضاء إلا الكتب المصرح بها وبياناتهم الخاصة. احمِ أذونات هذا المجلد ونسخه الاحتياطية.

## Docker والوكيل العكسي والتوثيق الكامل

في الحاويات، اربط الكتب للقراءة فقط واربط `--server-dir` بوحدة تخزين دائمة. لا تقبل ترويسات الوكيل إلا من وكلاء موثوقين، واستخدم HTTPS في عمليات النشر العامة.

للاطلاع على Docker Compose وجميع خيارات CLI وعمليات الترحيل والشبكة المحلية والوكيل العكسي واستكشاف الأخطاء، راجع [README الكامل بالإنجليزية](README.md) أو [README الكامل بالصينية المبسطة](README.zh-CN.md). سلوك الوضعين واحد في جميع اللغات.
