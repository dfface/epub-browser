# Third-party browser assets

This is the release inventory for generated browser assets under `epub_browser/assets/vendor/`.
Every archive and installed file is pinned by SHA-256 in `third_party/assets.lock.json`;
`python3 tools/sync_vendor_assets.py verify` validates the complete offline inventory.

For Mermaid, component versions were recovered from the `mermaid@11.12.0` source map and
cross-checked against the immutable release lock. For PDF.js, decoder and build-runtime
versions were cross-checked against the immutable `pdfjs-dist@6.2.108` worker, the
PDF.js `v6.2.108` source tag (`0365cbde028bd92e58f2dab1bb70cd30ac7acfd7`), and the
upstream wrapper locks/commits named below. Supplemental Brotli, Emscripten, and
wasm-bindgen license texts are embedded in the strict lock because `pdfjs-dist` omits them;
each text has an explicit immutable upstream URL and a validated SHA-256 digest.
