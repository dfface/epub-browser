EPUB Browser มีสองโหมดที่แยกหน้าที่กันอย่างชัดเจน:

| | `ssg` | `server` |
| --- | --- | --- |
| การนำไปใช้งาน | โฮสติ้งแบบสแตติก, Pages, ที่เก็บออบเจ็กต์, Nginx | บริการอ่านส่วนตัวแบบถาวร |
| บัญชี | ไม่มี | บัญชีภายในระบบ |
| ความคืบหน้า คำอธิบายประกอบ ชั้นหนังสือ | เฉพาะเบราว์เซอร์นี้ | ข้อมูลบัญชีที่เข้าสู่ระบบใน SQLite |
| การอัปเดตต้นฉบับ | เรียกใช้ `ssg` อีกครั้ง | เริ่มบริการใหม่หรือใช้ `--watch` |
| ฐานข้อมูลขณะทำงาน | ไม่มี | จำเป็น |

ใช้ `ssg` เมื่อต้องการเผยแพร่ไฟล์สแตติกทั่วไป ใช้ `server` เมื่อต้องการบัญชี ข้อมูลข้ามอุปกรณ์ การควบคุมสิทธิ์เข้าถึงหนังสือ หรือการติดตามต้นฉบับโดยอัตโนมัติ

## การอ่านด้วย AI แบบเนทีฟ (เฉพาะ Server)

การอ่านด้วย AI สร้างชั้นการเรียนรู้ที่ใช้ร่วมกันและตรวจสอบได้บนข้อความต้นฉบับ แทนการวางบทสรุปทั่วไปแยกจากหนังสือ ประกอบด้วยแนวทางก่อนอ่าน ภาพรวมบทเมื่อเรียกใช้ คำอธิบายที่เชื่อมกับข้อความอ้างอิง หมายเหตุเกี่ยวกับหน้าที่ของย่อหน้า คำอธิบายคำศัพท์ คำอธิบายแบบเข้าใจง่ายในตอนท้าย และคำถามเพื่อคิดต่อ

ผลลัพธ์สร้างจากงานเบื้องหลัง เก็บใน SQLite และแชร์กับผู้อ่านที่มีสิทธิ์เข้าถึงหนังสือ ส่วนบทสนทนาต่อเนื่องเป็นข้อมูลส่วนตัวของแต่ละบัญชี ผู้ดูแลต้องตั้งค่าผู้ให้บริการที่เข้ากันได้กับ OpenAI และอนุญาตสมาชิกเป็นรายคน ข้อความ EPUB ที่เลือกจะถูกส่งไปยังผู้ให้บริการนั้น จึงควรเปิดใช้เมื่อผู้อ่านยินยอมเท่านั้น เอาต์พุต SSG จะไม่มีบัญชี ตัวควบคุม AI งานเบื้องหลัง หรือการตั้งค่าผู้ให้บริการ

## ข้อกำหนดและการติดตั้ง

- Python 3.9 หรือใหม่กว่า
- ไฟล์ `.epub` หนึ่งไฟล์ขึ้นไป โฟลเดอร์ซ้อนที่มี EPUB หรือไลบรารีแบบ Calibre

การติดตั้งจาก PyPI รองรับทั้งโหมด SSG และ Server:

```bash
pip install epub-browser

# วิธีใช้ทั้งหมดของแต่ละโหมด
epub-browser --help
epub-browser ssg --help
epub-browser server --help
```

หากต้องการเรียกใช้ Server แบบถาวรด้วย Docker ให้ใช้อิมเมจที่เผยแพร่แล้ว โดยไม่ต้องติดตั้ง Python บนโฮสต์:

```bash
docker pull dfface/epub-browser:latest
```

## เริ่มต้นอย่างรวดเร็ว

### สร้างเว็บไซต์สแตติก

```bash
epub-browser ssg /path/to/books \
  --output-dir /path/to/dist
```

ให้บริการ `dist/` ผ่าน HTTP และอย่าเปิดหน้าที่สร้างขึ้นโดยตรงด้วย `file://` หากนำไปใช้ภายใต้เส้นทางย่อย ให้เพิ่ม `--base-path /my-repository/` ตัวเลือกนี้เปลี่ยน URL ที่สร้างขึ้น ไม่ใช่โฟลเดอร์เอาต์พุต

### เรียกใช้ไลบรารี Server แบบถาวร

```bash
epub-browser server /path/to/books \
  --server-dir /path/to/epub-browser-state \
  --watch
```

เปิด `http://127.0.0.1:8000/` การเข้าครั้งแรกใช้สร้างผู้ดูแลเริ่มต้น โดยไลบรารีจะยังไม่ถูกสแกนหรือเผยแพร่จนกว่าจะตั้งค่าเสร็จ `--no-browser` เพียงป้องกันไม่ให้บริการเปิดเบราว์เซอร์ในเครื่องโดยอัตโนมัติ

## ข้อมูล บัญชี และขอบเขตการเข้าถึง

หนังสือทุกเล่มมี `book_id` ที่คงที่ ตามค่าเริ่มต้น `--book-id-storage sidecar` จะเก็บรหัสประจำตัวไว้ข้าง EPUB โดยไม่แก้ไขไบต์ของไฟล์ ส่วน `--book-id-storage embedded` จะเขียนลงในเมทาดาทา OPF และต้องใช้ต้นฉบับที่แก้ไขได้

ในโหมด Server โฟลเดอร์ `--server-dir` เป็นแหล่งข้อมูลหลักสำหรับ SQLite แคช และข้อมูลสำรองการย้ายระบบ บัญชี ชั้นหนังสือ ความคืบหน้าการอ่าน คำอธิบายประกอบ ผลลัพธ์ AI และงานต่าง ๆ จะเก็บไว้ที่นี่ ผู้ดูแลจัดการผู้ใช้ บทบาท เซสชัน และสิทธิ์หนังสือ ส่วนสมาชิกใช้ได้เฉพาะหนังสือที่ได้รับอนุญาตและข้อมูลส่วนตัวของตน โปรดปกป้องสิทธิ์ของโฟลเดอร์นี้และข้อมูลสำรอง

## Docker, รีเวิร์สพร็อกซี และเอกสารฉบับเต็ม

ในคอนเทนเนอร์ ให้เมานต์หนังสือแบบอ่านอย่างเดียวและเมานต์ `--server-dir` เป็นโวลุมถาวร ยอมรับส่วนหัวพร็อกซีจากพร็อกซีที่เชื่อถือได้เท่านั้น และใช้ HTTPS สำหรับการนำไปใช้สาธารณะ

ดู Docker Compose ตัวเลือก CLI ทั้งหมด การย้ายข้อมูล LAN รีเวิร์สพร็อกซี และการแก้ไขปัญหาได้ใน [README ภาษาอังกฤษฉบับเต็ม](../../README.md) หรือ [README ภาษาจีนตัวย่อฉบับเต็ม](README.zh-CN.md) การทำงานของทั้งสองโหมดเหมือนกันในทุกภาษา
