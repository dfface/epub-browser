# v2.20.0

## 新增

- 管理员可以开启匿名阅读，让访客在书库里看到并打开公开的书（#85）。个人数据、AI、管理和 PAT 接口仍要求登录。书籍新增「公开 / 登录后可读 / 按授权」三种可见性，也能为首次导入的书设置默认可见性（#86）。默认仍是关闭匿名阅读、新书登录后可读，已有书籍和授权不变。
- 站点可以换上自己的名字、Logo 和图标，也能隐藏页脚的版本与更新提示（#87）。Server 在管理界面里设置并预览，SSG 用 `--site-name`、`--site-logo`、`--site-favicon`、`--hide-version-info`。图片支持 PNG/JPEG/WebP，最大 1 MB、2048 像素，保存时会重编码去掉元数据。
- 可以把整本书缓存在本机，打开和翻章更快（#100）。带版本校验、下载进度、取消与重试，可以移除单本或清空全部；存储不足和书籍更新时都有提示。EPUB 和 PDF、SSG 和 Server 都能用。
- 书籍页和阅读器的目录新增「全部展开 / 全部折叠」（#105），Kindle 精简阅读器也保留深层分支。
- 连续阅读的章节切换和加载状态更稳定，改设置或来回翻章时不容易停在错误的章节（#101）。窄屏下书籍信息、书评和目录改为相接的全宽区块，中间不再留卡片空隙。

## 修复

- 登录页、初始化页和对话框的文案统一走语言包，关闭按钮等提示不再漏翻译。
- 书籍卡片在窄屏、没有书评时不再留下空白占位。

## 影响范围

- 公开阅读、可见性和站点品牌设置是 Server 专属；品牌在 SSG 侧由构建参数提供，SSG 输出不依赖登录或 `/api/*`。
- 本地书籍缓存和目录展开折叠在共享页面里，SSG 与 Server、EPUB 与 PDF 都生效。
- SQLite schema 从 35 升到 38：新增公开阅读设置与 `site_branding` 表（含隐藏版本信息开关），迁移会重建 `books` 表以放宽可见性取值，原有书籍、授权和关联数据保留。
- EPUB `content/` 与 PDF 缓存修订都没变（`server-content-v13`、`server-pdf-v2`），不需要重转书籍。新增的 CLI 参数全部可选。

## 升级说明

- Server：部署重启后自动完成三次迁移到 `user_version = 38`，无需手工 SQL。升级前建议备份 `data/`；回退到旧版本需要恢复升级前的数据库。默认行为不变，匿名阅读要在管理界面主动开启。
- SSG：重新生成并发布整站即可得到新的缓存脚本、目录控件和响应式样式；要用自定义品牌就在构建命令里加对应参数。
- 浏览器里已有的偏好和已缓存的书不会丢；书籍内容变化时会提示重新缓存。

## English

### Added

- Administrators can enable anonymous reading so visitors see and open public books in the catalogue (#85). Personal data, AI, administration and PAT endpoints still require sign-in. Books now have public / signed-in / restricted visibility, and a configurable default for first-time imports (#86). The defaults stay private: anonymous reading off and new books signed-in. Existing books and grants are unchanged.
- Sites can set their own name, logo and favicon, and hide footer credits, version and update notices (#87). Server exposes this under Administration with a preview; SSG uses `--site-name`, `--site-logo`, `--site-favicon` and `--hide-version-info`. PNG, JPEG and WebP images up to 1 MB and 2048 pixels are accepted and re-encoded to strip metadata.
- A whole book can be cached on the device to speed up opening and chapter navigation (#100). It includes version checks, download progress, cancel and retry, per-book removal and clear-all, plus messages for full storage and changed books. Works for EPUB and PDF, in both SSG and Server.
- Book and reader contents gain "Expand all" and "Collapse all" controls (#105); the Kindle reader keeps deep branches as well.
- Continuous reading handles chapter switches and loading states more reliably when settings change or chapters are revisited (#101). On narrow screens, book info, reviews and contents become adjoining full-width sections without card gaps.

### Fixed

- Login, setup and dialog copy now uses the shared locale packs, so labels such as the close button are translated.
- Book cards no longer leave empty space on narrow screens when reviews are hidden.

### Affected scope

- Anonymous reading, visibility settings and site branding administration are Server-only. SSG branding comes from build flags; static output depends on neither login state nor `/api/*`.
- Local book caching and the contents controls live in shared pages, covering SSG and Server, EPUB and PDF.
- SQLite schema advances from 35 to 38: anonymous-reading settings and the `site_branding` table (with the footer visibility switch) are added, and the `books` table is rebuilt to allow the new visibility value. Existing books, grants and related records are preserved.
- Neither the EPUB `content/` nor the PDF cache revision changed (`server-content-v13`, `server-pdf-v2`), so no books need reconversion. All new CLI flags are optional.

### Upgrade notes

- Server: three migrations run automatically on restart to `user_version = 38`, with no manual SQL. Back up `data/` before upgrading; rolling back to an older release requires the pre-upgrade database. Defaults are unchanged, so anonymous reading must be enabled explicitly in Administration.
- SSG: regenerate and republish the static site to pick up the cache scripts, contents controls and responsive styles; add the branding flags to the build command if needed.
- Existing browser preferences and cached books are kept; a changed book asks to be cached again.
