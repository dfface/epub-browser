# v2.15.1

## 修复

- **搜索索引与书籍缓存的 LRU 竞态（仅 Server）**：发布索引或恢复书籍缓存时按当前上限预留槽位并即时裁剪，避免刚构建好的索引或刚恢复的缓存被立即淘汰；正在使用中的索引与书籍缓存延后淘汰，索引构建失败时保留原有缓存条目。调整搜索索引缓存上限后立即裁剪已有索引。书籍缓存将「最近阅读时间」与「缓存访问时间」合并为同一最近使用时间，首次打开的书不再被误判为最久未读。全书搜索也不再依赖预先检查索引新旧，而是在同一次缓存锁定内完成构建与校验。
- **冷缓存准备完成后的循环（仅 Server）**：书籍缓存恢复完成后直接打开目标书籍并保留章节锚点，不再刷新准备页；避免并发读者在两次请求之间淘汰该书，导致反复回到准备流程。
- **全书搜索交互（仅 Server，EPUB）**：结果分页新增页码输入与跳转，可直接前往指定结果页；搜索进行中禁止重复翻页或提交；请求失败后重新打开面板会重试上次查询。焦点不会停留在隐藏的分页控件或隐藏元素上，结果区滚动不再带动外层页面。书籍页弹窗与章节页抽屉改用同一份模板，窄屏下分页控件可换行显示。
- **生词本视图切换（仅 Server）**：从某本书的单词列表可一键返回「全部单词」；切换视图会取消在途请求，清空搜索、筛选与滚动位置，并把焦点移到列表标题，避免残留上一本书的结果。

### 影响范围

- 行为变化仅作用于 Server：全书搜索（仅 EPUB）、搜索索引缓存、书籍磁盘缓存与生词本。共享页面模板的改动只进入 Server 分支；SSG 不输出搜索或生词本资源与接口，本次无需重新生成静态站点。
- 未新增 API、CLI 参数或数据库迁移；EPUB `content/` 与 PDF 缓存修订、SQLite schema 均未变化。
- 新增 17 种语言的 `vocabulary.allWords` 文案。

### 升级说明

- Server：部署并重启即可，无需重新转换 EPUB 或 PDF，也无需数据库迁移；仍建议按惯例在升级前备份 `data/`。
- 「一般设置」中的书籍缓存数量与搜索索引缓存数量调整现在会立即生效，并在索引或缓存发布时按新上限裁剪。
- 升级重启后首次搜索会按需重建索引；缓存代际未变的既有索引会继续复用。
- SSG：无需操作。

## Fixes

- **LRU races between search indexes and book caches (Server only)**: Publishing an index or restoring a book cache now reserves a slot and trims against the current limit, so a freshly built index or restored cache is not evicted immediately. Indexes and book caches in use are evicted only after they are released, a failed index build keeps the existing cache entry, and lowering the search-index cache limit trims existing indexes right away. Book caches now combine reading recency and cache access time into one last-used value, so a book opened for the first time is no longer treated as the least recently used. Full-book search no longer pre-checks index freshness; building and validation happen under one cache pin.
- **Cold-cache preparation loop (Server only)**: Once a book cache is restored, the reader opens the target book directly with its chapter anchor instead of reloading the preparation page. A concurrent reader can no longer evict the book between those two requests and send the user back into preparation repeatedly.
- **Full-book search interactions (Server only, EPUB)**: Result pagination gains a page-number input and jump action, repeat paging or submissions are blocked while a search is running, and reopening the panel after a failed request retries the last query. Focus no longer stays on hidden pagination controls or hidden elements, result scrolling no longer chains to the outer page, and the book dialog and chapter drawer share one template with pagination that wraps on narrow screens.
- **Vocabulary view switching (Server only)**: A book's word list now has a one-click "All vocabulary" back action. Switching views cancels in-flight requests, clears the query, filter and scroll position, and moves focus to the list heading so results from the previous book cannot linger.

### Affected scope

- Behavior changes are Server-only: full-book search (EPUB only), search-index caching, on-disk book caches and vocabulary lists. Shared template changes only affect the Server branch. SSG emits neither search nor vocabulary assets or endpoints and needs no regeneration for this release.
- No new API, CLI flag or database migration. Neither the EPUB `content/` nor the PDF cache revision changed, and the SQLite schema is unchanged.
- The `vocabulary.allWords` copy ships in all 17 locales.

### Upgrade notes

- Server: deploy and restart. No EPUB or PDF reconversion and no database migration are needed; backing up `data/` before upgrading remains recommended.
- Changes to the book cache limit and search-index cache limit in General settings now take effect immediately and are applied when indexes or caches are published.
- The first search after a restart rebuilds its index on demand; existing indexes whose cache generation is unchanged are reused.
- SSG: no action required.
