# EPUB Browser v2.3.14 — 更顺畅的管理体验与跨站嵌入

发布日期 / Release date: 2026-08-25

## 中文

v2.3.14 优化了移动端书库、账户与管理后台的使用反馈，并让 Server 部署的阅读页面可以嵌入其它站点。

### 改进

- **Server 端允许跨站 iframe 嵌入**：阅读器响应不再通过 CSP 阻止外部站点嵌入，便于放入门户、知识库或其它受控站点。
- **移动端书库保持适度左右留白**：书籍、搜索与筛选内容不再紧贴屏幕边缘，同时维持原有的信息层级与网格密度。
- **品牌标识使用透明源图**：导航标识、favicon 与 PWA 图标均由 `logo-mark-color.png` 演化生成，避免不透明底色出现在浏览器或系统界面中。
- **账户设置与管理后台增加加载反馈**：面板打开后会立刻提示正在加载，所有首屏请求完成或失败后自动恢复可操作状态。
- **AI 权限列表更紧凑清晰**：成员授权改为带文字标签的无障碍开关，额度覆盖输入保持独立标签，避免原生 checkbox 被通用表单样式放大。

### 升级说明

- 无需 SQLite migration、无需重新转换 EPUB，也无需提高 Server EPUB 内容缓存修订。
- Server 部署更新并重启后即可生效；SSG 部署请重新生成并完整发布输出目录，以便新的哈希资源一同上线。
- 允许跨站嵌入会放宽点击劫持防护边界；仅应将受信任的阅读器部署地址嵌入受控页面。

## English

v2.3.14 improves mobile-library spacing and account-management feedback, and allows Server reader pages to be embedded by other sites.

### Improvements

- **Server pages may be embedded cross-site**: Reader responses no longer use CSP to block external iframe embedding, making controlled portal and knowledge-base integrations possible.
- **Mobile Library has balanced side spacing**: Books, search, and filters no longer sit against the viewport edge while retaining the existing hierarchy and grid density.
- **Brand marks now come from a transparent source image**: Navigation, favicon, and PWA icons are derived from `logo-mark-color.png`, avoiding opaque backgrounds in browser and system surfaces.
- **Account settings and Administration now provide loading feedback**: Each surface announces loading immediately, then restores interaction after its initial requests complete or fail.
- **AI permissions are clearer and more compact**: Member authorization uses labelled accessible switches, and quota overrides retain their own clear labels instead of oversized native checkboxes.

### Upgrade notes

- No SQLite migration, EPUB reconversion, or Server EPUB-content-cache revision is required.
- Restart an updated Server deployment to apply the change. For SSG deployments, regenerate and publish the complete output directory so the new hashed assets are available together.
- Cross-site embedding relaxes the clickjacking boundary; only embed a trusted reader deployment in controlled pages.
