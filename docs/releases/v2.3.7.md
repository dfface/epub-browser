# EPUB Browser v2.3.7 — AI chapter overview

发布日期 / Release date: 2026-08-24

## 中文

v2.3.7 为 Server 阅读器加入“本章总览”：它把 AI 阅读结果组织为可快速回看的章节信息结构，并提供可交互的思维导图；不改变 EPUB 内容缓存，也不影响 SSG 阅读页。

### 新功能与改进

- **本章总览**：AI 阅读引导中可打开全屏的章节总览，按“本章在讲什么、章节推进、关键内容、本章落点”组织内容，避免把章节理解压缩成单一长摘要。
- **可操作的思维导图**：导图支持拖动、滚轮缩放、缩小、放大与一键适配；在窄屏上会回到单列阅读布局。
- **更严谨的阅读理解**：章节提示词新增技术类、小说类、通用类和自动识别指引，并要求以文本证据区分事实、推断与开放问题。
- **阅读主题与字体一致性**：本章总览会继承阅读器字体设置；导图和段落注释在深色主题下修正文字与背景对比，保证多层节点和注释内容可读。

### 升级说明

- 无需 SQLite migration、无需重新转换 EPUB，也无需更新 Server EPUB 内容缓存修订。
- 本章总览是 Server 专属 AI 功能，SSG 输出不会包含相关 API 或交互。
- 已有 AI 章节结果使用旧模板版本时，请重新生成该章节的 AI 阅读结果以获得本章总览。

## English

v2.3.7 adds **Chapter Overview** to the Server reader: an AI-generated, structured view of a chapter with an interactive mind map. It does not change EPUB-derived content caches or the SSG reader.

### Features and improvements

- **Chapter Overview**: Open a full-screen overview from the AI reading guide. It organizes a chapter into what it does, its progression, key material, and its actual ending rather than another long summary.
- **Interactive mind map**: Pan, wheel zoom, zoom controls, and fit-to-view are available; narrow screens switch back to a single-column reading layout.
- **More rigorous reading comprehension**: Chapter prompts now have technical, fiction, general, and automatic profiles and require evidence-based distinctions between fact, inference, and open question.
- **Reader-consistent presentation**: Chapter Overview follows reader typography. Mind maps and paragraph notes correct text/background contrast in dark themes so nested nodes and notes remain readable.

### Upgrade notes

- No SQLite migration, EPUB reconversion, or Server EPUB-content-cache revision is required.
- Chapter Overview is a Server-only AI feature; SSG output includes neither its APIs nor its interaction surface.
- Regenerate an existing chapter AI result created with an older template version to receive Chapter Overview.
