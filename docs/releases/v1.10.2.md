# EPUB Browser v1.10.2

发布日期 / Release date: 2026-08-12

## 中文

这是一个稳定性修复版本，改善了静态部署到 Pages 后从书籍或章节页返回书库的体验。

### 修复

- **更可靠地返回书库**：Book 与 Chapter 页的书库入口现在直接指向站点根路径，不再经过 `/index.html` 的重定向。
- **移除无效地址片段**：已删除链接中未被使用的书籍 hash fragment，避免 Pages 重定向与浏览器缓存交叠时出现“网页可能已移动”的错误页。

### 升级提示

重新部署完整生成目录后即可生效。无需迁移数据，也无需手动清除浏览器缓存。

## English

This is a stability release that improves the path back to the library when a generated site is deployed to Pages.

### Fixes

- **A more reliable return to the library**: Library links on book and chapter pages now go straight to the site root, without passing through the `/index.html` redirect.
- **Removed an unused URL fragment**: Book hash fragments that were never read by the app have been removed, avoiding the browser error page that could occur when Pages redirects and cached navigation overlap.

### Upgrade note

Redeploy the complete generated directory to apply the update. No data migration or manual browser-cache clearing is required.
