# EPUB Browser v2.9.11 — 首页"继续阅读"栏及其设置功能

发布日期 / Release date: 2026-09-04

## 中文

v2.9.11 在库首页新增"继续阅读"(Continue reading)栏，展示最近阅读的书本，并标注相对时间与上次阅读位置；同时新增仅 Server 模式可用的管理员 **General** 设置面板，用于配置首页"继续阅读"栏显示的书本数量。本次还补全了新界面在全部 17 种语言下的翻译，并把 General 设置界面收敛为更紧凑、可扩展的布局。

### 新功能

- **首页"继续阅读"栏**：库首页新增"继续阅读"区块，按最近阅读时间列出书本，显示"刚刚 / X 分钟前 / X 小时前 / X 天前 / X 个月前"的相对时间标签以及上次停留的章节或页码；点击任意书本直接进入上次的阅读位置。
- **管理员 General 设置（仅 Server）**：管理后台新增 **General** 标签页，提供"*Books in 'Continue reading'*"（首页"继续阅读"栏显示的最近阅读书本数量）一项设置，输入框带正整数校验（大于 0），并具备"保存中 / 已保存 / 保存失败"的状态反馈；"保存设置"按钮置于表单底部，便于未来继续增加选项。

### 影响范围

- **部署与格式范围**：该特性仅作用于 Server 模式——"继续阅读"栏与管理员 General 设置依赖登录态、SQLite 与 `/api/*` 服务端能力，SSG 静态站点不依赖也不暴露这些能力；PDF 与 EPUB 均适用。
- **触发条件**：登录 Server 后访问库首页；以管理员身份打开管理后台的 General 标签页并修改"继续阅读"书本数量；切换界面语言。

### 升级说明

- **Server 部署**：重启 Server 即生效（页面资产重新哈希发布）；后端复用既有的阅读进度与服务器设置存储，无需手动迁移。
- **SSG 部署**：不涉及本特性，无需重新生成。
- **无需配置**：语言包随资产一并发布；General 设置项为服务端配置，不涉及内容缓存 schema 或 SQLite 迁移。

## English

v2.9.11 adds a "Continue reading" rail to the Library home page that lists recently read books with a relative timestamp and the last reading position, and introduces a Server-only administrator **General** settings panel that controls how many recently read books the rail shows. This release also completes translations for the new interface across all 17 languages and tightens the General settings layout into a more compact, extensible form.

### New features

- **Library "Continue reading" rail**: The Library home page gains a "Continue reading" section that lists books by recent reading activity, showing a relative-time label ("Just now / {count}m ago / {count}h ago / {count}d ago / {count}mo ago") and the last chapter or page reached; selecting a book jumps straight back to where reading left off.
- **Administrator General settings (Server only)**: The administration console gains a **General** tab with a single "Books in 'Continue reading'" setting that controls how many recently read books appear in the home rail. The field validates a positive whole number (greater than 0) and reports "Saving… / saved / save failed" states; the "Save settings" button sits at the bottom of the form so further options can be added later.

### Affected scope

- **Deployment and format scope**: The feature applies to Server mode only — the "Continue reading" rail and General settings depend on sign-in state, SQLite, and `/api/*` server capabilities, which SSG static output neither relies on nor exposes; both EPUB and PDF are covered.
- **Trigger**: visiting the Library home while signed in to a Server; opening the administration General tab as an admin and changing the "Continue reading" book count; switching the interface language.

### Upgrade notes

- **Server**: restart to pick up the new asset hashes; the backend reuses the existing reading-progress and server-settings storage, so no manual migration is needed.
- **SSG**: not affected by this feature; no regeneration required.
- **No configuration required**: the language bundles ship with the assets, and the General setting is server-side configuration that does not change the content-cache schema or SQLite migrations.
