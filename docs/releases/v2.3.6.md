# EPUB Browser v2.3.6 — EPUB 3 navigation support

发布日期 / Release date: 2026-08-24

## 中文

v2.3.6 让纯 EPUB 3 图书能够使用其标准导航文档提供的目录，而不再要求附带旧版 NCX 文件。

### 改进

- **支持 EPUB 3 标准目录**：现在会识别 OPF manifest 中标记为 `properties="nav"` 的导航文档，读取其中 `epub:type="toc"` 的章节标题、层级和锚点。
- **目录更符合原书结构**：无链接的分组标题会保留为目录分段；当图书同时提供 EPUB 3 nav 和 NCX 时，以 EPUB 3 nav 为准，NCX 继续作为旧版 EPUB 和兼容文件的回退。

### 升级说明

- 无需 SQLite migration，也无需修改原 EPUB。Server 的 EPUB 派生内容缓存修订已更新；部署并重启后，已有书籍会在下一次扫描时重新转换，以生成标准 EPUB 3 目录。SSG 请照常重新生成站点。

## English

v2.3.6 lets EPUB 3 books use their standard navigation document for the table of contents, without requiring a legacy NCX file.

### Improvements

- **Standard EPUB 3 navigation support**: The reader now recognizes navigation documents declared with `properties="nav"` in the OPF manifest and reads chapter titles, hierarchy, and anchors from `epub:type="toc"`.
- **A TOC that matches the book**: Non-linked grouping labels are preserved as sections. When a book provides both an EPUB 3 nav document and an NCX, the EPUB 3 nav document is authoritative; NCX remains a fallback for EPUB 2 and compatibility files.

### Upgrade notes

- No SQLite migration or source-EPUB change is required. The Server EPUB-derived content-cache revision has changed, so existing books are reconverted on the next scan after deployment and restart to generate their EPUB 3 TOCs. Regenerate SSG sites as usual.
