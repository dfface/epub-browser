# EPUB Browser v2.3.11 — 更快、更统一的阅读与主题体验

发布日期 / Release date: 2026-08-25

## 中文

v2.3.11 缩短了书库和书籍页面的首屏资源路径，统一了阅读页面的主题表现，并修复了导航菜单在页面间的一致性问题。书架、标注和排序等较少使用的功能仍可正常使用，只会在首次需要时加载。

### 改进

- **更轻的书库与书籍首屏**：Library 和 Book 页面不再在首次打开时加载书架、标注和拖拽排序所需的 JavaScript；首次打开相应功能时会自动加载，不影响原有操作。
- **AI 富文本继续按需加载**：Book 页的 Mermaid 和 KaTeX 等 AI 富文本资源保持非首屏加载，减少普通阅读路径上的下载与解析工作。
- **统一阅读主题**：Light、Dark、Sepia、Forest、Ocean、Peach 和 Lavender 主题现在为章节阅读的页面、正文、控制按钮与移动端阅读栏提供一致的配色、边框和阴影，并保持足够的文字与控件对比度。
- **可键盘操作的主题菜单**：主题选择器现在会标记当前主题和展开状态，支持方向键、Home、End 与 Escape；选定主题或关闭菜单后焦点会回到主题按钮。切换语言时，已打开菜单的主题名称也会立即刷新。

### 修复

- **恢复弹窗的正确布局**：修复了延迟资源加载后，Library 或 Book 页面中的书架、账户和管理面板可能错误出现在正文底部的问题。
- **导航菜单互斥**：打开主题菜单后再点击语言、账户、管理或其他导航操作，主题菜单会立即关闭；Library、Book 与 Chapter 页面行为一致。

### 升级说明

- 无需 SQLite migration、无需重新转换 EPUB，也无需提高 Server EPUB 内容缓存修订。
- Server 部署更新并重启后即可生效；SSG 部署请重新生成并完整发布输出目录，以便新的哈希资源一同上线。

## English

v2.3.11 shortens the initial resource path for Library and Book pages, unifies reader-surface theming, and makes navigation menus behave consistently across reader surfaces. Less frequently used bookshelf, annotation, and sorting features continue to work as before, loading only when first needed.

### Improvements

- **Lighter Library and Book first loads**: Library and Book pages no longer load the JavaScript for bookshelf, annotation, and drag-ordering features on initial render. The required code loads automatically when a reader first uses the related feature.
- **AI rich text remains on demand**: Mermaid, KaTeX, and related Book-page AI rich-text assets remain off the critical reading path.
- **Unified reading themes**: Light, Dark, Sepia, Forest, Ocean, Peach, and Lavender now provide coordinated page, text, control, and mobile-reader-chrome colors, borders, and shadows for chapter reading, with accessible text and control contrast.
- **Keyboard-operable theme picker**: The picker now exposes the current selection and expanded state, supports Arrow keys, Home, End, and Escape, and restores focus to the theme button after selection or dismissal. Its labels also refresh immediately when the locale changes.

### Fixes

- **Correct modal layout restored**: Fixed an issue where bookshelf, account, or administration panels could appear in the document flow at the bottom of Library or Book pages after deferred-resource loading.
- **Mutually exclusive navigation menus**: Opening another navigation action—such as language, account, or administration—now immediately closes the theme picker on Library, Book, and Chapter pages.

### Upgrade notes

- No SQLite migration, EPUB reconversion, or Server EPUB-content-cache revision is required.
- Restart an updated Server deployment to apply the change. For SSG deployments, regenerate and publish the complete output directory so the new hashed assets are available together.
