# v2.9.12

## 修复 / Fixes

### 中文
- **当 AI 阅读被禁用时，隐藏全部 AI 阅读入口**：此前即使服务器端关闭了 AI 阅读功能，单本书的阅读页面与 library 首页导航栏仍会显示 "AI readings" 入口，并加载 AI 功能脚本。现在所有 AI 阅读入口统一由服务器唯一的 `ai_settings.enabled` 开关驱动——禁用后，章节/书籍目录中的 AI 阅读导航、桌面与移动端工具栏的 AI 按钮、书籍页的 AI 操作、阅读进度指示器，以及 `ai-feature-loader.js` 脚本均不再渲染。
- 修正了 library 首页（全局导航栏）此前完全未接入 `ai_reading_enabled` 标志的遗漏（关联 issue #24）。

### English
- **Hide all AI reading entry points when AI reading is disabled**: Previously, even when the server disabled AI reading, the per-book reader and the library home navigation bar still showed the "AI readings" entry and loaded the AI feature script. All AI reading entry points are now driven by the server's single `ai_settings.enabled` capability. When disabled, the AI reading nav (chapter/book TOC), desktop and mobile toolbar AI buttons, the book-page AI actions, reading indicators, and the `ai-feature-loader.js` script are no longer rendered.
- Fixed the library home (global nav bar), which previously never received the `ai_reading_enabled` flag at all (issue #24).

## 受影响范围 / Affected scope

### 中文
- **Server 模式**：AI 入口现在随 `ai_settings.enabled` 实时切换，无需重启服务。
- **SSG 模式**：始终不生成任何 AI 入口（与以往一致）。
- **PDF 模式**：沿用其既有的独立条件，不受影响。
- **阅读洞察（Reading insights）**：独立于 AI 阅读开关，在 Server 模式下始终保留显示。

### English
- **Server mode**: AI entry points now toggle live with `ai_settings.enabled` — no restart required.
- **SSG mode**: still generates no AI entry points (unchanged).
- **PDF mode**: uses its own existing condition; unaffected.
- **Reading insights**: independent of the AI reading toggle and remains visible in Server mode.

## 升级说明 / Upgrade notes

### 中文
- 无需数据迁移或配置变更。
- 若你此前依赖某些 DOM 元素/脚本的存在与否来判定 AI 是否可用，请注意：禁用 AI 阅读时这些元素与脚本现在会完全不输出。

### English
- No data migration or configuration changes required.
- If you previously relied on the presence/absence of certain DOM elements or scripts to detect AI availability, note that when AI reading is disabled they are now fully omitted.
