# EPUB Browser v2.3.16 — 修复 Server 书架同步

发布日期 / Release date: 2026-08-25

## 中文

v2.3.16 修复了 Server 模式下从书籍页加入书架后，书籍没有出现在书架中的问题，并恢复了章节页书架的初始化。

### 修复

- **书籍页加入书架会正确写入 Server**：书架模块现在会在处理“加入书架”操作前加载；登录用户的操作不再误写入浏览器本地存储。
- **章节页书架恢复可用**：章节页现在调用正确的书架初始化器，避免重复重试而无法打开书架。

### 升级说明

- 无需 SQLite migration、无需重新转换 EPUB，也无需提高 Server EPUB 内容缓存修订。
- Server 部署更新并重启后即可生效；SSG 部署请重新生成并完整发布输出目录，以便新的哈希资源一同上线。
- 旧版本中已误写入浏览器本地存储的书架项目不会自动迁移；请在更新后重新加入书架。

## English

v2.3.16 fixes Server-mode bookshelf additions from a book page and restores bookshelf initialization on chapter pages.

### Fixes

- **Book-page additions now persist to the Server**: The bookshelf module loads before handling an Add to Shelf action, so signed-in users no longer write their shelf changes to browser-local storage by mistake.
- **Chapter-page bookshelf is available again**: Chapter pages now invoke the exported bookshelf initializer instead of retrying an unavailable name.

### Upgrade notes

- No SQLite migration, EPUB reconversion, or Server EPUB-content-cache revision is required.
- Restart an updated Server deployment to apply the change. For SSG deployments, regenerate and publish the complete output directory so the new hashed assets are available together.
- Shelf entries accidentally saved in browser-local storage by older versions are not migrated automatically; add them to the shelf again after updating.
