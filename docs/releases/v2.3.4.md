# EPUB Browser v2.3.4 — Clearer sign-in and mobile AI reading

发布日期 / Release date: 2026-08-23

## 中文

v2.3.4 修复登录页初始错误提示和移动端章节 AI 阅读入口，并在 README 中补充可直接体验两种部署模式的演示站点。

### 改进

- **可直接体验两种模式**：README 现在提供 SSG 和 Server 演示站点链接；Server 演示环境可使用 `demo` / `demo` 登录。

### 修复

- **登录页不会误报凭证错误**：首次打开登录页时，“用户名或密码不正确”提示会保持隐藏，只有登录请求真正失败后才出现。
- **移动端章节 AI 阅读**：底部 AI 阅读按钮现在与桌面侧边栏的章节 AI 阅读完全一致，会在需要生成时显示确认弹窗，而不会跳转到 AI 阅读汇总。连续滚动时也能正确保持当前章节上下文。

### 升级说明

- 无需 SQLite migration，也无需重新转换 EPUB。部署 `epub-browser:2.3.4` 并重启 Server 即可生效；SSG 输出不包含这些 Server 专属能力。

## English

v2.3.4 fixes the initial sign-in error display and the mobile chapter AI-reading entry point, and adds live SSG and Server demos to the README.

### Improvement

- **Try both modes directly**: The README now links to live SSG and Server demos. The Server demo accepts `demo` / `demo` credentials.

### Bug fixes

- **No false sign-in error on page load**: “Invalid username or password” now remains hidden when the sign-in page first opens and appears only after an actual failed request.
- **Mobile chapter AI reading**: The bottom AI-reading button now matches the desktop reader sidebar’s chapter AI-reading action. It shows the generation confirmation when needed instead of opening the AI-readings summary, and preserves the current chapter in continuous reading.

### Upgrade notes

- No SQLite migration or EPUB reconversion is required. Deploy `epub-browser:2.3.4` and restart the Server; SSG output remains free of these Server-only capabilities.
