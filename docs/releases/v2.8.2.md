# EPUB Browser v2.8.2 — 更专注、更协调的桌面阅读

发布日期 / Release date: 2026-08-29

## 中文

v2.8.2 让桌面端阅读界面更安静，也把 EPUB 与 PDF、SSG 与 Server 的导航体验进一步统一。读者现在可以分别控制章节侧栏和阅读工具栏是否自动隐藏；需要操作时，只需将指针移到对应边缘或使用键盘聚焦即可唤出。

### 阅读体验

- **章节侧栏与阅读工具栏可独立自动隐藏**：阅读设置新增“自动隐藏章节侧栏”和“自动隐藏阅读工具栏”。两项设置互不依赖，可按阅读习惯自由组合，并在桌面端保存选择。
- **左右边缘提示更协调**：隐藏后的章节侧栏与阅读工具栏采用一致的边缘露出宽度、透明度和延迟，悬停或键盘聚焦时再完整显示；减少动效模式下会直接切换，避免不必要的动画。
- **AI 阅读场景保持一致**：无论 AI 对话面板是否打开或进入全屏，底层章节侧栏都沿用同一套自动隐藏规则。全屏 AI 仍会自然遮挡阅读控件，不产生额外的布局分支。
- **设置说明更轻量**：两项自动隐藏设置的操作说明收进可访问的小型信息按钮，减少设置面板中的常驻文字，让选项层级更清楚。
- **章节侧栏更安静**：降低侧栏边框与阴影的视觉强度，使其接近右侧阅读工具栏，不再在正文旁形成明显发光效果。

### 多语言与 SSG

- **SSG 导航补齐语言切换**：静态生成的 Library、Book 和 Chapter 页面现在都提供一致的多语言切换入口，并加载同一套本地化导航逻辑。
- **Book 与 Chapter 样式恢复一致**：语言控件依赖的无障碍隐藏样式移入共享导航样式，修复静态书籍页和章节页中语言图标、文字及选择框挤在一起的问题。

### 升级说明

- 不包含 SQLite migration，也不改变 EPUB/PDF 内容缓存结构或对应 revision；Server 中已有书籍无需重新转换。
- Server 部署新版本并重启即可获得界面与交互更新。SSG 站点需要使用新版本重新执行 `epub-browser ssg`，以写出新的页面和静态资源。

## English

v2.8.2 makes desktop reading quieter and brings navigation behavior into closer alignment across EPUB and PDF as well as SSG and Server deployments. Readers can now control chapter-sidebar and reading-toolbar auto-hide independently, revealing either control by moving the pointer to its edge or focusing it from the keyboard.

### Reading experience

- **Independent auto-hide controls**: Reading settings now include “Auto-hide chapter sidebar” and “Auto-hide reading toolbar.” Each preference is stored independently on desktop, so readers can combine them to fit their workflow.
- **Balanced edge reveals**: Hidden left and right controls now share the same visible edge, opacity, and delay. Hover or keyboard focus reveals the full control, while reduced-motion mode switches state without unnecessary animation.
- **Consistent behavior with AI chat**: The underlying chapter sidebar follows the same auto-hide rule whether the AI panel is closed, open, or fullscreen. Fullscreen AI can naturally cover reading controls without introducing a separate layout behavior.
- **Lighter settings guidance**: Auto-hide instructions now live in accessible info buttons instead of persistent helper paragraphs, making the settings hierarchy easier to scan.
- **A quieter chapter sidebar**: Softer borders and shadows bring the chapter sidebar in line with the reading toolbar and remove the distracting glow beside the text.

### Language and SSG

- **Language switching throughout SSG navigation**: Static Library, Book, and Chapter pages now expose the same locale control and load the shared localized-navigation behavior.
- **Correct Book and Chapter styling**: The visually hidden label rule used by the locale control now lives in shared navigation CSS, fixing the compressed icon, label, and select layout on static book and chapter pages.

### Upgrade notes

- This release has no SQLite migration and does not change the EPUB or PDF content-cache schema or revisions; existing Server books do not need reconversion.
- Deploy and restart Server mode to pick up the UI and interaction updates. For SSG, rerun `epub-browser ssg` with this version to emit the updated pages and static assets.
