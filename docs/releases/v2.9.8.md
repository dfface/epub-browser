# EPUB Browser v2.9.8 — Kindle 极简阅读器修复、书架分组、阅读时段上报与权限加固

发布日期 / Release date: 2026-08-31

## 中文

v2.9.8 是 v2.9.7 Kindle 极简模式发布后的修复与加固版本。主题与字号按钮现在同时出现在 Kindle 首页与章节页头部，且主题切换在 e-Ink Kindle WebKit 上真正生效（CSS 改用 `background-color` + `!important`，正文颜色随主题联动；主题循环改用显式 ES5 循环，兼容旧 WebKit）。Server 模式下，极简书架页会把当前用户的书架分组渲染为只读嵌套列表（来自鉴权后的 SQLite 文档，绝不信任客户端输入）；Kindle 章节页的阅读时段心跳改为上报真实的墙钟阅读秒数（1–20 秒上限，与桌面阅读时段跟踪器一致），节奏从 60 秒恢复为 15 秒且首个心跳立即发送，阅读时长统计不再虚高或偏低。账户管理中的会话设备标签现在能正确识别 Kindle 家族设备——e-Ink Kindle（UA 含 `Kindle/`、`Arora/`）显示为 "Kindle"，Fire 平板（`Silk/`）显示为 "Kindle Fire"，不再把 Kindle 的 WebKit UA 误报成 "Safari · Android"。最后，受限可见性书籍在所有 Kindle 面上对未授权用户做了完整加固：极简书架不列出该书、`kindle.html` / `kindle_chapter_N.html` 与 `/api/reading-progress/{hash}` 全部返回 403，并补齐了相应回归测试。

### 修复与改进

- **Kindle 主题/字号生效（SSG 与 Server）**：极简阅读器的主题样式改用 `background-color` + `!important`，e-Ink Kindle WebKit 上 Sepia/Dark 主题的背景与文字色不再被忽略；正文（`.k-content`）颜色随主题联动；`kTheme()` 用显式循环替代 `indexOf`，兼容无该方法的旧 WebKit。主题与字号按钮（Theme / A- / A+）新增到 Kindle 首页与章节页头部（带 `accesskey`），章节页底部原有控制保留。
- **Kindle 书架分组（Server）**：`/kindle-library.html` 渲染用户书架分组为只读嵌套列表，数据来自鉴权后的 SQLite 文档，绝不使用客户端输入；无分组时保持原有平铺列表。
- **阅读时段上报修正（Server）**：Kindle 章节页心跳上报真实的墙钟间隔秒数（1–20 秒上限），发送节奏从 60 秒恢复为 15 秒，首个心跳立即发送；阅读时段统计与桌面端一致。
- **会话设备标签识别**：账户管理的会话设备标签识别 Kindle 家族——e-Ink Kindle（`Kindle/`、`Arora/`）显示 "Kindle"，Fire 平板（`Silk/`）显示 "Kindle Fire"；普通浏览器（Edge/Firefox/Chrome/Safari + 平台）识别不变。
- **Kindle 权限加固（Server）**：受限可见性书籍对未授权用户在所有 Kindle 面拒绝——极简书架不列出、书页与章节页返回 403、进度 API 返回 403；新增回归测试覆盖匿名（303）、PDF（404）与私有书（403）三类场景。

### 影响范围

- **部署与格式范围**：Kindle 主题/字号修复作用于 SSG 与 Server 共享的极简页面模板；书架分组、心跳上报与权限加固仅 Server；仅 EPUB。SSG 默认行为不变。
- **触发条件**：在 Kindle 上切换主题或调整字号；Server 上打开极简书架（含书架分组）；Kindle 章节页阅读触发心跳；账户管理查看会话设备标签；未授权用户访问受限书目的 Kindle 面。

### 升级说明

- **Server 部署**：重启 Server 即生效（页面模板与资产、权限逻辑均为请求时生效），无需重新转换 EPUB，不涉及内容缓存 schema 或 SQLite 迁移。
- **SSG 部署**：用 `ssg --kindle` 重新生成静态站点以获取主题/字号修复。
- **无需配置**：无新增配置项。

## English

v2.9.8 is the fix-and-hardening release that follows the v2.9.7 Kindle minimal mode. Theme and font buttons now appear on both the Kindle index and chapter headers, and theme switching actually works on e-Ink Kindle WebKit (the CSS now uses `background-color` with `!important`, body text colour follows the theme, and the theme rotation uses an explicit ES5 loop for older WebKit). In Server mode the minimal shelf renders the signed-in user's bookshelf groups as read-only nested lists (from the authenticated SQLite document, never from client input); Kindle chapter heartbeats now report real wall-clock reading seconds (capped at 1–20, matching the desktop reading-session tracker) at a 15-second cadence with an immediate first beat, so reading-time totals are no longer inflated or understated. Session-device labels in the account panel now recognize the Kindle family — e-Ink Kindles (UA contains `Kindle/` or `Arora/`) show "Kindle" and Fire tablets (`Silk/`) show "Kindle Fire" instead of the misleading "Safari · Android". Finally, restricted-visibility books are fully hardened across every Kindle surface for unauthorized users: the minimal shelf omits the book, `kindle.html` / `kindle_chapter_N.html` and `/api/reading-progress/{hash}` all return 403, and regression tests cover the anonymous (303), PDF (404), and private-book (403) cases.

### Fixes and improvements

- **Kindle theme/font now apply (SSG and Server)**: minimal-reader theme styles use `background-color` + `!important` so Sepia/Dark backgrounds and text colours are no longer ignored on e-Ink Kindle WebKit; `.k-content` text follows the theme; `kTheme()` rotates via an explicit loop instead of `indexOf` for older WebKit. Theme and font controls (Theme / A- / A+) were added to the Kindle index and chapter headers (with `accesskey`); the existing chapter-footer controls remain.
- **Bookshelf groups on the minimal shelf (Server)**: `/kindle-library.html` renders the user's bookshelf groups as read-only nested lists sourced from the authenticated SQLite document — never from client input; books without a group keep the plain flat list.
- **Reading-session reporting fix (Server)**: Kindle chapter heartbeats report the real wall-clock elapsed seconds (capped at 1–20), the cadence is back to 15 seconds from 60, and the first beat fires immediately; totals now match the desktop tracker.
- **Session-device label recognition**: the account panel labels the Kindle family correctly — e-Ink Kindles (`Kindle/`, `Arora/`) show "Kindle" and Fire tablets (`Silk/`) show "Kindle Fire"; ordinary browsers (Edge/Firefox/Chrome/Safari + platform) are unchanged.
- **Kindle permission hardening (Server)**: restricted-visibility books refuse unauthorized users on every Kindle surface — the minimal shelf omits them, book and chapter pages return 403, and the progress API returns 403; new regression tests cover anonymous (303), PDF (404), and private-book (403) cases.

### Affected scope

- **Deployment and format scope**: the Kindle theme/font fixes ship through the shared minimal-page templates for both SSG and Server; bookshelf groups, heartbeat reporting, and permission hardening are Server-only; EPUB only. Default SSG output is unchanged.
- **Trigger**: toggling theme or font size on a Kindle; opening the minimal shelf with bookshelf groups on the Server; reading a Kindle chapter (heartbeat reporting); viewing session-device labels in the account panel; an unauthorized user hitting a restricted book's Kindle surfaces.

### Upgrade notes

- **Server**: restart to pick up the templates, assets, and permission logic — all apply at request time; no EPUB reconversion, content-cache schema change, or SQLite migration.
- **SSG**: regenerate with `ssg --kindle` to get the theme/font fixes.
- **No configuration required**: no new settings.
