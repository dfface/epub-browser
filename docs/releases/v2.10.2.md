## 修复

- 修复 EPUB 发布者样式覆盖阅读器字号设置的问题。字号滑块扩展到 12 档，并增加更大的字号选项。
- EPUB 样式表中的固定字号会随阅读器字号设置缩放，翻页模式会同步更新页数。

### 影响范围

EPUB 阅读器和 Kindle 兼容阅读页面。SSG 与 Server 部署均适用。

### 升级说明

无需重新转换书籍。Server 页面与资源在部署新版本后生效。

## Fixes

- Fixed publisher styles overriding the EPUB reader's font size. The font slider now has 12 levels, including larger sizes.
- Fixed-size font values in EPUB stylesheets now scale with the reader setting. Pagination updates its page count when the font size changes.

### Affected scope

EPUB reader and Kindle-compatible reading pages in both SSG and Server deployments.

### Upgrade notes

Books do not need to be converted again. Server pages and assets update when the new version is deployed.
