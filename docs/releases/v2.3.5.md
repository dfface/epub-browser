# EPUB Browser v2.3.5 — Reliable JPEG cover resources

发布日期 / Release date: 2026-08-23

## 中文

v2.3.5 修复了部分 EPUB 在 Server 模式下缺少书籍封面的问题。

### 修复

- **JPEG 封面资源会完整发布**：扩展名为 `.jfif` 或 `.jpe` 的 JPEG 封面现在会随 EPUB
  资源一起复制并安全地提供给浏览器；`.jfif` 文件会以 `image/jpeg` 响应，避免因不同平台的
  MIME 识别差异而无法显示。

### 升级说明

- 无需 SQLite migration，也无需修改原 EPUB。重启 Server 或等待下一次书库扫描即可；缺少
  封面的旧缓存会被识别为无效，并只重新转换受影响的书籍。

## English

v2.3.5 fixes missing book covers for some EPUBs in Server mode.

### Bug fixes

- **JPEG cover resources are published completely**: JPEG covers named with the
  `.jfif` or `.jpe` extension are now copied with EPUB resources and safely
  served to the browser. `.jfif` files are returned as `image/jpeg`, avoiding
  platform-specific MIME-type gaps that could prevent covers from displaying.

### Upgrade notes

- No SQLite migration or source-EPUB change is required. Restart the Server or
  wait for the next library scan; an older cache with a missing cover is marked
  invalid and only the affected book is reconverted.
