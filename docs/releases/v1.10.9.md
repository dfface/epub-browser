# EPUB Browser v1.10.9

发布日期 / Release date: 2026-08-17

## 中文

这是一个恢复目录自动监控可靠性的维护版本。

### 修复

- **Watch 模式不再在文件事件后卡死**：修复了 `--watch` 处理快速完成的 EPUB 导入任务时可能发生的死锁。监控器现在会继续响应后续的新建、修改、移动和删除事件。
- **连续更新更稳定**：旧任务完成时不再误删同一路径上较新任务的跟踪状态，降低密集文件变更下漏处理的风险。
- **监控可正常停止**：关闭服务时，watchdog 事件线程可以正常退出，不再因上述死锁阻塞停机。

### 兼容性

命令行参数和监控行为保持不变，无需迁移或额外配置。

## English

This maintenance release restores reliable automatic directory monitoring.

### Fixes

- **Watch mode no longer stalls after a file event**: Fixed a deadlock that could occur when `--watch` handled an EPUB import task that completed quickly. The watcher now continues responding to later create, modify, move, and delete events.
- **Back-to-back updates are tracked reliably**: An older task completing can no longer remove the tracking state for a newer task on the same path, reducing the risk of missed work during rapid file changes.
- **Clean watcher shutdown**: The watchdog event thread can exit normally when the service stops instead of being held open by the deadlock.

### Compatibility

Command-line options and watch behavior are unchanged. No migration or additional configuration is required.
