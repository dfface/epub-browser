# v2.18.0

先看升级：Server 的 EPUB 内容缓存从 v11 升到 v12。升级重启后会自动重转 EPUB，确认源书还在监控目录里。PDF 不用动。

## 新增

- 移动端底部工具栏的按钮可以自己排序了。在设置里拖动按钮或点箭头调整位置，一键可以恢复默认。顺序按浏览器保存，只影响当前站点。另外新增了「滚动时保持工具栏可见」开关，默认仍然是下滑收起、上滑出现。
- 阅读设置多了几个开关：本章大纲按钮（默认开，关掉不影响整本书的目录）、桌面目录侧栏的显示和自动隐藏、文本对齐、图片笔记入口、阅读进度条。关掉图片笔记入口后，已有的笔记标记还会显示。

## 修复

- EPUB 里的内部链接改成按 spine 解析，不再靠文件名猜章节。跨章节链接、锚点跳转、目录里指向纯数字文件名的链接都能正常打开，同名章节也不会串到别处。
- 书籍页和阅读器里的目录保留原始层级，多级嵌套能看出缩进。
- 书架按钮的文案现在会跟着语言切换更新。

## 升级

- Server：部署重启后会自动重转 EPUB（v11 → v12），源 EPUB 要留在监控目录。重转期间相关章节可能短暂不可用。建议先备份 `data/`。
- SSG：重新生成并发布整站，静态输出里有新的 `mobile-toolbar.js` 和翻译文案。
- 浏览器里已经保存的偏好不会丢，新开关按各自默认值生效。

## English

Upgrade first: the Server EPUB content cache moves from v11 to v12. After restarting, EPUBs are reconverted automatically, so keep the source books in the watched directory. PDFs are unaffected.

### Added

- Buttons in the mobile bottom toolbar can be reordered. Drag them or use the arrows in settings, and restore the default order with one click. The order is saved per browser for this site. A new switch keeps the toolbar visible while scrolling; by default it still hides on scroll-down and returns on scroll-up.
- Reading settings gain a few switches: the chapter outline button (on by default; turning it off leaves the full book contents alone), the desktop contents sidebar and its auto-hide behavior, text alignment, image-note buttons, and the reading progress bar. Existing image-note markers stay visible when that switch is off.

### Fixed

- EPUB internal links now resolve through the spine instead of guessing from file names. Cross-chapter links, anchors, and contents links to numeric file names work, and chapters with the same file name no longer collide.
- The book page and reader keep the original TOC hierarchy, so nested sections stay distinguishable.
- Bookshelf button labels now follow locale changes without a reload.

### Upgrade

- Server: EPUBs are reconverted automatically after restart (v11 → v12). Keep source EPUBs in the watched directory; chapters may be briefly unavailable during reconversion. Back up `data/` first.
- SSG: regenerate and republish the static site to pick up the new `mobile-toolbar.js` and translation bundles.
- Preferences already saved in the browser are kept; new switches take their defaults.
