# v2.18.0

## 新功能

- **移动端工具栏自定义（#83）**：底部工具栏按钮可拖拽或使用箭头调整顺序，并可一键恢复默认；顺序保存在当前浏览器，对该站点所有书籍生效，暂时不可用的按钮仍保留其保存位置。可设置滚动时保持底部工具栏可见：关闭后下滑隐藏、上滑显示；顶部与「书籍首页」按钮位置固定。
- **阅读设置扩展（#82、#83）**：新增「本章大纲」按钮开关（默认开），关闭后隐藏按钮并关闭抽屉，不影响书籍目录，连续滚动与 PDF 页面不适用。新增桌面目录侧边栏开关及自动隐藏（鼠标移到左边缘或按 Tab 唤出）、文本对齐（左 / 右 / 居中 / 两端）、图片笔记按钮开关（关闭后已有标记仍可见）和阅读进度条开关。相关文案覆盖 17 种语言。

## 修复

- **EPUB 内部链接按 spine 解析（#80）**：章节链接现在解析为完整归档路径对应的 `chapter_N.html`，覆盖不在目录中的章节并避免同名文件冲突；修复跨章节链接与 fragment 导航、纯数字目录链接，网站 URL 不再被当作 EPUB 内部路径改写。
- **保留源目录层级（#81）**：书籍页与章节阅读器的目录按源文档层级缩进，各级深度保持可区分；嵌套导航在 SSG 与 Server 两种模式下都保留。
- 书架按钮补齐 `aria-pressed` 与 `data-i18n`，语言切换时书架状态文案可原地更新。
- 修正部分发布者样式：正文的 body margin 不再把内容推出阅读卡片。

### 影响范围

- 阅读器自定义与目录渲染覆盖 SSG 与 Server；EPUB 链接修复在 SSG 与 Server 两种模式下均生效。
- **EPUB Server 内容缓存修订升级为 `server-content-v12`**（链接目标按 spine 解析、body 锚点 ID 修正）；旧 `content/` 缓存不再兼容，需要重建。PDF 缓存修订仍为 `server-pdf-v2`，无需重转。
- 工具栏顺序、章节大纲等偏好保存在浏览器本地；文本对齐、图片笔记与进度条为阅读设置。无新增服务端 API、CLI 参数或数据库迁移。

### 升级说明

- Server：部署并重启后，协调器检测到 EPUB 缓存修订由 v11 变为 v12，会自动按新修订重新转换 EPUB（需保留源 EPUB 文件）；重转完成前相关章节可能暂时不可用。PDF 无需重转。建议升级前备份 `data/` 与源书。
- SSG：需重新生成并整站发布静态输出，以应用 spine 解析后的链接、目录层级、新增的 `mobile-toolbar.js`、阅读设置与 17 语言文案。
- 浏览器中已保存的偏好（工具栏顺序、大纲开关等）会保留；新设置按各自默认值生效。

## Features

- **Customizable mobile toolbar (#83)**: Buttons in the bottom toolbar can be reordered by dragging or with arrow controls and restored to the default order with one action. The order is saved in the current browser for every book on the site, and buttons that are unavailable keep their saved positions. A new setting keeps the bottom toolbar visible while scrolling; when off, scrolling down hides it and scrolling up reveals it. Top and Book home stay in place.
- **Expanded reading settings (#82, #83)**: A new "Show chapter outline button" switch (on by default) hides the button and closes the drawer without affecting the book contents; it does not apply in continuous-scroll mode or on PDF pages. The book-contents sidebar can now be toggled and auto-hidden (revealed by hovering the left edge or pressing Tab). Text alignment (left / right / center / justify), an image-note button switch (existing markers stay visible) and a reading-progress-bar switch were added. All new copy ships in 17 locales.

## Fixes

- **Resolve EPUB internal links through the spine (#80)**: Chapter links now resolve to `chapter_N.html` via the full archive path, covering chapters absent from the TOC and avoiding basename collisions. Cross-chapter links and fragment navigation, contents links to numeric sibling files, and archive paths with encoded spaces were fixed. Website URLs are no longer mistaken for EPUB-internal paths.
- **Preserve source TOC hierarchy (#81)**: The book page and chapter reader indent contents according to the source hierarchy so every depth stays distinguishable. Nested source navigation is retained in both SSG and Server.
- Shelf buttons now expose `aria-pressed` and `data-i18n`, so locale switches update their labels in place.
- Publisher body margins no longer push reader content outside the reading card.

### Affected scope

- Reader customization and contents rendering cover SSG and Server; the EPUB link fixes apply in both modes.
- **The EPUB Server content cache revision is now `server-content-v12`** (spine-resolved link targets and corrected body anchor IDs). The old `content/` caches are incompatible and must be rebuilt. The PDF cache revision remains `server-pdf-v2`, with no reconversion needed for PDFs.
- Toolbar order and chapter-outline preferences live in browser-local storage; text alignment, image notes and the progress bar are reading settings. No new server API, CLI flag or database migration was added.

### Upgrade notes

- Server: after deploying and restarting, the reconciler detects the EPUB cache revision change from v11 to v12 and automatically reconverts EPUBs under the new revision; keep the source EPUBs available. Chapters may be temporarily unavailable until reconversion finishes. PDFs need no reconversion. Back up `data/` and your source books before upgrading.
- SSG: regenerate and republish the full static output to pick up spine-resolved links, TOC hierarchy, the new `mobile-toolbar.js`, reading settings and the 17 locale bundles.
- Preferences already saved in the browser (toolbar order, outline switch, etc.) are preserved; new settings take their documented defaults.
