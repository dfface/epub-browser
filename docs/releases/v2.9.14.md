# v2.9.14

## 修复 / Fixes

### 中文

- **书籍 `:root` 自定义属性污染应用外壳（#33）**：修复书籍章节 CSS 中 `:root` / `html` / `body` 的自定义属性（如 `--accent`、`--border`、`--code-bg`）被错误地映射到 `[data-eb-styles]:root` 这种匹配不到的死选择器，导致这些变量既不作用于书本内容、又会在与应用同名时意外覆盖应用外壳（工具栏、边框、强调色）的问题。现在它们被限定到内容容器 `[data-eb-styles]`，`var(--code-bg)` 等在内容区域内正确解析，应用外壳不再被书籍配色污染。
- **书籍暗色调跟随阅读器开关而非系统（#33）**：修复书籍 `@media (prefers-color-scheme: dark)` 原样保留、使其暗色调按**操作系统**偏好生效——即使阅读器处于浅色模式、只要系统设了暗色，书籍暗色调也会套用的问题。现在该媒体块被**改写**为 `.dark-mode [data-eb-styles] { … }` 并丢弃原 `@media` 外壳，书籍暗色调只跟随阅读器的 `.dark-mode` 开关。
- **CSS 解析器改为花括号感知的递归实现**：替换此前脆弱的扁平正则解析器，正确处理 `@media { :root { … } }` 这类嵌套块，避免内部 `:root` 未被作用域化的既有缺陷。

### English

- **Book `:root` custom properties leaked into the app chrome (#33)**: Fixed book chapter CSS where `:root` / `html` / `body` custom properties (e.g. `--accent`, `--border`, `--code-bg`) were mapped to a non-matching dead selector `[data-eb-styles]:root`. This meant the variables neither applied to the book content nor, when sharing a name with the app, accidentally overrode the application chrome (toolbar, borders, accent color). They are now scoped to the content container `[data-eb-styles]`, so `var(--code-bg)` etc. resolve correctly inside the content and the app chrome is no longer recolored by the book.
- **Book dark palette follows the reader toggle, not the OS (#33)**: Fixed the issue where the book's `@media (prefers-color-scheme: dark)` was preserved verbatim, so its dark palette applied according to the **operating system** preference — even when the reader was in light mode, as long as the OS was dark. The media block is now **rewritten** to `.dark-mode [data-eb-styles] { … }` and the original `@media` wrapper is dropped, so the book dark palette follows only the reader's `.dark-mode` toggle.
- **Brace-aware recursive CSS scoper**: Replaced the previous fragile flat-regex parser so nested blocks such as `@media { :root { … } }` are handled correctly, fixing a pre-existing defect where the inner `:root` was left unscoped.

## 影响范围 / Affected scope

### 中文

- 仅改动 `epub_browser/assets/chapter.js`（阅读器共享静态资源，EPUB/PDF、SSG/Server 共用）。
- 新增 `tests/test_scope_css.js`（Node 单测）。
- 不影响内容缓存修订，无需重新转码书籍。
- 已知边界：书籍暗色调目前仅映射到阅读器的 `.dark-mode`（暗色主题）；sepia / forest / ocean 等非暗色主题下不会套用书籍暗色调。

### English

- Only `epub_browser/assets/chapter.js` is changed (shared reader static asset, used by both EPUB/PDF and the SSG/Server).
- Added `tests/test_scope_css.js` (Node unit test).
- No content-cache revision is affected, so books do not need to be re-transcoded.
- Known boundary: the book dark palette is currently mapped only to the reader's `.dark-mode` (dark theme); sepia / forest / ocean and other non-dark themes will not apply the book dark palette.
