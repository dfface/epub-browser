# EPUB Browser v1.11.1

发布日期 / Release date: 2026-08-18

## 中文

这是一个让版本信息更清晰、升级路径更直接的维护版本。

### 新功能

- **Footer 版本号**：书库、书籍首页和章节页现在都会显示当前 EPUB Browser 版本，方便确认正在使用的版本。
- **GitHub 更新提醒**：浏览器能够连接 GitHub 时，会检查最新稳定版；如有更高版本，footer 会显示可点击的更新链接，直接打开对应 Release 页面。

### 改进与兼容性

- **离线不受影响**：网络不可用、请求超时或 GitHub 暂时不可访问时，阅读和书库功能保持正常，footer 只显示当前版本。
- **减少重复检查**：成功的更新检查结果会在浏览器中缓存 6 小时，避免频繁请求 GitHub。
- 无需迁移或额外配置。

## English

This maintenance release makes the installed version clearer and the upgrade path easier to find.

### New Features

- **Footer version**: The library, book home, and chapter pages now show the current EPUB Browser version, making it easy to confirm what you are running.
- **GitHub update notice**: When the browser can reach GitHub, it checks the latest stable release. If a newer version is available, the footer provides a clickable link to that release.

### Improvements and Compatibility

- **Offline-safe behavior**: Reading and library features continue normally when the network is unavailable, a request times out, or GitHub cannot be reached; the footer simply shows the current version.
- **Fewer repeated checks**: Successful update checks are cached in the browser for six hours to avoid unnecessary GitHub requests.
- No migration or additional configuration is required.
