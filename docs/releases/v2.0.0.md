# EPUB Browser v2.0.0

发布日期 / Release date: 2026-08-18

## 中文

v2.0.0 将 EPUB Browser 明确拆分为两个产品模式，并重新定义了运行时数据边界。

### 主要变化

- 新增顶层命令 `epub-browser ssg`：事务式生成可直接部署的静态站点，支持 `--base-path`，产物不包含数据库或 Server 状态。
- 新增顶层命令 `epub-browser server`：使用独立的持久化 `data/` 和可重建的 `cache/`，默认只监听 `127.0.0.1`。
- Server 为书籍维护持久 ID，并对未变化的 EPUB 复用缓存；删除缓存不会删除标注、书架同步记录或阅读进度。
- v1 根目录数据库会在首次持久 Server 启动时自动校验、备份、升级和迁移。旧书籍 ID、标注、书架及阅读进度会尽可能保持不变。
- 旧命令语法在整个 v2 主版本期间继续兼容，并映射到 `ssg` 或 `server`；加 `--log` 可查看等价的新命令。
- 默认 CLI 输出保持安静，避免打乱 tqdm 进度；`--log` 才输出运行细节，错误始终可见。
- Docker 镜像现在使用持久 Server 模式，明确区分只读 EPUB 输入、读写 Server 数据和可选的旧 JSON 导入目录。

### 兼容性说明

- 这是主版本升级：自动迁移前仍建议备份完整的旧输出目录。
- Python 最低版本提升为 3.9。
- 书架交互逻辑不变：默认保存在浏览器中，用户点击现有 Sync 后才会写入同步数据库。
- 请阅读 [v2 迁移指南](../migration-v2.md)，特别是数据库冲突、备份和回滚章节。

## English

v2.0.0 makes EPUB Browser's two product modes explicit and establishes strict runtime data boundaries.

### Highlights

- `epub-browser ssg` transactionally generates a directly deployable static site, supports `--base-path`, and emits no database or Server state.
- `epub-browser server` separates durable `data/` from replaceable `cache/` and binds to `127.0.0.1` by default.
- Server keeps durable book IDs and reuses unchanged conversions. Deleting the cache does not delete annotations, synchronized bookshelf rows, or reading progress.
- Persistent first startup verifies, backs up, upgrades, and migrates a v1 root database. Legacy book IDs and user data are preserved whenever they can be correlated safely.
- v1 command syntax remains supported for the full v2 major line and maps to `ssg` or `server`; `--log` shows the equivalent new command.
- Normal CLI output stays quiet so tqdm progress remains intact. Operational detail requires `--log`, while errors remain visible.
- The Docker image now runs persistent Server mode and documents separate read-only EPUB input, read-write Server state, and optional legacy JSON import mounts.

### Compatibility

- This is a major release. Back up the complete v1 output directory before relying on automatic migration.
- The minimum Python version is now 3.9.
- Bookshelf interaction is unchanged: it is browser-local until the existing manual Sync action is used.
- Read the [v2 migration guide](../migration-v2.md) for database conflicts, backup locations, and rollback.
