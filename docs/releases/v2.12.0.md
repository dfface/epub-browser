# v2.12.0

## 新功能

- **本书阅读统计（#29，仅 Server）**：从 EPUB 或 PDF 的书籍页、阅读页，或书库的阅读时长排行进入，查看累计阅读时长、首次和最近阅读时间、标注数。从排行返回会恢复之前的统计区间。
- **阅读洞察改版（#23、#29，仅 Server）**：总览、日、周、月使用统一的卡片顺序。热力图可直接打开当天的阅读记录，趋势图按时间粒度显示指标，区间阅读书数按书籍去重。管理员可在「一般设置」调整排行展示数量，默认 10 本。新增界面文案覆盖 17 种语言。
- **Kindle 屏保时区（#49，仅 Server）**：可在账户设置中为 Kindle 屏保选择时区，时钟、月历和日程会按所选时区显示。未指定时使用设备本地时间。

## 修复

- **弱网下的阅读洞察（#23）**：首屏只加载汇总、图表和排行。当天的阅读会话按需分页请求。服务端压缩响应，并按账户和数据版本缓存汇总。请求失败时可在界面重试。
- **PDF 内嵌 ID 写入失败**：如果 PDF 无法安全写入且源文件未发生变化，会把同一个书籍 ID 保存到相邻的 sidecar 文件。签名或加密的 PDF 也适用。

### 升级说明

- Server 启动时自动将 SQLite 数据库升级到版本 28，并保留现有设置。升级前请备份服务器的 `data/` 目录，回退到旧版本时需恢复升级前的数据库。
- EPUB 和 PDF 内容缓存修订未变。Server 部署并重启即可使用新的阅读洞察。SSG 用户可用新版本重新生成静态站点以应用 PDF ID 修复。

## Features

- **Book reading stats (#29, Server only)**. Open the report from an EPUB or PDF book or chapter page, or from the library’s reading time ranking. See active reading time, first and last read, and annotation count. Returning from a ranked book restores the previous date range.
- **Updated Reading Insights (#23, #29, Server only)**. Cards follow the same order across Overview, Day, Week, and Month. Select a square in the activity calendar to open that day. Trend titles reflect the period and metric, and book totals count each book once per range. Administrators can set the ranking size in General settings. The default is 10 books. New UI copy ships in all 17 locales.
- **Kindle screensaver time zone (#49, Server only)**. Choose a time zone in account settings to display the screensaver clock, calendar, and agenda in that zone. The default uses the device’s local time.

## Fixes

- **Reading Insights on slow connections (#23)**. The initial response contains summaries, charts, and rankings. Daily sessions load on demand in pages. The server compresses responses and caches summaries by account and data revision. Failed requests can be retried from the report.
- **Failed embedded PDF ID writes**. If an ID cannot be embedded safely and the PDF has not changed, the app saves the same ID in an adjacent sidecar. This also applies to signed or encrypted PDFs.

### Upgrade notes

- Server upgrades its SQLite database to schema 28 automatically and preserves existing settings. Back up the Server `data/` directory before upgrading. Restoring the pre-upgrade database is required to roll back to an older release.
- EPUB and PDF cache revisions stay the same. Deploy and restart Server to use the updated reports. SSG users can regenerate their static site with this release to pick up the PDF ID fix.
