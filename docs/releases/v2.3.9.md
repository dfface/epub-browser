# EPUB Browser v2.3.9 — Smaller Docker deployments

发布日期 / Release date: 2026-08-25

## 中文

v2.3.9 缩小了 Server 部署所需的 Docker 镜像和构建输入，让拉取、构建和更新更轻快；阅读器、书库和 AI 阅读的功能保持不变。

### 改进

- **更小的 Docker 镜像**：运行时从 Debian slim 切换到 Alpine，并跳过安装时生成的 Python bytecode。常见的本机构建体积显著降低，部署到新机器时需要传输的数据更少。
- **更快、更稳定的构建输入**：Docker 构建现在只复制生成应用 wheel 所需的文件，并排除示例 EPUB、测试、文档及本地开发状态。这些与运行无关的变动不会再使镜像构建失去缓存。
- **保留跨平台部署能力**：Linux arm64 与 amd64 均按相同 Dockerfile 构建，服务所需的 Python 原生依赖仍随镜像安装。

### 升级说明

- 使用 Docker Compose 的部署请执行 `docker compose up -d --build`；使用已发布镜像的部署请拉取 `v2.3.9` 或 `latest` 后重建容器。
- 无需 SQLite migration、无需重新转换 EPUB，也无需提高 Server EPUB 内容缓存修订。

## English

v2.3.9 makes Server Docker deployments smaller and lighter to build, pull, and update. Reader, library, and AI-reading functionality are unchanged.

### Improvements

- **Smaller Docker image**: The runtime moves from Debian slim to Alpine and skips installation-time Python bytecode. Typical local builds are substantially smaller, so new deployments transfer less data.
- **Faster, more reliable build inputs**: Docker now copies only the files required to build the application wheel and excludes sample EPUBs, tests, documentation, and local development state. Unrelated changes no longer discard the image build cache.
- **Cross-platform deployment retained**: The same Dockerfile builds for Linux arm64 and amd64, while the Python native dependencies needed by the service remain included in the image.

### Upgrade notes

- For Docker Compose deployments, run `docker compose up -d --build`. For published images, pull `v2.3.9` or `latest` and recreate the container.
- No SQLite migration, EPUB reconversion, or Server EPUB-content-cache revision is required.
