# v2.11.0

## 新功能

- **PDF 稳定 ID 可写入文档内（#41）**：`--book-id-storage=embedded` 现在对 PDF 生效，转换前通过增量更新把 ID 写入 PDF 文档信息字典；SSG 与 Server 均交付写入 ID 后源文件的逐字节副本。默认的 `sidecar` 行为不变（相邻 JSON 文件，不改动源文件）。切换存储模式会沿用既有 ID，书籍 URL、标注与阅读进度保持不变。签名或加密的 PDF 必须使用 `sidecar`；不安全或不可写的目标会被拒绝并停止处理该书。
- **Kindle 个人屏保仪表盘（#16、#19，仅 Server）**：启用 `--kindle` 后可从 `/kindle`、`/kindle/screensaver` 或账户设置进入，展示实时时钟、月历、未来 7 天日程（最多 8 个 HTTPS/`webcal` 日历订阅，服务端限制下载大小、事件数与超时并校验地址）、仅本人可见的 4000 字备忘录和番茄钟，同时显示最近阅读与书架。页面和设置接口需登录；PAT 新增 `kindle-memo:read`、`kindle-memo:write` 两个 scope，并提供 `/api/v1/me/kindle-memo` 读写接口与 OpenAPI 文档。新增 17 种语言文案，切换语言无需刷新。
- **Kindle 极简阅读改进（#16）**：书架加入封面、搜索与分页，Server 端按账户读取最近阅读与阅读进度（SSG 仍使用本地 Cookie 进度）；书籍行可直接续读对应章节。
- **阅读时预取下一章（#46）**：章节渲染完成后在浏览器空闲时仅预取「当前 +1」章，结果只保留一份内存 HTML，切到该章时一次性消费；重复渲染去重、换章取消在途请求、最后一章与连续滚动模式跳过，失败时静默回退正常加载。适用于 EPUB 与 PDF 的共享章节页，SSG 与 Server 均生效；Kindle 极简页面不受影响。

## 修复

- 表格内文字的高亮标注不再因包裹 `span` 破坏表格结构；回放校验同时接受原始引文与实际可绘制文本。
- SSG Service Worker 写入缓存失败时不再产生未处理的 Promise 拒绝。
- 移除 Kindle 极简书籍页底部的「Open full reader」链接及相关样式。

### 影响范围

- PDF ID 存储、章节预取、标注高亮修复同时覆盖 SSG 与 Server（EPUB / PDF）。
- Kindle 屏保仪表盘、账户设置、新增 Session / PAT 接口与 SQLite 自动迁移均为 Server 专属；SSG 不输出仪表盘，也不依赖 `/api/*` 或登录态。
- 本次仅涉及页面、资源、i18n 与身份载体，EPUB `content/` 与 PDF 缓存修订均未改变。

### 升级说明

- Server：部署新版本并重启即可生效，无需重新转换 EPUB 或 PDF。启动时自动创建 `kindle_screensavers` 表并将 `user_version` 推进到 26，无需手工 SQL；升级前建议备份源书与 `data/`。
- 若使用 `--book-id-storage=embedded`（Docker 镜像与 Compose 默认值），升级后首次扫描会向源 PDF 写入 ID，源字节变化会触发这些 PDF 的缓存完整刷新一次，`book_id` 与阅读数据不变。签名/加密 PDF 或只读挂载的书库请改用 `sidecar`。
- SSG：需重新生成并整站发布静态输出（新增 `chapter-prefetch.js` 等哈希资源、Kindle 模板与 i18n 包）。
- 无破坏性变更：CLI 默认值（`sidecar`）、既有 URL、API 形状与 PAT 均保持兼容。

## Features

- **Stable PDF IDs can be embedded in the document (#41)**: `--book-id-storage=embedded` now applies to PDFs. Before conversion, an incremental update writes the ID into the PDF document information dictionary, and both SSG and Server deliver a byte-for-byte copy of the updated source. The default `sidecar` behavior is unchanged (an adjacent JSON file, with source bytes untouched). Switching carriers keeps the existing ID, so book URLs, annotations and reading progress stay stable. Signed or encrypted PDFs must use `sidecar`; unsafe or unwritable targets are refused and stop that book.
- **Personal Kindle screensaver dashboard (#16, #19, Server only)**: With `--kindle`, `/kindle`, `/kindle/screensaver` and Account settings open a dashboard with a live clock, month calendar, a 7-day agenda from up to eight HTTPS/`webcal` iCalendar subscriptions (with server-side download size, event count, timeout and SSRF safeguards), a private 4,000-character memo and a Pomodoro timer, alongside recent reading and the bookshelf. Pages and settings require a session login. PATs gain the `kindle-memo:read` and `kindle-memo:write` scopes with `/api/v1/me/kindle-memo` GET/PUT operations and OpenAPI documentation. New copy ships in all 17 locales and switches in place without a reload.
- **Improved minimal Kindle reading (#16)**: The bookshelf gains covers, search and pagination, and Server builds it from account-scoped recent reading and progress (SSG still uses local Cookie progress). Book rows can resume the matching chapter directly.
- **Prefetch the next chapter while reading (#46)**: After a chapter renders, the browser prefetches only the immediately next chapter during idle time and keeps a single in-memory HTML string, consumed once when the reader switches to it. Repeat renders are deduplicated, in-flight requests are cancelled on chapter changes, the last chapter and continuous-scroll mode are skipped, and failures fall back silently to normal loading. This applies to shared EPUB and PDF chapter pages in both SSG and Server; minimal Kindle pages are unaffected.

## Fixes

- Highlights over table text no longer wrap structural table nodes in `span` elements, which could break table layout; replay validation now accepts both the original quote and the text the painter could actually mark.
- A failed Cache Storage write in the SSG Service Worker no longer produces an unhandled Promise rejection.
- Removed the "Open full reader" link and its styles from minimal Kindle book pages.

### Affected scope

- PDF ID storage, chapter prefetch and the table-highlight fix cover both SSG and Server, for EPUB and PDF.
- The screensaver dashboard, account settings, new Session/PAT endpoints and the automatic SQLite migration are Server-only. SSG emits no dashboard widgets and depends on neither `/api/*` nor login state.
- This release changes pages, assets, i18n and identity carriers only; neither the EPUB `content/` nor the PDF cache revision changed.

### Upgrade notes

- Server: deploy and restart to pick up the release; no EPUB or PDF reconversion is needed. Startup automatically creates the `kindle_screensavers` table and advances `user_version` to 26, with no manual SQL. Back up source books and `data/` before upgrading.
- With `--book-id-storage=embedded` (the Docker image and Compose default), the first scan after upgrading writes IDs into source PDFs, so those books refresh their PDF cache once. The `book_id` and reading data are unchanged. Signed/encrypted PDFs and read-only library mounts should use `sidecar`.
- SSG: regenerate and republish the full static output (new hashed assets such as `chapter-prefetch.js`, Kindle templates and locale bundles).
- No breaking changes: CLI defaults (`sidecar`), existing URLs, API shapes and PATs remain compatible.
