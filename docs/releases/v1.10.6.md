# EPUB Browser v1.10.6

发布日期 / Release date: 2026-08-12

## 中文

这是一个完善阅读进度目录呈现的维护版本。

### 改进

- **目录中清晰标记同步进度**：Book 页会在当前阅读章节的标题旁显示 `Cloud sync · 用户名`；未设置用户名时，显示与 Annotation 一致的 `Cloud sync · shared`。
- **继续阅读状态更易识别**：目录中的当前章节、Continue Reading 按钮与服务端同步的章节保持一致，方便从书籍目录恢复阅读。
- **更稳健的身份显示**：修复某些本地进度场景显示 `undefined` 的问题；目录标签始终显示有效身份。
- **目录布局更稳定**：同步标签紧随章节标题，长标题会在标签前截断；右侧 `chapter_xxx.html` 文件名保持右对齐、不换行，并与标签保留适当间距。

### 兼容性

章节同步仍仅在 server 模式可用。静态 Pages 构建继续保存浏览器本地阅读位置，但不提供服务端章节同步 API。

## English

This maintenance release refines how reading progress appears in the table of contents.

### Improvements

- **Clear synced-progress marker in the TOC**: The Book page now labels the current synced chapter beside its title as `Cloud sync · username`; when no username is configured, it uses `Cloud sync · shared`, consistent with Annotations.
- **Easier resume state recognition**: The active TOC chapter, Continue Reading button, and server-synced chapter now stay aligned, making it easier to resume from a book's contents page.
- **More robust identity display**: Fixed cases where locally restored progress could display `undefined`; the marker now always has a valid identity.
- **More stable TOC layout**: The marker sits beside the chapter title, long titles truncate before it, and the right-aligned `chapter_xxx.html` filename remains on one line with deliberate spacing.

### Compatibility

Chapter synchronization remains available in server mode only. Static Pages builds continue to retain browser-local reading positions, but do not provide the server-side reading-progress API.
