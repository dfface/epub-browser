# v2.9.13

## 修复 / Fixes

### 中文

- **代码块逐 token 换行（#31）**：修复 O'Reilly 等出版商把一行代码拆成多个内联 `<code>`（逐 token 拆分）时，每个 token 独占一行、代码块被撑成几十行的问题。现在保留出版商自带的 token 类与配色，将其渲染为单一连续的代码块。
- **浅色 / 暗色模式代码“无高亮”**：修复通用的代码高亮被压平成正文色的问题——`chapter.css` 中浅色与暗色模式把字符串、标识符、内置名等以 `!important` 压平成正文色（暗色模式下还会被全局反转规则进一步压制），导致 Python 这类代码看起来没有语法高亮。现在改用 github 浅色 / 暗色主题配色（暗色模式以更高特异性的 `!important` 胜出全局反转规则）。

### English

- **Code blocks wrapping line-by-line per token (#31)**: Fixed the issue where publishers such as O'Reilly split a single line of code into multiple inline `<code>` elements (one per token), causing each token to occupy its own line and the block to stretch across dozens of lines. The publisher's own token classes and colors are now preserved and rendered as a single continuous code block.
- **No syntax highlighting in light / dark mode**: Fixed a general problem where code highlighting was flattened to the body text color. In `chapter.css`, both light and dark mode rules used `!important` to flatten strings, identifiers, built-ins, etc. into the body text color (in dark mode this was further overridden by a global inversion rule), making languages like Python look unhighlighted. The block now uses the github light / dark theme palette (in dark mode a higher-specificity `!important` rule wins over the global inversion rule).

## 影响范围 / Affected scope

### 中文

- 仅改动 `epub_browser/assets/chapter.css` 与 `epub_browser/assets/chapter.js`（阅读器共享静态资源，EPUB/PDF、SSG/Server 共用）。
- 不影响内容缓存修订，无需重新转码书籍。

### English

- Only `epub_browser/assets/chapter.css` and `epub_browser/assets/chapter.js` are changed (shared reader static assets, used by both EPUB/PDF and the SSG/Server).
- No content-cache revision is affected, so books do not need to be re-transcoded.

## 升级说明 / Upgrade notes

### 中文

- 无需额外操作；重新构建或重新部署应用即可生效。
- 该修复同时覆盖普通代码块与出版商逐 token 拆分的代码块（如 O'Reilly 书籍）。

### English

- No extra steps required; simply rebuild or redeploy the application.
- The fix covers both ordinary code blocks and publisher token-split code blocks (e.g. O'Reilly books).
