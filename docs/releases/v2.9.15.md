# v2.9.15

## 修复 / Fixes

### 中文

- **阅读器字号调节对所有 EPUB 生效（#35）**：修复部分 EPUB 在 `font-size` 等属性上使用 `pt`/`px` 等固定单位（或相对文档根的 `rem`），导致阅读器顶栏的「字号」滑块对其无效的问题。现在清洗期会把影响字号的 `px`/`pt`/`rem`/`%` 统一转换为相对内容容器的 `em`，使字号滑块真正缩放每一本书。
- **仅缩放排版相关属性**：转换只作用于 `font-size` / `line-height` / `letter-spacing` / `word-spacing`；边框、外边距、宽度、图片等布局关键属性保持原单位不变，避免版式错位。
- **保留既有语义与鲁棒性**：保留 `!important`；跳过 `calc()` / `var()` / `clamp()` 与 `ex`/`ch`/`vw` 等 exotic 单位；遇到畸形 CSS 不会中断整段转换。
- **阅读器自带内容排版同步改用 `em`**：`#eb-content pre` / `pre code` 改为 `em`，并清理两处从未生效的死注释块（被未闭合注释吞掉的真实规则）。

### English

- **Reader font-size control now affects every EPUB (#35)**: Fixed books that used fixed units (`pt`/`px`) or document-root-relative `rem` on font-size-related properties, which ignored the reader's font-size slider. The sanitizer now converts `px`/`pt`/`rem`/`%` that affect font size to `em` relative to the content container, so the slider truly scales every book.
- **Only typographic properties are scaled**: The conversion applies only to `font-size` / `line-height` / `letter-spacing` / `word-spacing`; layout-critical properties (borders, margins, widths, images) keep their original units to avoid reflow breakage.
- **Preserves existing semantics and is robust**: `!important` is preserved; `calc()` / `var()` / `clamp()` and exotic units (`ex`/`ch`/`vw`) are skipped; malformed CSS does not abort the whole conversion.
- **Reader's own content typography also switches to `em`**: `#eb-content pre` / `pre code` now use `em`, and two never-active dead comment blocks (real rules swallowed by unclosed comments) were removed.
