# EPUB Browser v2.3.12 — 更可靠的按需界面加载

发布日期 / Release date: 2026-08-25

## 中文

v2.3.12 修复了按需加载的导航与 AI 阅读界面在慢网络或书库更新期间可能出现的瞬态布局问题，并让书库增量刷新更可靠。

### 修复

- **按需导航保持在原位加载**：首次打开书架、标注汇总或 AI 阅读汇总时，按钮会显示本地化的加载状态并阻止重复触发。相应 CSS 完成绘制后才创建并打开界面，不会再把未样式化的内容短暂插入页面底部。
- **本章总览资源就绪后再显示**：AI 阅读画布、思维导图和 KaTeX 相关样式会在实际绘制完成后启用。本章总览不会因延迟样式而闪烁或以未样式状态插入正文。
- **书库不会在刷新后重复卡片**：修复目录更新恰好打断大书库分批渲染时，旧渲染任务仍追加卡片的问题；客户端也会防御性合并指向同一书籍 URL 的重复元数据条目。

### 升级说明

- 无需 SQLite migration、无需重新转换 EPUB，也无需提高 Server EPUB 内容缓存修订。
- Server 部署更新并重启后即可生效；SSG 部署请重新生成并完整发布输出目录，以便新的哈希资源一同上线。

## English

v2.3.12 fixes transient layout issues that could occur while on-demand navigation and AI-reading UI loaded on slow connections or during catalog updates, and makes incremental Library refreshes more reliable.

### Fixes

- **Deferred navigation stays in place while loading**: On first use, Shelf, Annotations, and AI Readings now show a localized loading state and ignore repeat activation. Their interfaces are created and opened only after CSS has painted, preventing unstyled content from briefly entering document flow at page bottom.
- **Chapter Overview waits for its resources**: AI-reading canvas, mind-map, and KaTeX styles are enabled after they have painted. Chapter Overview no longer flashes or inserts unstyled content into the reading body while styles are delayed.
- **Library cards no longer duplicate after refresh**: Fixed an issue where a catalog update could interrupt batched rendering of a large Library, allowing a stale batch to append cards after the refreshed list. The client also defensively merges duplicate metadata entries that point to the same book URL.

### Upgrade notes

- No SQLite migration, EPUB reconversion, or Server EPUB-content-cache revision is required.
- Restart an updated Server deployment to apply the change. For SSG deployments, regenerate and publish the complete output directory so the new hashed assets are available together.
