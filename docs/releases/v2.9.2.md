# EPUB Browser v2.9.2 — 紧急修复 AI 阅读标记导致的页面卡死

发布日期 / Release date: 2026-08-30

## 中文

v2.9.2 是一个紧急稳定性补丁，修复“AI 阅读标记按当前语言显示”功能可能让 EPUB Book 页面和章节目录完全卡死的问题，并降低目录标记接口的响应体积。本版本还修复了并行打开登录页时偶发的 403、登录页 favicon 缺失和重复 CSP 指令警告。

### 严重问题与影响范围

- **受影响版本**：v2.8.1 至 v2.9.1。
- **受影响页面**：仅 Server 部署中的 EPUB Book 页面及 EPUB 章节页目录抽屉。
- **触发条件**：当前界面语言下至少存在一个章节级 AI 阅读结果。标记插入目录后，外层 `MutationObserver` 会因标签文本被重复写入而持续触发自身，耗尽浏览器主线程，使页面无法响应。
- **不受影响**：SSG 输出、PDF 阅读、没有当前语言 AI 章节标记的 EPUB，以及服务端 AI 生成任务本身。

### 修复

- **移除目录标记的宽泛 DOM 观察器**：Book 页面在绑定时直接扫描已渲染目录；章节页在 `toc.json` 填充完成后通过现有显式事件刷新。相同标记文案也不再重复写入 DOM，阻断任何刷新反馈环。
- **轻量 AI 标记接口**：目录标记改用 `view=indicators`，只返回结果 ID、书籍 ID、章节索引、范围和语言，不再下载完整 AI 正文。大体积 AI 阅读历史不会再拖慢 Book 页面初始化。
- **多标签登录不再误报 403**：同一匿名浏览会话可以同时持有多个短时登录 nonce。先打开 Book 登录页再打开 Library 登录页，不会再让前一个表单立即失效。
- **登录页 favicon 使用发布清单**：登录页读取 `asset-manifest.json` 中带内容 hash 的 favicon，并将对应不可变资源加入未登录可访问边界。
- **消除重复 CSP 指令**：应用不再为阅读页面重复声明由部署层控制的 `frame-ancestors`，避免浏览器忽略重复指令的警告。

### 升级说明

- v2.9.2 继续使用 v2.9.1 的 SQLite schema v21，不新增数据库迁移，也不改变 EPUB/PDF 内容缓存 revision；已有书籍无需重新转换。
- 已运行过 v2.9.1 的数据库不能直接交给仅支持 schema v20 的旧镜像。遇到 `Database uses newer schema version 21; this version supports 20` 时，请升级到 v2.9.2，不要继续降级镜像。
- Docker 部署只需拉取 v2.9.2 镜像并重启。页面脚本是带 hash 的不可变资源，部署完成后浏览器会自动使用新 URL。

## English

v2.9.2 is an urgent stability patch for a browser-main-thread freeze introduced by language-scoped AI reading chapter markers. It also reduces the chapter-indicator payload and fixes concurrent sign-in 403 responses, the missing login favicon, and a duplicate CSP directive warning.

### Severity and affected scope

- **Affected versions**: v2.8.1 through v2.9.1.
- **Affected surfaces**: EPUB Book pages and EPUB chapter TOC drawers in Server deployments only.
- **Trigger**: At least one chapter-level AI reading result exists for the active interface language. After inserting its marker, a broad `MutationObserver` observed an unconditional label rewrite and repeatedly triggered itself, saturating the browser main thread.
- **Not affected**: SSG output, PDF reading, EPUB books without a matching language marker, and server-side AI generation jobs.

### Fixes

- **Remove the broad TOC mutation observer**: Book pages scan their server-rendered TOC during binding, while chapter pages use the existing explicit event after `toc.json` populates the drawer. Unchanged marker labels are no longer rewritten, preventing future refresh feedback loops.
- **Lightweight AI indicator response**: The TOC requests `view=indicators`, which returns only the result ID, book ID, chapter index, scope, and language instead of full generated AI content. Large retained reading histories no longer delay Book-page initialization.
- **Reliable concurrent sign-in**: One anonymous browser session can retain several short-lived login nonces. Opening a Book sign-in page and then a Library sign-in page no longer invalidates the first form with a 403.
- **Manifest-backed login favicon**: The login page resolves the hashed favicon through `asset-manifest.json`, and the corresponding immutable asset is available before authentication.
- **No duplicate CSP directive**: Reader responses leave `frame-ancestors` to the deployment layer, avoiding duplicate-directive warnings in browsers.

### Upgrade notes

- v2.9.2 keeps the SQLite schema at v21 from v2.9.1. It adds no database migration and changes neither the EPUB nor PDF content-cache revision, so books do not need reconversion.
- A database already opened by v2.9.1 cannot be used by an older image that supports only schema v20. If startup reports `Database uses newer schema version 21; this version supports 20`, upgrade to v2.9.2 instead of continuing the image downgrade.
- Docker deployments only need the v2.9.2 image and a restart. Hashed page assets receive a new URL automatically.
