# v2.14.0

## 新功能

- **Server 书籍磁盘缓存上限（#42，仅 Server）**：管理员可在「一般设置」设置保留在磁盘上的书籍缓存数量，默认 100 本。超出上限时按最近阅读时间淘汰最久未读的书，只保留封面、目录和元数据等轻量文件，书库与阅读记录仍可正常显示。打开被淘汰的书时会显示准备页面，从源文件恢复缓存后自动打开，失败可重试或返回书库。阅读页、PDF 文档交付、AI 阅读和公开 API 会锁定当前书籍，避免正在使用的缓存被淘汰；源文件不可用或 PDF 缓存失效时返回明确错误（503 / 409），不再返回不完整内容。
- **按账户保存日夜主题（#55，仅 Server）**：账户设置可分别选择白天与夜间主题（7 种内置主题），并可开启跟随设备深色模式的自动切换。设置保存在账户中，随登录会话生效；首屏通过共享 `theme-bootstrap.js` 立即应用主题，避免加载时闪现。新增需登录的 `/api/account/appearance` 接口，新增文案覆盖 17 种语言。

## 修复

- 自动切换主题时隐藏工具栏的手动主题按钮，避免手动选择与自动切换冲突（#55）。
- 书籍页与章节页的主题初始化由重复的内联脚本统一改为共享 `theme-bootstrap.js`，SSG 与 Server 不再维护两份逻辑；移除章节页中未使用的代码高亮主题切换函数。

### 影响范围

- 缓存上限、冷缓存准备页面、账户外观与自动主题切换均为 Server 专属；SSG 仍使用浏览器本地主题，不引入 `/api/*` 或登录态。
- 共享模板与 `theme-bootstrap.js`、`theme.js` 覆盖 SSG 与 Server 的 EPUB / PDF 页面；SSG 需重新生成以应用新的资源引用。
- EPUB `content/` 与 PDF 缓存修订均未变（`server-content-v11`、`server-pdf-v2`）；本次改动位于页面资源、缓存管理与应用数据层。

### 升级说明

- Server：部署并重启即可。启动时自动为 `general_settings` 增加 `book_cache_limit` 列并创建 `account_appearance` 表，SQLite `user_version` 提升到 32；升级前建议备份 `data/`，回退到旧版本需恢复升级前的数据库。
- 默认保留最近 100 本的磁盘缓存。书库超过 100 本时，升级后首次协调会淘汰较久未读的缓存；这些书首次打开需从源文件重新准备一次，之后恢复正常速度。可在「一般设置」调整上限；源文件必须仍存在于监控目录，否则无法恢复。
- 账户外观默认不启用自动切换（白天 `light`、夜间 `dark`、手动 `light`），既有用户的手动主题保持不变。
- SSG：需重新生成并整站发布静态输出以应用共享主题脚本更新；无 CLI 参数或书籍 URL 变化，也无需重新转换书籍。

## Features

- **Bounded Server book cache with LRU eviction (#42, Server only)**: Administrators can set how many books stay cached on disk in General settings; the default is 100. Beyond the limit, the least recently read books lose their full cache while keeping lightweight files such as covers, TOC and metadata, so the library and reading history still render. Opening an evicted book shows a preparation page that restores the cache from its source and opens automatically; failures can be retried or dismissed back to the library. Reader pages, PDF delivery, AI reading and the public API pin the current book so an in-use cache cannot be evicted. Missing sources or stale PDF caches now return explicit errors (503 / 409) instead of incomplete content.
- **Per-account day and night themes (#55, Server only)**: Account settings can choose separate day and night themes from the seven built-in themes and enable automatic switching that follows the device's dark-mode preference. Preferences are stored per account and apply to every signed-in session. A shared `theme-bootstrap.js` applies the theme on the first paint to avoid a flash. A session-protected `/api/account/appearance` endpoint was added, with new copy in all 17 locales.

## Fixes

- The toolbar's manual theme picker is hidden while automatic switching is active, so manual choices no longer conflict with the automatic theme (#55).
- Book and chapter pages now initialize themes through the shared `theme-bootstrap.js` instead of duplicated inline scripts for SSG and Server; the unused code-highlight theme switcher was removed from the chapter page.

### Affected scope

- Cache limits, cold-cache preparation, account appearance and automatic theme switching are Server-only. SSG keeps using the browser-local theme and depends on neither `/api/*` nor login state.
- Shared templates, `theme-bootstrap.js` and `theme.js` cover EPUB and PDF pages in both SSG and Server; SSG sites need regeneration to pick up the new asset references.
- Neither the EPUB `content/` nor the PDF cache revision changed (`server-content-v11`, `server-pdf-v2`); this release touches page assets, cache management and application data.

### Upgrade notes

- Server: deploy and restart. Startup adds the `book_cache_limit` column to `general_settings`, creates the `account_appearance` table and advances SQLite `user_version` to 32. Back up `data/` before upgrading; rolling back to an older release requires the pre-upgrade database.
- The default keeps the 100 most recently read books on disk. Libraries larger than that will evict older caches during the first reconciliation after upgrading; those books are prepared once from their sources on their next open. Adjust the limit in General settings, and keep source files in the watched directory so evicted books can be restored.
- Appearance defaults keep automatic switching off (day `light`, night `dark`, manual `light`), so existing manual theme choices are preserved.
- SSG: regenerate and republish the full static output to pick up the shared theme script. No CLI flags, book URLs or conversion formats changed, and no books need reconversion.
