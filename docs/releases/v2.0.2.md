# EPUB Browser v2.0.2

发布日期 / Release date: 2026-08-19

## 中文

这是一个强化 SSG 隐私边界的维护版本，确保静态站点始终使用浏览器本地数据。

### 修复与改进

- **静态阅读进度保持本地**：SSG 站点不再沿用浏览器中由 Server 模式留下的用户名。阅读进度始终保存在当前浏览器中，不会被误标记为已同步状态。
- **移除不适用于 SSG 的身份与同步入口**：静态书库不再显示登录和书架同步按钮，避免用户触发静态托管环境无法提供的 Server 操作。书架导入、导出和本地管理仍可正常使用。

### 兼容性

- 不需要数据迁移。现有静态站点重新运行 `epub-browser ssg` 后即可获得修复。
- Server 模式的登录、书架同步与跨设备阅读进度不受影响。

## English

This maintenance release strengthens the privacy boundary of SSG sites so static deployments consistently use browser-local data.

### Fixes and Improvements

- **Static reading progress stays local**: SSG sites no longer reuse a username left in the browser by a Server deployment. Reading progress remains in the current browser and is no longer presented as synchronized state.
- **Server-only identity and sync controls are hidden in SSG**: Static libraries no longer show login or bookshelf sync actions that their hosting environment cannot provide. Bookshelf import, export, and local organization continue to work normally.

### Compatibility

- No data migration is required. Regenerate an existing static site with `epub-browser ssg` to apply the fixes.
- Login, bookshelf synchronization, and cross-device reading progress in Server mode are unchanged.
