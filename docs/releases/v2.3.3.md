# EPUB Browser v2.3.3 — Easier Server book administration

发布日期 / Release date: 2026-08-23

## 中文

v2.3.3 改进 Server 管理后台的书籍维护体验，并修复移动端 AI 阅读入口与 AI 任务列表的展示问题。

### 新功能

- **书籍排序**：书籍管理支持按书名正序或倒序、最近加入和最近更新排序；排序可与搜索、可见性、服务端标签筛选、分页和跨页批量选择组合使用。

### 改进

- **更适合日常维护的书籍列表**：书籍表格拥有更大的可滚动区域，展开一本书的设置后仍可浏览更多书籍。书籍摘要还提供加入时间，保证“最近加入”按服务端记录而非浏览器猜测排序。
- **统一批量操作确认**：批量设为受限和批量授权改用应用内的标准可访问确认弹窗，避免浏览器原生确认框造成的样式与交互不一致。

### 修复

- **移动端 AI 阅读**：底部 AI 阅读入口现在与桌面侧边栏一致，打开 AI 阅读弹窗；连续滚动阅读时，章节 AI 结果不会再因上下文判断错误而被静默忽略。
- **AI 任务列表**：修复进度条破坏表格行布局的问题，并改善任务列宽，使状态、进度与时间信息更稳定易读。

### 升级说明

- 无需 SQLite migration，也无需重新转换 EPUB。部署 `epub-browser:2.3.3` 并重启 Server 即可生效；SSG 输出不包含这些 Server 专属能力。

## English

v2.3.3 makes everyday Server book administration easier and fixes the mobile AI-reading entry point and AI-job table layout.

### New feature

- **Book sorting**: Book management can now sort by title in either direction, recently added, or recently updated. Sorting works together with search, visibility and server-tag filters, pagination, and cross-page bulk selection.

### Improvements

- **A more practical book list**: The book table has a taller scrollable workspace, so more books remain visible while an individual book is expanded for editing. Summaries now include the server-recorded added time, making the “recently added” order reliable.
- **Consistent bulk-operation confirmation**: Bulk restriction and member-grant actions now use the app’s standard accessible confirmation dialog instead of browser-native prompts.

### Bug fixes

- **Mobile AI reading**: The bottom AI-reading action now opens the same AI-reading dialog as the desktop sidebar. In continuous reading, chapter AI results are no longer silently discarded by an incorrect context check.
- **AI jobs**: Fixed progress controls disrupting table-row layout and improved task-column sizing so status, progress, and timestamps stay readable.

### Upgrade notes

- No SQLite migration or EPUB reconversion is required. Deploy `epub-browser:2.3.3` and restart the Server; SSG output remains free of these Server-only capabilities.
