# EPUB Browser v2.9.10 — Kindle 极简阅读器点击翻页（左右点击翻屏）

发布日期 / Release date: 2026-08-31

## 中文

v2.9.10 为 Kindle 极简阅读器章节页新增"点击翻页"：在正文区域点击左侧或右侧约三分之一屏宽，即向前/向后翻一屏（按视口高度对齐到整屏边界），让老款 e-Ink Kindle 上的阅读体验更接近实体书。

实现要点：

- 新增按钮 `Tap to turn`（i18n：`tapTurn`，覆盖全部 18 种语言）位于章节页顶部 `.k-controls` 工具条，紧随主题、A-、A+ 之后；默认开启，按下后写入 `kindle_click_scroll` cookie（值为 `on`/`off`，有效期 365 天），并通过 `kSyncClickScrollToggle()` 同步按钮的 `aria-pressed` 与 `.k-on` 高亮态（含 sepia/dark 配色）。
- 翻页逻辑由 `kClickTurn` 在 `document.onclick` 上分发：仅当点击落在 `.k-content` 内、且目标不是 `A`/`BUTTON`/`INPUT`/`SELECT`/`TEXTAREA` 等可交互节点时才翻屏；`kScrollPage(dir)` 以视口高度为步长做整屏 snap，避免半屏错位。关闭开关后即恢复原有的纯滚动阅读。
- 全部脚本保持 ES5、cookie 驱动，不引入 `fetch`/`localStorage`/`classList`，沿用 v2.9.8/v2.9.9 为老款 e-Ink Kindle WebKit 制定的兼容基线；SSG 静态页与 Server 动态页都内置同一模板与脚本，无新增 CSP 调整。

### 修复与改进

- **Kindle 极简阅读器点击翻页**：章节页新增 `Tap to turn` 开关与左右三分之一屏点击翻屏（snap-aligned），默认开启、cookie 持久化；按钮态、aria-pressed 与 sepia/dark 配色同步；点击落在链接、按钮等可交互节点或 `.k-content` 之外时不触发翻页，避免误触。
- **i18n 完整**：`tapTurn` 文案覆盖 en/zh/zh-CN/zh-TW/ja/ko/es/de/fr/ru/it/pt-BR/ar/id/hi/vi/th/ms 全部 18 种语言。

### 影响范围

- **部署与格式范围**：SSG 与 Server 均生效；仅 EPUB；仅 Kindle 极简阅读器章节页（`kindle_chapter_N.html` 及 Server 动态等价页）。普通阅读器页面、书架页、书页与 PDF 不受影响。
- **触发条件**：在 Kindle 极简阅读器章节页点击正文区域左右三分之一屏，或操作顶部 `Tap to turn` 开关。
- **无内容缓存变更**：不触及 `content/` 缓存 schema、`metadata.json`/`toc.json`/`chapter_<n>.json`，也不触及 SQLite 迁移；SERVER_OUTPUT_REVISION 与 PDF 修订均不变。

### 升级说明

- **Server 部署**：重启 Server 即生效（章节页与 CSP 在请求时渲染），无需重新转换 EPUB，不涉及内容缓存或 SQLite 迁移。
- **SSG 阅读器部署**：需重新转换 Kindle 极简输出（`--kindle`）以让新章节页带上点击翻页脚本与开关。
- **无需配置**：无新增配置项；默认开启，读者可在章节页顶部按钮处关闭以恢复纯滚动。

## English

v2.9.10 adds "tap to turn" to the Kindle minimal-reader chapter page: tapping the left or right third of the reading area moves one screen backward or forward (snapped to viewport-height boundaries), bringing the e-ink Kindle reading experience closer to a physical book.

Implementation notes:

- A new `Tap to turn` button (i18n key `tapTurn`, all 18 languages) joins the chapter-page `.k-controls` toolbar right after Theme / A- / A+; it defaults to on, writes the `kindle_click_scroll` cookie (`on`/`off`, 365 days) when toggled, and `kSyncClickScrollToggle()` keeps its `aria-pressed` and `.k-on` highlight (with sepia/dark variants) in sync.
- `kClickTurn` handles `document.onclick`: it only triggers when the tap lands inside `.k-content` and the target is not an `A`/`BUTTON`/`INPUT`/`SELECT`/`TEXTAREA` interactive node; `kScrollPage(dir)` advances by exactly one viewport height with snap alignment so half-screens do not misalign. Turning the toggle off restores the original plain-scroll reading.
- Everything stays ES5 and cookie-driven — no `fetch`/`localStorage`/`classList` — preserving the compatibility baseline established in v2.9.8/v2.9.9 for legacy e-ink Kindle WebKit. SSG static pages and Server dynamic pages share the same template and script, with no CSP changes.

### Fixes and improvements

- **Kindle minimal-reader tap-to-turn**: the chapter page gains a `Tap to turn` toggle and left/right-third tap-to-advance (snap-aligned), on by default and persisted via cookie; the button state, `aria-pressed`, and sepia/dark coloring stay in sync; taps on links, buttons, and other interactive nodes, or outside `.k-content`, do not trigger a turn to avoid accidental navigation.
- **Full i18n**: the `tapTurn` string is translated across all 18 languages (en/zh/zh-CN/zh-TW/ja/ko/es/de/fr/ru/it/pt-BR/ar/id/hi/vi/th/ms).

### Affected scope

- **Deployment and format scope**: SSG and Server; EPUB only; only the Kindle minimal-reader chapter page (`kindle_chapter_N.html` and its Server dynamic equivalent). Ordinary reader pages, the shelf, the book page, and PDF are unchanged.
- **Trigger**: tapping the left/right third of the reading area on a Kindle minimal-reader chapter page, or toggling the `Tap to turn` button.
- **No content-cache changes**: does not touch the `content/` schema, `metadata.json`/`toc.json`/`chapter_<n>.json`, or any SQLite migration; neither SERVER_OUTPUT_REVISION nor the PDF revision is bumped.

### Upgrade notes

- **Server deployment**: restart the Server to take effect (chapter pages and CSP are rendered per request); no EPUB re-conversion, no content-cache or SQLite migration.
- **SSG deployment**: re-run the Kindle minimal conversion (`--kindle`) so new chapter pages carry the tap-to-turn script and toggle.
- **No configuration**: no new options; on by default, and readers can turn it off from the chapter-page toolbar to restore plain scrolling.
