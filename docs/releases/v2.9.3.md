# EPUB Browser v2.9.3 — 慢速网络下更可靠的登录与汇总加载

发布日期 / Release date: 2026-08-30

## 中文

v2.9.3 修复慢速网络下重复提交登录表单时，用户已经登录成功却仍看到 403 和“用户名或密码不正确”的问题。登录结果现在会按真实原因反馈；AI 阅读汇总和标注汇总也不再预先下载页面尚未使用的大体积详情数据。

### 修复与改进

- **重复登录直接进入目标页面**：第一个登录请求成功建立会话后，来自同一旧登录页的重复请求会复用现有会话并返回安全处理后的跳转地址，不再因缺少 CSRF token 返回 403，也不会再次验证密码或替换会话。
- **避免表单重复提交**：登录请求进行期间会禁用提交按钮并忽略后续提交，慢速网络或连续点击不再产生多个并发登录请求。
- **准确显示失败原因**：只有服务端明确返回 `invalid_credentials` 时才显示“用户名或密码不正确”并标记输入框；请求校验失效、尝试次数过多、网络不可达和未知服务错误分别显示对应提示。
- **AI 阅读分层加载**：书籍列表通过 `/api/ai/library?view=summary` 只读取书籍信息和结果数量；进入某本书后，再通过该书的 results 接口读取实际展示的标题、摘要、语言、版本、时间和删除权限。完整 AI 阅读正文及未使用的生成配置字段不再进入汇总响应。
- **标注按需加载**：标注总览通过 `view=summary` 由 SQLite 直接按书统计数量和最近更新时间，不再一次性返回所有标注正文、笔记和定位信息；进入某本书后才加载该书的完整标注。
- **兼容现有 API 调用**：两个接口未传 `view` 时仍返回原有完整结构，已有客户端无需同步升级。
- **阅读导航统一进入工具栏**：桌面章节页删除底部 navigation 和重复的“书籍”入口；滚动模式的上一章、下一章常驻右侧阅读工具栏，翻页模式在两者之间按顺序显示上一页、重新加载分页和下一页，并提供可直接输入页码的跳转控件。移动端保留原有布局，并在翻页模式增加页码跳转按钮。
- **翻页模式只保留可用操作**：桌面和移动阅读工具栏都会隐藏不受支持的“AI 阅读”和“问问 AI”。翻页模式设置会隐藏连续滚动、章节侧栏、自动隐藏章节侧栏和导航栏行为；自动隐藏阅读工具栏仍可正常开关，“点击翻页”移入设置且只在翻页模式可用。
- **分页适配完整视口高度**：章节模板不再生成底部导航，`createPages()` 首次分页时直接使用完整可用高度；用户调整窗口宽度或高度时会重新计算页数，并按原阅读比例定位到最接近的页面。高度变化只响应浏览器 `resize`，不会加入可能由分页重排反复触发的尺寸观察链。

### 影响范围

- **受影响版本**：截至 v2.9.2 的 Server 部署。
- **触发条件**：登录响应返回前重复提交表单；慢速网络、多标签页或连续点击会提高出现概率。
- **不受影响**：SSG 输出、已经完成登录后的正常阅读，以及 EPUB/PDF 内容缓存。汇总优化同时适用于 Server 中的 EPUB 和 PDF 标注；AI 阅读仍仅适用于 EPUB。

### 升级说明

- v2.9.3 不新增 SQLite migration，也不改变 EPUB/PDF 内容缓存 revision；升级镜像并重启即可，已有书籍无需重新转换。
- 登录 nonce 仍用于保护匿名登录请求。本次修复只把已经成功登录后的同源旧表单重复请求视为幂等跳转，不放宽其他写请求的 CSRF 校验。

## English

v2.9.3 fixes a slow-network sign-in race where an account was already authenticated but a repeated form submission still produced a 403 and was misleadingly shown as an incorrect username or password. Sign-in failures now reflect their actual cause, while AI-reading and annotation summaries avoid downloading large details that the overview has not yet used.

### Fixes and improvements

- **Repeated sign-in goes to the requested page**: After the first request establishes a session, a repeated request from the same stale sign-in page reuses that session and returns a sanitized redirect. It no longer fails CSRF validation, rechecks the password, or replaces the session.
- **Prevent duplicate form submissions**: The submit button is disabled while sign-in is pending, and additional submissions are ignored. Slow connections and repeated clicks therefore do not create concurrent login requests.
- **Accurate failure messages**: Only an explicit `invalid_credentials` response shows the username-or-password message and marks those fields invalid. Expired request validation, rate limiting, network failures, and unknown service errors each use a distinct message.
- **Layered AI-reading loading**: `/api/ai/library?view=summary` returns only book information and result counts. Opening a book then fetches its displayed titles, summaries, languages, versions, timestamps, and delete permissions from that book's results endpoint. Full AI content and unused generation settings no longer enter summary responses.
- **Annotations load on demand**: The annotation overview uses `view=summary`, letting SQLite aggregate each book's count and latest update without returning every highlight, note, or position. Full annotations are fetched only after a book is opened.
- **Existing API clients remain compatible**: Omitting `view` preserves the original complete response for both endpoints.
- **Reading navigation is consolidated in the toolbar**: Desktop chapter pages no longer render the bottom navigation or its duplicate Book action. Previous and Next Chapter remain in the right reading toolbar in scrolling mode; page-turning mode inserts Previous Page, Reload Pagination, and Next Page between them, followed by a direct page-number field. Mobile keeps its existing layout and gains a page-jump action in page-turning mode.
- **Page-turning mode shows only supported controls**: Unsupported AI Reading and Ask AI actions are hidden in both desktop and mobile toolbars. Continuous scroll, chapter-sidebar, chapter-sidebar auto-hide, and navigation-behavior settings are hidden while page-turning mode is active; reading-toolbar auto-hide remains available. Click to Turn Page now lives in Settings and is enabled only in page-turning mode.
- **Pagination uses the full viewport height**: The chapter template no longer emits bottom navigation, so the first `createPages()` pass measures the full available height directly. User-driven window width or height changes recalculate the page count and return to the nearest proportional page. Height changes are handled only by browser `resize`, avoiding a resize-observer feedback chain during pagination reflow.

### Affected scope

- **Affected versions**: Server deployments through v2.9.2.
- **Trigger**: The sign-in form is submitted again before its first response completes; slow networks, multiple tabs, and repeated clicks make this more likely.
- **Not affected**: SSG output, normal reading after authentication, or EPUB/PDF content caches. The annotation-summary optimization covers both EPUB and PDF in Server mode; AI reading remains EPUB-only.

### Upgrade notes

- v2.9.3 adds no SQLite migration and changes neither the EPUB nor PDF content-cache revision. Pull the updated image and restart; existing books do not need reconversion.
- The anonymous sign-in nonce remains in place. This fix treats only a same-origin repeated request from a stale sign-in page after successful authentication as an idempotent redirect; CSRF checks for other state-changing requests remain unchanged.
