# EPUB Browser v1.11.5

发布日期 / Release date: 2026-08-18

## 中文

这是一个修复 server 模式标注删除问题的维护版本。

### 修复

- **标注删除恢复正常**：现在可以正常删除标注，即使客户端随 `DELETE` 请求发送空 body 和 `Content-Type: application/json`。此前这类请求会被误判为无效 JSON，并显示“标注请求无效”。

### 兼容性

- 不需要迁移。既有标注、书库、书架和阅读进度数据保持兼容。

## English

This maintenance release fixes annotation deletion in server mode.

### Fix

- **Annotation deletion works reliably**: Annotations can now be deleted when a client sends an empty body with `Content-Type: application/json` on a `DELETE` request. Previously, that valid request shape was incorrectly rejected as invalid JSON.

### Compatibility

- No migration is required. Existing annotations, library data, bookshelves, and reading progress remain compatible.
