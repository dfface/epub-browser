# v2.10.0

## 新功能 / Features

### 中文

- **Web 界面上传书籍（#18）**：新增 Web 上传入口，可直接在浏览器中上传 EPUB 与 PDF 文件，无需命令行即可加入书库。
- **i18n 运行时按语言拆分为独立不可变包（#37）**：运行时的国际化数据拆分为按语言加载的不可变资源包，按需从源码即时提供，减少初始加载体积并支持更细粒度的语言加载。

### English

- **Web UI book upload (#18)**: Added a web upload entry point so EPUB and PDF files can be added to the library directly from the browser, without the command line.
- **i18n runtime split into per-locale immutable packs (#37)**: The internationalization runtime is now split into per-locale immutable packs served on demand from source, reducing initial load size and enabling finer-grained locale loading.

## 修复 / Fixes

### 中文

- **API 文档页初始化 i18n（#37）**：修复 API 文档页未初始化国际化运行时，导致该页文案无法翻译的问题。
- **身份控件随语言切换重新渲染（#37）**：导航栏账户值与账户设置面板的 `signedInAs` 现会在切换语言时正确重渲染，不再残留旧语言。
- **初始加载完成后通知语言监听者**：修复 `i18n.init()` 在异步加载完字典后只执行 `translateDocument()` 而未通知 `onLocaleChange` 监听者的缺陷。此前任何依赖 `t()` 且由监听者渲染（而非 `data-i18n` 属性）的内容会在字典就绪前被画一次且不再重绘——账户面板里的 `signedInAs` 因此在字典晚于会话加载时渲染成键名本身（如 `account.signedInAs`），并在 `chapter → 主页` 这类整页重载后偶现。现已与 `setLocale` 行为一致，在初始本地化完成后也触发 `notifyListeners()`。

### English

- **Initialize i18n on the API docs page (#37)**: Fixed the API docs page not initializing the i18n runtime, which left its copy untranslated.
- **Identity controls re-render on locale change (#37)**: The navbar account value and the account settings panel's `signedInAs` line now re-render correctly when the language is switched, instead of retaining the previous language.
- **Notify locale listeners after the initial dictionary load**: Fixed `i18n.init()` running `translateDocument()` after the dictionaries load asynchronously but never calling `notifyListeners()`. Previously any content rendered via a listener that uses `t()` (rather than a `data-i18n` attribute) was painted once before the dictionary was ready and never repainted — the account panel's `signedInAs` therefore rendered as the key itself (e.g. `account.signedInAs`) when the dictionary finished after the session loaded, and surfaced intermittently after full reloads such as `chapter → home`. `init()` now triggers `notifyListeners()` once initial localization completes, matching `setLocale`.

## 影响范围 / Affected scope

### 中文

- 改动 `epub_browser/assets/i18n/i18n-core.js`（初始加载完成后通知监听者）。
- 改动 `epub_browser/assets/auth.js`（语言切换时重渲染身份控件；账户菜单值改由 JS 控制，移除 `data-i18n` 以免被 `translateDocument` 覆盖）。
- 改动 `epub_browser/server_chrome.py`（导航栏账户值模板移除 `data-i18n`）。
- 改动 `epub_browser/assets/i18n/*.js` 及相关资源发布（按语言拆包）。
- 改动 Web 上传相关页面与后端接口（#18）。
- **无需内容缓存修订升级**：本版本仅涉及 UI/i18n/资源与上传能力，按既有约定只需重启/部署，无需重新转换 EPUB 或 PDF。

### English

- `epub_browser/assets/i18n/i18n-core.js` changed (notify listeners after initial load).
- `epub_browser/assets/auth.js` changed (re-render identity controls on locale change; account menu value is now JS-controlled with `data-i18n` removed so `translateDocument` cannot clobber it).
- `epub_browser/server_chrome.py` changed (navbar account value template no longer carries `data-i18n`).
- `epub_browser/assets/i18n/*.js` and related asset publishing changed (per-locale packs).
- Web upload page and backend endpoints changed (#18).
- **No content-cache revision bump**: This release only touches UI/i18n/assets and the upload feature, so per the existing convention it requires only a restart/deploy — no EPUB or PDF reconversion.

## 升级说明 / Upgrade notes

### 中文

- Server 模式：拉取新版本后**重启服务**即可（UI、i18n 与资源更新无需重新转换书籍）。
- SSG 模式：重新构建站点以应用新的页面与资源。
- 上传功能仅对管理员开放：入口位于管理面板内（非管理员不可见），后端 `/api/admin/books/upload` 强制 `require_admin`（非管理员返回 403），无需额外配置即可保证仅管理员可上传。

### English

- Server mode: after pulling the new version, **restart the server** (UI, i18n and asset updates need no book reconversion).
- SSG mode: rebuild the site to apply the new pages and assets.
- Upload is admin-only: the entry point lives inside the admin panel (hidden from non-admins) and the backend `/api/admin/books/upload` enforces `require_admin` (returns 403 for non-admins). No extra configuration is needed to keep uploads administrator-restricted.
