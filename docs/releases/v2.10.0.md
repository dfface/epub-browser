# EPUB Browser v2.10.0 — 标签拖拽排序回归、标签栏样式统一与 EPUB 解析容错增强

发布日期 / Release date: 2026-08-31

## 中文

v2.10.0 恢复了库页面标签云的拖拽排序：长按（触摸设备）或按住拖动标签即可调整顺序，排序结果保存在浏览器本地，书籍元数据刷新后依然保持。同时重写了标签栏的视觉样式，用主题统一的颜色变量、边框、胶囊圆角与悬停/选中态，让标签与整体界面风格完全一致。此外，EPUB 解析管线进一步容错：对中文工具导出的 GB18030/GBK 编码章节正确解码，对重复 rootfile、缺失或重复 manifest id、悬空 spine 引用等非规范结构采取"取首可用项 / 跳过"策略而非整本书拒绝，单个章节损坏时渲染空白占位而不中断整本书。

### 新功能

- **标签云拖拽排序（回归）**：库页面中的标签可以通过拖拽重新排列顺序（桌面按住拖动、触摸端长按后拖动）。排序顺序持久化到浏览器 `localStorage`，元数据刷新后依然保持；`All` 与 `NoTag` 固定在最前且不可拖拽；拖拽结束后不会误触发标签筛选切换。
- **标签栏样式统一**：标签改用主题变量（`--tag-bg` / `--tag-text` / `--tag-hover`），深色、棕色、绿色、蓝色、粉色、紫色与自定义主题全部自动适配；新增 1px 边框、胶囊圆角、悬停（淡色底）与选中（实心主色）的明确区分、键盘 `focus-visible` 焦点环，以及拖拽过程中的占位/选中视觉反馈。Kindle 模式自动降级为无边框、无阴影的简洁样式。

### 修复与改进

- **GB18030/GBK 中文编码兜底**：无编码声明的 GBK/GB18030 章节（常见于中文工具导出）不再因解码失败导致章节失败或乱码。`decode_html_bytes` 现在按 BOM → meta charset → UTF-8 → GB18030 → latin-1 → 替换字符的顺序兜底，文本解码本身惰性，绝不执行任何内容。
- **非规范 EPUB 结构容忍**：重复的 rootfile 声明取第一个可用项；缺失 id 的 manifest 项跳过（无法被 spine 引用，保留其余书籍）；重复 id 首次生效；悬空 spine `idref` 丢弃。主流阅读器可正常打开的书不再被整体拒绝。
- **单章损坏降级**：某个章节处理失败时渲染空白占位，章节与目录保持对齐，不再中断整本书；路径逃逸仍是安全边界，直接拒绝而非降级。
- **解析性能**：`parse_xhtml_document` 改为单次读取文件字节，消除严格解析失败回退时的重复磁盘 IO。

### 影响范围

- **部署与格式范围**：库页面 UI（标签排序与样式）同时作用于 SSG 与 Server 的共享页面资产；EPUB 解析改动影响转换期，SSG 与 Server 均受益；PDF 不受影响。
- **触发条件**：在库页面拖拽标签；转换含 GBK/GB18030 章节、重复 rootfile、缺失/重复 manifest id 或悬空 spine 引用的 EPUB；某章节损坏的书籍。

### 升级说明

- **Server 部署**：重启 Server 即生效（资产重新哈希发布）；解析容错作用于转换期，新转换的书籍立即受益，已有内容缓存的存量书无需变化，如需让存量书享受更宽容的解析可重新转换。
- **SSG 部署**：重新生成静态站点即可。
- **无需配置**：拖拽排序与本地持久化是浏览器行为，不涉及内容缓存 schema 或 SQLite 迁移。

## English

v2.10.0 brings back drag sorting for the Library tag cloud: press and drag a tag (long-press on touch devices) to reorder it, and the order persists in browser `localStorage` across metadata refreshes. The tag bar has also been restyled to match the rest of the interface — theme-driven colours, borders, pill radii, and distinct hover/selected states. On the parsing side, the EPUB pipeline is more forgiving: chapters exported in GB18030/GBK by Chinese tools decode correctly, and non-conformant structures such as repeated rootfiles, missing or duplicate manifest ids, and dangling spine references are handled by "first usable / skip" instead of rejecting the whole book; a single broken chapter renders a blank placeholder instead of failing the entire conversion.

### New features

- **Tag-cloud drag sorting (restored)**: Library tags can be reordered by dragging (hold and drag on touch devices). The order persists in `localStorage` and survives metadata refreshes; `All` and `NoTag` stay pinned at the front and cannot be dragged; a completed drag no longer triggers an accidental tag-filter toggle.
- **Unified tag-bar styling**: Tags now use the theme variables (`--tag-bg` / `--tag-text` / `--tag-hover`) so dark, brown, green, blue, pink, purple, and custom themes all adapt automatically, with a 1px border, pill radii, a clear hover (tinted) vs selected (solid accent) distinction, a `focus-visible` ring, and drag feedback (ghost/selected/dragging states). Kindle mode degrades to a borderless, shadow-free look.

### Fixes and improvements

- **GB18030/GBK fallback decoding**: Chapters encoded in GBK/GB18030 without an encoding declaration no longer fail or garble. `decode_html_bytes` now falls back through BOM → meta charset → UTF-8 → GB18030 → latin-1 → replacement characters, and plain-text decoding never executes or loads anything.
- **Tolerant EPUB structures**: Repeated rootfile declarations use the first usable entry; manifest items with a missing id are skipped (they can never be addressed by a spine idref); duplicate ids keep their first occurrence; dangling spine idrefs are dropped. Books that mainstream readers open are no longer rejected wholesale.
- **Single-chapter degradation**: A chapter that fails to process renders a blank placeholder so the chapter list and TOC stay aligned; path escaping remains a security boundary and is rejected rather than degraded.
- **Parsing performance**: `parse_xhtml_document` reads the file bytes once, removing duplicate disk I/O on the strict-parse-failure fallback path.

### Affected scope

- **Deployment and format scope**: The Library UI (tag sorting and styling) ships through the shared page assets for both SSG and Server; the EPUB parsing changes affect the conversion phase for both modes; PDF is unaffected.
- **Trigger**: dragging tags on the Library page; converting EPUBs with GBK/GB18030 chapters, repeated rootfiles, missing/duplicate manifest ids, or dangling spine references; books with a broken chapter.

### Upgrade notes

- **Server**: restart to pick up the new asset hashes; the parsing tolerance applies at conversion time, so newly converted books benefit immediately while existing cached books need no changes — reconvert if you want older books to enjoy the more lenient parsing.
- **SSG**: regenerate the static site.
- **No configuration required**: drag sorting and its local persistence are browser behaviour; no content-cache schema change or SQLite migration is involved.
