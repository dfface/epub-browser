# EPUB Browser v1.10.1

发布日期 / Release date: 2026-08-12

## 中文

这一版本让 EPUB Browser 更像一个安静、可靠、属于你自己的阅读空间，同时完成了品牌与阅读界面的统一升级。

### 新增与改进

- **全新的品牌标识**：加入小书虫 Logo，并更新 PWA 图标、favicon、移动端主题色和 README。产品定位也更清晰：它既是个人 EPUB 阅读器，也是可直接部署到 Pages 的静态网站生成器。
- **统一的导航体验**：书库、书籍和章节页面现在共用紧凑的面包屑样式与品牌入口；从任意页面都能清晰返回书库，阅读界面的层级更一致。
- **划线后可复制原文**：选中文本创建划线时，可以直接复制原始选区文字，无需先添加标注。
- **阅读设置更集中**：Custom CSS 已收纳到 **Settings → Reading → Custom styles**，与字体、阅读模式等设置放在同一处。
- **更自然的内容加载**：取消会打断阅读的全屏 Loading。章节初始化和首次字体排版只在会变化的正文区域显示与主题协调的加载状态，面包屑始终可见。

### 修复

- 修复翻页模式的初始化与上一章导航问题。
- 修复 Chapter 页品牌图标的垂直对齐，并移除翻页模式中多余的顶部留白。
- 修复字体和阅读偏好应用时的内容闪动，同时保留设置过程中可见的即时预览。
- **缓存更新不再依赖强刷**：样式、脚本、图标会以内容指纹发布；普通刷新即可获得新版资源，离线时仍可回退到已缓存内容。

### 升级提示

无需迁移数据。刷新页面即可获取新版本资源，不再需要在开发者工具的 **Network** 面板中清空缓存或使用 **Empty Cache and Hard Reload**。如果部署环境仍然提供旧文件，请检查 CDN 或反向代理是否错误地缓存了 `index.html`、`sw.js` 或 `assets/manifest.json`。

## English

This release makes EPUB Browser feel more like a calm, dependable reading space that belongs to you, while bringing the brand and reader interface into one coherent experience.

### New and improved

- **A new brand identity**: Meet the bookworm logo across the PWA icons, favicon, mobile browser colour, and README. EPUB Browser is now presented clearly as both a personal EPUB reader and a static-site generator ready for Pages deployment.
- **One consistent navigation surface**: Library, book, and chapter pages now share a compact breadcrumb and brand entry point, so returning to your library is clear from anywhere in the reader.
- **Copy highlighted source text**: When creating a highlight, you can now copy the original selected passage directly—no annotation required.
- **A more coherent Reading settings area**: Custom CSS now lives in **Settings → Reading → Custom styles**, alongside font and reading-mode controls.
- **Calmer content loading**: Full-screen loading screens no longer interrupt reading. Chapter setup and initial font layout use a theme-aware loading state only over changing reading content, while navigation stays visible.

### Fixes

- Restored page-turning initialisation and previous-chapter navigation.
- Corrected brand-mark alignment on chapter breadcrumbs and removed unnecessary top spacing in page-turning mode.
- Reduced content flashes when applying saved font and reading preferences, without hiding live changes made in Settings.
- **Cache-safe updates**: styles, scripts, and icons now use content-addressed URLs. A regular refresh receives the new release, while cached content remains available offline.

### Upgrade note

No data migration is required. Refresh the page to receive the new release; there is no need to clear the browser cache from Developer Tools' **Network** panel or use **Empty Cache and Hard Reload**. If a deployment still serves old files, check whether a CDN or reverse proxy is incorrectly caching `index.html`, `sw.js`, or `assets/manifest.json`.
