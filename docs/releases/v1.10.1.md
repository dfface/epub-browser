# EPUB Browser v1.10.1

发布日期 / Release date: 2026-08-12

## 中文

这一版本让 EPUB Browser 更像一个安静、可靠、属于你自己的阅读空间：阅读器界面更统一，品牌更清晰，更新也终于不再依赖手动清缓存。

### 新增与改进

- **全新的品牌标识**：小书虫 Logo 已覆盖应用图标、favicon、PWA 与 README。EPUB Browser 的定位也更明确：既是个人 EPUB 阅读器，也是可直接部署到 Pages 的静态网站生成器。
- **统一的阅读导航**：书库、书籍和章节页面现在共用紧凑的面包屑与品牌入口。无论身处哪里，都能自然回到书库。
- **划线后可复制原文**：选中内容创建划线时，可直接复制原始选区文字，无需先添加标注。
- **更集中的阅读设置**：Custom CSS 已收纳到 **Settings → Reading → Custom styles**，与字体、字号和阅读模式放在同一处。
- **更自然的加载体验**：不再使用会打断阅读的全屏 Loading。章节初始化和首次排版只在正文区域显示与主题协调的加载状态，导航始终可见。

### 更可靠的自动更新

- **无需再点 Update**：首页的手动 Update 按钮已移除。普通刷新会自动发现新版阅读器资源，不再要求读者清浏览器缓存。
- **资源更新更稳妥**：样式、脚本、图标和字体现在使用内容指纹 URL；新版本会请求新文件，已缓存的旧文件仍可用于离线阅读。
- **离线优先但不过期**：Service Worker 只对版本化资源使用缓存优先策略；书籍内容和页面在线时优先从网络读取，网络不可用时才回退到缓存。

### 修复

- 修复翻页模式的初始化与上一章导航问题。
- 修复 Chapter 页品牌图标的垂直对齐，并移除翻页模式中多余的顶部留白。
- 修复字体和阅读偏好应用时的内容闪动，同时保留设置过程中可见的即时预览。

### 升级提示

无需迁移数据，也无需在开发者工具的 **Network** 面板中清空缓存。刷新页面即可获取新版资源。若部署后仍持续显示旧页面，请检查 CDN 或反向代理是否错误缓存了 `index.html`、`sw.js` 或 `assets/manifest.json`。

## English

This release makes EPUB Browser feel more like a calm, dependable reading space that belongs to you: the reader is more coherent, the brand is clearer, and updates no longer depend on manually clearing the browser cache.

### New and improved

- **A new brand identity**: The bookworm logo now spans the app icons, favicon, PWA, and README. EPUB Browser is also positioned more clearly as both a personal EPUB reader and a static-site generator ready for Pages deployment.
- **One navigation surface**: Library, book, and chapter pages now share a compact breadcrumb and brand entry point, making it natural to return to the library from anywhere.
- **Copy highlighted source text**: When creating a highlight, you can copy the original selected passage directly—no annotation required.
- **More coherent reading settings**: Custom CSS now lives in **Settings → Reading → Custom styles**, alongside font, size, and reading-mode controls.
- **Calmer loading**: Full-screen loading no longer interrupts reading. Chapter setup and first layout use a theme-aware state only over changing content, while navigation remains visible.

### More reliable automatic updates

- **No Update button needed**: The manual Update button has been removed from the library. A normal refresh discovers new reader resources automatically, without asking readers to clear their cache.
- **Cache-safe assets**: Styles, scripts, icons, and fonts now use content-addressed URLs. New releases request new files, while cached files remain useful for offline reading.
- **Offline-friendly without stale pages**: The Service Worker uses cache-first only for versioned assets. Pages and book content prefer the network when available, then fall back to the cache offline.

### Fixes

- Restored page-turning initialisation and previous-chapter navigation.
- Corrected brand-mark alignment on chapter breadcrumbs and removed unnecessary top spacing in page-turning mode.
- Reduced content flashes when applying saved font and reading preferences, without hiding live changes made in Settings.

### Upgrade note

No data migration is required, and there is no need to clear the browser cache from Developer Tools' **Network** panel. Refresh the page to receive the new release. If an old page persists after deployment, check whether a CDN or reverse proxy is incorrectly caching `index.html`, `sw.js`, or `assets/manifest.json`.
