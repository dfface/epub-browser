# EPUB Browser v1.10.8

发布日期 / Release date: 2026-08-13

## 中文

这是一个面向沉浸式阅读与云端标注可靠性的维护版本。

### 改进

- **标注成功后保持安静**：新增、修改和删除标注成功时不再弹出通知；阅读流程保持连续，只有失败时才显示带原因的错误提示。
- **移出书架状态更清晰**：Book 页的 `Remove from Shelf` 按钮使用高对比度的危险操作色与白色文字，悬停状态也保持清晰可辨。

### 修复

- **云端标注恢复更可靠**：章节重新进入时，过期的异步标注请求不会覆盖当前章节；若页面首次布局导致高亮锚点暂时无法匹配，阅读器会在布局稳定后自动重试一次。
- **恢复失败可见且可处理**：只有在自动重试后仍无法还原标注，或云端加载本身失败时，才会显示明确的错误提示并建议刷新章节。

### 兼容性

云端标注继续按现有用户名隔离；本地 IndexedDB 标注和静态站点行为保持不变，无需迁移或重新配置。

## English

This maintenance release improves immersive reading and cloud-annotation reliability.

### Improvements

- **Successful annotation actions stay quiet**: Adding, editing, and deleting annotations no longer shows success notifications. Reading stays uninterrupted, while failures still provide a reasoned error message.
- **Clearer remove-from-shelf state**: The Book page's `Remove from Shelf` action now uses a high-contrast destructive color with white text, including a clear hover state.

### Fixes

- **More reliable cloud-annotation restoration**: When re-entering a chapter, stale asynchronous annotation responses can no longer overwrite the current chapter. If the first layout temporarily prevents a highlight anchor from matching, the reader retries once after layout settles.
- **Actionable restoration failures**: An error is shown only when the retry still cannot restore an annotation, or when the cloud request itself fails; the message advises the reader to reload the chapter.

### Compatibility

Cloud annotations remain isolated by the existing username identifier. Local IndexedDB annotations and static-site behavior are unchanged; no migration or reconfiguration is required.
