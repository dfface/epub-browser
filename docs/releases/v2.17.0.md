# v2.17.0

## 新功能

- **书架优先排序（#73）**：主书库与 Kindle 书架的排序下拉新增「书架优先」。已加入书架的书按加入时间由新到旧排在前面，其余书籍保留手动顺序；时间戳相同或未入架时，用手动顺序与书籍 ID 稳定决胜。加入书架、移除书籍或删除书架分组时会维护或清理加入时间；旧书架数据没有时间戳时按当前显示顺序推导，无需迁移。Server 从账户书架文档读取时间，SSG 从浏览器本地书架读取；管理后台的排序选项不变。
- **PDF 优先排序**：新增「PDF 优先」选项，把所有 PDF 排在 EPUB 前面，组内按创建时间由新到旧排列，并以书名作最终决胜；Server 与 ES5 客户端共用同一套格式分组和决胜规则。新增 17 种语言文案。
- **排序偏好与书库页码进入 URL**：主书库记住上次选择的排序方式，并把当前页码写入 `page` 查询参数（与 `sort` 并列）。从书籍页返回、刷新、历史导航或书签都能回到同一页；切换排序时回到第一页。Kindle 书架继续使用既有偏好保存。
- **阅读器侧边栏随视口自适应**：桌面章节侧边栏与阅读列共享水平预算，按页面宽度、外侧偏移和两侧留白计算剩余空间，达到最小宽度才显示，并在 220–320px 之间随剩余空间增长；正文在各种视口下保持居中。桌面设置按钮不再受固定 1360px 断点限制（改为 968px），AI 聊天模式仍排除在外。
- **文档**：README 及 17 种语言版本加入 Kindle 极简模式截图。

## 修复

- 修正侧边栏覆盖时左右留白不均，使阅读页与侧边栏保持视觉平衡（AI 聊天模式除外）。
- 行内 `code` 不再被高亮器排除：句中含代码时标注可作为连续区间绘制，恢复标注的文本锚点回退规则同步调整；块级 `pre` 仍受保护。
- 侧边栏宽度与阅读列不再随窗口变化而漂移，固定断点改为按实际可用宽度判断。

### 影响范围

- 排序、URL 状态与阅读器布局均为共享页面能力，覆盖 SSG 与 Server、EPUB 与 PDF；书架优先排序在 Server 读取账户书架、SSG 读取浏览器本地书架，管理后台排序选项不变。
- 书架数据格式向后兼容：`added` 时间戳为可选字段，旧数据按显示顺序推导。EPUB `content/` 与 PDF 缓存修订均未变（`server-content-v11`、`server-pdf-v2`），SQLite schema 仍为 34。
- 无新增 API、CLI 参数或登录要求；排序偏好保存在浏览器本地，页码与排序同时体现在 URL 中。

### 升级说明

- Server：部署并重启即可，无需重新转换书籍，也无需数据库迁移；仍建议按惯例在升级前备份 `data/`。
- SSG：需重新生成并整站发布静态输出，以应用新的排序脚本、阅读器布局资源、选项文案与哈希资源。
- 没有保存过排序偏好时仍默认「手动顺序」；已有偏好、`?sort=` 与新的 `?page=` 链接可直接使用。

## Features

- **Bookshelf-first sort (#73)**: The main library and Kindle bookshelf gain a "Bookshelf first" option. Books on the shelf come first, ordered by when they were added (newest first), while the remaining books keep their manual order; manual ranks and book IDs provide a stable tie-break for equal timestamps and non-shelf books. Add-to-shelf, remove-from-shelf and group deletion maintain or clear the timestamps. Legacy shelves without timestamps are derived from their current display order, so no migration is needed. Server reads timestamps from the account's bookshelf document, SSG from the browser-local bookshelf, and the administration book list keeps its existing options.
- **PDF-first sort**: A new "PDF first" option lifts every PDF ahead of the EPUBs, orders each group by creation time (newest first) and uses the title as the final tie-break. Server and the ES5 client share the same format grouping and tie-break rules. The label ships in all 17 locales.
- **Persisted sort preference and library page in the URL**: The main library remembers the last sort choice and writes the current page to a `page` query parameter alongside `sort`. Returning from a book page, reloading, history navigation and bookmarks restore the same page; changing the sort returns to page one. The Kindle bookshelf keeps using its existing preference storage.
- **Viewport-aware reader sidebar**: The desktop chapter sidebar shares one horizontal budget with the reading column. Its width is derived from what remains after the page width, outer offset and both gutters; it appears only when that remainder reaches the minimum and grows up to 320px with any surplus, so the reader stays centred at every viewport width. Desktop settings are no longer hidden by a fixed 1360px breakpoint (now 968px), and AI-chat mode remains excluded.
- **Documentation**: README and all 17 localized copies now include a Kindle minimal-mode screenshot.

## Fixes

- Balanced the left and right margins when the sidebar overlays the page, so the reading column no longer sits off-centre (AI-chat mode excluded).
- Inline `code` is no longer excluded by the highlighter, so a sentence containing code can be highlighted as one continuous range; the restored-quote text-anchor fallback follows the same rule, while block-level `pre` stays protected.
- The sidebar width and reading column no longer drift apart when the window resizes; the fixed breakpoint was replaced by a check against the actually available width.

### Affected scope

- Sorting, URL state and reader layout are shared page capabilities covering SSG and Server, EPUB and PDF. Bookshelf-first sort reads the account shelf on Server and the browser-local shelf on SSG; the administration book list keeps its existing options.
- The bookshelf format stays backward compatible: `added` timestamps are optional and legacy data is derived from display order. Neither the EPUB `content/` nor the PDF cache revision changed (`server-content-v11`, `server-pdf-v2`), and SQLite schema remains 34.
- No new API, CLI flag or login requirement. Sort preferences live in browser-local storage, while page and sort are reflected in the URL.

### Upgrade notes

- Server: deploy and restart. No book reconversion or database migration is needed; backing up `data/` before upgrading remains recommended.
- SSG: regenerate and republish the full static output to pick up the new sorting script, reader-layout assets, option labels and hashed assets.
- When no sort preference has been saved, the library still defaults to "Manual order". Existing preferences, `?sort=` links and the new `?page=` links work as described.
