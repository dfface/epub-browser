# EPUB Browser v1.10.4

发布日期 / Release date: 2026-08-12

## 中文

这是一个聚焦阅读流畅度和服务器同步可靠性的维护版本。

### 改进

- **更快地重新访问书籍**：书籍内的封面和其他 EPUB 资源现在可缓存 30 天；首页、Book 页和 Chapter 页仍会重新验证，因此更新不会被旧页面缓存遮蔽。
- **更可靠的服务器书架**：服务器模式将书架同步数据保存到 SQLite。首次同步时会自动导入同一用户名下版本最高的旧 JSON 书架文件，之后不再创建、更新或删除这些旧文件。
- **统一的服务器数据库**：标注与书架共同保存在 `epub-browser.db`。若仅存在旧的 `annotations.db`，启动时会尝试原子迁移；若迁移失败，服务仍会启动，新旧数据库都会保留，后续启动可重试迁移。
- **更平滑的连续滚动**：连续阅读在开启时会先预加载下一章，并保持至少两屏内容缓冲；短章节无需先滚到章节末尾也会继续加载。加载或淘汰章节时会固定当前可见内容的视口位置，跨过五章窗口边界不再因章节高度估算而突然回跳。新增图片完成加载后也会再次校正位置。

### 兼容性

浏览器本地 `localStorage` 仍是即时和离线书架缓存；`/sync` 的用户名、版本和数据字段保持不变。服务器身份仍只基于用户名，**不等同于认证或访问控制**。

### 升级提示

重新生成并完整部署站点目录即可生效。已有的 `annotations.db` 会在服务器启动时按需迁移为 `epub-browser.db`；已有服务器书架仍会在用户下一次同步时按需导入。

## English

This maintenance release focuses on smoother reading and more reliable server synchronization.

### Improvements

- **Faster revisits**: EPUB resources such as covers are cached for 30 days, while library, Book, and Chapter pages continue to revalidate so updates remain visible.
- **Durable server bookshelves**: Server-mode bookshelf sync now uses SQLite. On first sync, the highest-version legacy JSON shelf for the same username is imported once; legacy files are not subsequently created, updated, or deleted.
- **One server database**: Annotations and bookshelves share `epub-browser.db`. When only the old `annotations.db` exists, startup attempts an atomic migration; if it fails, the server still starts, both files remain, and a later startup can retry.
- **Smoother continuous reading**: Continuous mode preloads the next chapter on entry and maintains at least two viewport heights of buffered content, so short chapters continue without first reaching their end. Loading or evicting a chapter preserves the visible content anchor, eliminating height-estimation jumps at the five-chapter window boundary. Newly loaded images trigger a follow-up position correction.

### Compatibility

Browser `localStorage` remains the immediate and offline bookshelf cache, and `/sync` keeps its existing username, version, and data fields. Server identity is still username-based and **is not authentication or access control**.

### Upgrade note

Regenerate and deploy the complete site directory. An existing `annotations.db` is migrated into `epub-browser.db` on startup when possible; legacy server shelves import on the user's next sync.
