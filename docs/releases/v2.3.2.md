# EPUB Browser v2.3.2 — Simplified reverse-proxy IP trust

发布日期 / Release date: 2026-08-23

## 中文

v2.3.2 将反向代理配置收敛为真实客户端 IP 识别，移除了暂不需要的代理身份认证。

### 变更

- **移除代理身份认证**：删除代理身份请求头登录、身份关联 API、管理员身份映射界面及相关 CLI 参数。Server 现在仅支持本地账户密码登录。
- **简化真实 IP 配置**：`--trusted-proxy-cidr` 可单独配置，用于从可信直连代理安全解析 `X-Forwarded-For`，并应用于活跃会话和登录限流。
- **明确 HTTPS Cookie 配置**：`--cookie-secure` 只控制会话 Cookie 是否仅通过 HTTPS 发送，与真实 IP 配置独立；纯 HTTP 环境不应启用它。

### 升级说明

- 删除旧的 `--proxy-subject-header`、`--proxy-display-name-header` 和 `--proxy-issuer` 参数后重启服务。
- 既有 `user_identities` SQLite 数据会保留，但不再被读取或暴露；本版不改变 EPUB 内容缓存，也不需要重转书籍。
- 可信 CIDR 必须覆盖 EPUB Browser 实际看到的直连代理地址。例如直连地址为 `172.32.11.1` 时，使用 `--trusted-proxy-cidr=172.32.11.1/32`；`172.16.0.0/12` 不包含 `172.32.11.1`。

## English

v2.3.2 narrows reverse-proxy configuration to real client-IP recognition and removes proxy identity authentication, which is not currently needed.

### Changes

- **Proxy identity authentication removed**: Proxy-header sign-in, identity-linking APIs, the administrator mapping UI, and related CLI options are removed. Server now supports local password accounts only.
- **Simpler real-IP configuration**: `--trusted-proxy-cidr` now stands alone to safely parse `X-Forwarded-For` from trusted direct peers for active sessions and login throttling.
- **Clear HTTPS cookie behavior**: `--cookie-secure` independently restricts session cookies to HTTPS; do not enable it for HTTP-only deployments.

### Upgrade notes

- Remove the former `--proxy-subject-header`, `--proxy-display-name-header`, and `--proxy-issuer` options before restarting.
- Existing SQLite `user_identities` rows remain but are no longer read or exposed. This release does not change the EPUB content cache and does not require reconversion.
- The trusted CIDR must include the direct peer address EPUB Browser actually sees. For example, use `--trusted-proxy-cidr=172.32.11.1/32` for direct peer `172.32.11.1`; `172.16.0.0/12` does not include it.
