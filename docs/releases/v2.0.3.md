# EPUB Browser v2.0.3

发布日期 / Release date: 2026-08-19

## 中文

这是一个聚焦书架体验与交互一致性的维护版本。

### 新功能与改进

- **Server 书架自动云端同步**：书架在每次添加、删除、重命名或排序后自动保存到 Server 数据库，不再使用本地书架数据或手动 Sync。未登录时会提示先登录。
- **按模式显示正确操作**：Server 模式不再显示 Sync、Import 或 Export；SSG 模式保留 Import、Export，且不显示 Sync。
- **更完整的书架管理**：可搜索书库并将书籍加入根书架或当前分组；书籍卡片可单独移除，危险操作会要求确认。
- **书架界面重构**：书架与嵌套分组采用全屏、路径式导航；Home 与分组层级保持一致，移除了冗余标签栏，并遵循用户设置的字体。
- **项目级标准弹窗**：新增统一的输入与确认弹窗，覆盖书架、登录、标注、阅读进度、翻页模式及样式设置；支持国际化、键盘操作、焦点回归与移动端布局。
- **标注标题层级提升**：标注中心的标题与书架采用一致的标题比例和图标语言。

### 兼容性

- 不需要数据库迁移。Server 会在首次访问某个用户书架时继续兼容导入旧版书架 JSON。
- Server 书架需要已有用户名；用户名仍是当前项目的身份标识，不构成密码认证。
- SSG 书架的既有本地数据、Import 和 Export 格式保持兼容。

## English

This maintenance release focuses on bookshelf workflows and consistent interactions.

### New Features and Improvements

- **Automatic Server bookshelf sync**: Every add, removal, rename, and reorder now saves directly to the Server database. Server mode no longer uses local bookshelf data or a manual Sync action, and prompts unsigned-in users to sign in first.
- **Mode-appropriate actions**: Server mode no longer exposes Sync, Import, or Export. SSG keeps Import and Export, without Sync.
- **Fuller bookshelf management**: Search the library to add books to the root shelf or current group. Each book card can be removed independently, with confirmation for destructive actions.
- **Refined bookshelf UI**: The bookshelf and nested groups use full-screen, path-based navigation. Home matches the group hierarchy, the redundant tag bar is gone, and the interface follows the user-selected font.
- **Project-wide standard dialogs**: New shared input and confirmation dialogs now cover the bookshelf, sign-in, annotations, reading progress, page-turning mode, and style settings. They support localization, keyboard use, focus restoration, and mobile layouts.
- **Stronger annotation title hierarchy**: The annotation hub title now shares the bookshelf's title scale and icon language.

### Compatibility

- No database migration is required. Server continues to import a legacy bookshelf JSON when a user first accesses that shelf.
- A Server bookshelf requires an existing username. The username remains the project's current identity marker, not password authentication.
- Existing SSG local bookshelf data and its Import/Export format remain compatible.
