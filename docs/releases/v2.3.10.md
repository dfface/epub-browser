# EPUB Browser v2.3.10 — AI 阅读结果完整性

发布日期 / Release date: 2026-08-25

## 中文

v2.3.10 修复了 AI 阅读弹窗中的 Markdown 显示，并让章节 AI 阅读在关键学习内容缺失时自动补救，避免把不完整结果展示给读者。

### 修复与改进

- **正确显示 AI Markdown**：AI 划线和段落提示弹窗现在会渲染加粗、标题、列表、引用、代码、链接等 Markdown；日文等语言的多行说明也会按实际换行正常排版，不再显示 Markdown 标记或转义换行。
- **避免不完整的章节阅读结果**：若模型只生成了标注或段落提示，却漏掉章节导读、深入思考、本章总览或费曼学习法等核心学习内容，系统会自动再请求一次完整结果。
- **明确失败而非发布半成品**：补救请求仍缺少全部核心学习内容时，本次生成会报告失败，不会保存为看似成功但内容不全的 AI 阅读结果。

### 升级说明

- 无需 SQLite migration、无需重新转换 EPUB，也无需提高 Server EPUB 内容缓存修订。
- 已经生成但内容不完整的英文、韩文等章节结果，请在部署新版本后点击“重新生成”获取完整内容。

## English

v2.3.10 fixes Markdown presentation in AI-reading popovers and makes chapter AI reading recover when essential learning content is missing, so readers are not shown incomplete results.

### Fixes and improvements

- **AI Markdown renders correctly**: Highlight and paragraph-note popovers now render Markdown such as bold text, headings, lists, blockquotes, code, and links. Multi-line explanations, including Japanese content, follow their real line breaks instead of showing Markdown markers or escaped newlines.
- **Incomplete chapter readings are retried**: If a model returns annotations or paragraph notes but omits essential learning content such as the chapter guide, deep thinking, chapter overview, or Feynman learning section, the service automatically makes one retry for a complete result.
- **Clear failure instead of partial publication**: If the retry still contains none of the essential learning content, generation fails instead of saving an apparently successful but incomplete AI-reading result.

### Upgrade notes

- No SQLite migration, EPUB reconversion, or Server EPUB-content-cache revision is required.
- For English, Korean, or other chapters that were previously generated incompletely, choose **Regenerate** after deploying this release.
