# EPUB Browser v2.3.1 — Bulk access administration and real session IPs

发布日期 / Release date: 2026-08-23

## 中文

v2.3.1 为 Server 管理员补齐批量书籍权限操作，并让反向代理部署中的活跃会话显示真实客户端 IP。

### 新功能

- **批量书籍权限管理**：书籍表格可跨分页选择多本书，批量设为受限，或向选定成员追加访问授权。两种操作都会先确认，并在服务端对整组书籍原子校验和提交；批量授权不会覆盖既有成员授权。
- **Docker Compose 示例**：仓库根目录新增可直接构建和启动的 `docker-compose.yml`，以 loopback 端口发布服务，并持久化书库和 Server 状态。完整启动命令显式列出，便于追加反代等部署参数。

### 安全与升级

- **真实客户端 IP**：请求来自已配置的受信任反向代理时，活跃会话会从 `X-Forwarded-For` 右侧安全解析代理链，跳过受信任代理并记录首个真实客户端地址。未受信任来源仍只记录直连地址，避免伪造。
- **重新登录后生效**：已有会话会保留原有地址；升级并重启 Server 后，新的登录和代理身份会话会记录真实客户端 IP。
- **无需迁移或重转书籍**：本版不改变 SQLite schema 或 Server EPUB 内容缓存 schema。部署 `epub-browser:2.3.1` 并重启即可；SSG 保持纯静态，不含这些 Server 管理能力。

## English

v2.3.1 adds bulk book-access administration for Server operators and makes active sessions show the real client IP when the service is behind a reverse proxy.

### New feature

- **Bulk book access management**: The book table can select multiple books across pages, set them restricted in one operation, or add selected member grants. Both actions confirm first and validate and commit the complete set atomically; bulk grants never replace existing member access.
- **Docker Compose example**: The repository now includes a root-level `docker-compose.yml` that builds and starts the service with a loopback-only port and durable library and Server-state mounts. Its full command is explicit, so deployment-specific flags such as reverse-proxy settings can be appended directly.

### Security and upgrade notes

- **Real client IPs**: When a request comes through a configured trusted reverse proxy, active sessions safely walk the `X-Forwarded-For` chain from the right, skip trusted proxies, and store the first real client address. Untrusted peers continue to record only their direct address, preventing spoofing.
- **Takes effect after a new sign-in**: Existing sessions retain their prior address. After deploying and restarting the Server, new password and proxy-identity sessions record the real client IP.
- **No migration or book reconversion required**: This release changes neither the SQLite schema nor the Server EPUB content-cache schema. Deploy `epub-browser:2.3.1` and restart; static output remains free of these Server-only administration capabilities.
