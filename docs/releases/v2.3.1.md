# EPUB Browser v2.3.1 — Clearer administration and sign-in guidance

发布日期 / Release date: 2026-08-23

## 中文

v2.3.1 把 Server 管理面板从一页很长的设置表单整理成更易浏览的工作区，并补全了容易误操作或令人困惑的反馈。管理员可以更快定位用户、AI、标签和书籍操作；登录被限流时，读者也能明确知道何时可以再试。

### 管理体验

- **分区管理面板**：新增概览及“用户、AI 阅读、标签、书籍”分区导航。概览会显示各区当前数量，可直接跳转到待处理区域，避免在长页面中来回滚动。
- **更清晰的 AI 设置**：连接与模型、执行限制、成员默认值和凭据分别分组；界面会明确提示 AI 是未启用、已配置，还是仍需要 API Key。
- **更安全的日常操作**：创建或保存期间按钮会显示进行中并防止重复提交；关闭含未保存变更的管理面板会先确认。清空缓存、删除标签、停用用户、修改角色和撤销会话都会说明影响后再执行。
- **可见的标签使用情况**：标签列表显示每个标签当前关联的有效书籍数，删除时会提示会移除该标签与这些书籍的关联。
- **更轻量的书籍筛选**：书籍管理在保留搜索、可见性和服务器标签筛选的同时，提供“一键清除筛选”，便于从筛选结果回到完整书库。

### 登录与升级

- **登录限流提示**：密码尝试触发限流时，登录页会显示剩余等待分钟数，并由 API 返回 `Retry-After`，而不是误报为用户名或密码错误。
- **无需重新转换 EPUB**：本次没有改变 Server EPUB 内容缓存 schema，也没有数据库 migration。部署镜像 `epub-browser:2.3.1` 并重启 Server 即可；SSG 输出仍不会包含账户或管理功能。

## English

v2.3.1 turns the long Server administration form into a clearer workspace and fills in feedback for actions that were easy to misread or accidentally repeat. Administrators can reach user, AI, tag, and book work faster; readers who are rate-limited at sign-in now know when they can try again.

### Administration experience

- **Sectioned administration**: An overview plus Users, AI reading, Tags, and Books navigation replaces the long single surface. The overview shows current counts and links directly to the area that needs attention.
- **Clearer AI settings**: Connection and model, execution limits, member defaults, and credentials are grouped separately. The interface explains whether AI is disabled, configured, or still needs an API key.
- **Safer routine actions**: Save and create controls show in-progress state and prevent duplicate submission; closing an administration panel with unsaved changes asks first. Cache clearing, tag deletion, user disabling, role changes, and session revocation explain their effect before proceeding.
- **Visible tag usage**: Each server tag now shows how many active books use it, and deletion warns that those associations will be removed.
- **Lighter book filtering**: Book management retains search, visibility, and server-tag filters while adding a one-click reset to return from a filtered result set to the complete library.

### Sign-in and upgrade

- **Rate-limit guidance at sign-in**: When password attempts trigger throttling, the login page displays the remaining wait in minutes and the API returns `Retry-After` instead of presenting the result as invalid credentials.
- **No EPUB reconversion required**: This release changes neither the Server EPUB content-cache schema nor the database schema. Deploy `epub-browser:2.3.1` and restart the Server; static output continues to exclude account and administration features.
