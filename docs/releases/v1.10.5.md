# EPUB Browser v1.10.5

发布日期 / Release date: 2026-08-12

## 中文

### 修复

- 服务器的统一 SQLite 数据库现在命名为 `epub-browser.db`，不再使用容易误解为“仅标注”的 `annotations.db`。
- 启动时若仅存在旧的 `annotations.db`，会以原子重命名方式自动迁移到 `epub-browser.db`；已有标注和书架记录完整保留。

## English

### Fixes

- The shared server SQLite database is now named `epub-browser.db`, replacing the misleading annotation-only name `annotations.db`.
- When only the old `annotations.db` exists, startup atomically renames it to `epub-browser.db`, preserving existing annotations and bookshelves.
