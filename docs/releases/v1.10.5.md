# EPUB Browser v1.10.5

发布日期 / Release date: 2026-08-12

## 中文

这是一个改进阅读进度保存可靠性的维护版本。

### 改进

- **跨章节阅读进度同步**：连续阅读时，当前章节和阅读位置会随阅读过程同步保存；切换章节及关闭或刷新页面前也会尝试保存最新位置。
- **避免旧请求覆盖新位置**：进度同步按顺序处理，并会忽略过期请求的失败结果，避免网络延迟或页面卸载期间的请求影响较新的阅读位置。
- **恢复阅读更准确**：重新打开书籍时，会优先恢复最近同步的章节及其阅读位置。

### 兼容性

阅读进度继续保存在浏览器本地，不改变现有书架或服务器同步接口。旧版本保存的书籍阅读位置仍可正常使用。

## English

This maintenance release improves the reliability of reading-progress persistence.

### Improvements

- **Cross-chapter progress synchronization**: While reading continuously, the active chapter and reading position are saved as progress changes. The latest position is also saved when changing chapters and before a page is closed or refreshed.
- **Protection against stale requests**: Progress updates are serialized, and failures from stale requests are ignored so network latency or unload-time requests cannot overwrite a newer position.
- **More accurate resume**: Reopening a book restores the most recently synchronized chapter and reading position when available.

### Compatibility

Reading progress remains stored locally in the browser. This release does not change the existing bookshelf or server-sync interfaces, and positions saved by earlier versions continue to work.
