# EPUB Browser v2.3.8 — Deeper AI reading and a cleaner reader

发布日期 / Release date: 2026-08-25

## 中文

v2.3.8 完善了章节 AI 阅读和阅读器的日常使用体验：AI 现在通过多阶段任务生成更可靠的章节学习层，并把费曼式讲解、词语与生僻字解释放在更合适的阅读位置；图片型书籍也可以留下笔记。

### 新功能与改进

- **多阶段章节 AI 阅读**：一次章节 AI 阅读在后台分阶段完成核心理解与原文定位，仍作为一次面向读者的结果呈现。章首导读保持简短，费曼式通俗讲解移到章末，避免重复摘要。
- **词语与生僻字解释**：AI 会识别值得解释的词语、固定表达、成语、俗语及各书写系统中的罕见单字／字位；在确定且有帮助时会附上读音、语境含义和简短例句。
- **图片笔记**：无法划线的图片书籍现在可以直接创建“图片笔记”。标注汇总显示缩略图，点击可回到图片所在章节并打开该笔记。
- **阅读器控制与换章清理**：阅读设置增加可单独关闭的左右键和空格键导航；编辑注释时不会触发翻章。普通滚动模式切换章节会关闭瞬态标注界面，并清除上一章的标注、AI 结果和无关 hash 参数。
- **更清晰的管理与导航**：AI 阅读管理拆分为 AI 配置、AI 权限和 AI 任务标签；书籍管理与 AI 任务表格去除嵌套滚动。Server 动态书籍页的导航补齐语言、账户及按权限显示的管理入口。
- **五语界面与文档**：界面新增繁體中文、한국어和日本語；README 同步提供三份本地化部署指南，并可在五种语言版本间切换。
- **视觉修正**：AI 内容继续统一使用魔杖标识，而“重新生成”使用刷新图标；自定义阅读字体不再覆盖 Font Awesome 图标字体。

### 升级说明

- 无需 SQLite migration、无需重新转换 EPUB，也无需提高 Server EPUB 内容缓存修订。
- 要获得费曼讲解和新的词语／生僻字说明，请重新生成既有章节的 AI 阅读结果；旧结果继续可用。
- 图片笔记、AI 阅读、账户和权限能力均为 Server 专属；SSG 输出仍保持静态，不包含这些 API 或运行时数据。

## English

v2.3.8 refines chapter AI reading and everyday reader behavior. AI now builds a more dependable chapter learning layer through staged background work, puts the Feynman-style explanation and vocabulary guidance where they belong in the reading flow, and lets image-only books receive notes too.

### Features and improvements

- **Multi-stage chapter AI reading**: A single reader-facing chapter result is generated through background stages for core understanding and source grounding. The opening guide stays concise, while the plain-language Feynman explanation moves to the end of the chapter instead of repeating the summary.
- **Vocabulary and rare-character guidance**: AI can explain useful words, fixed expressions, idioms, proverbs, and uncommon individual characters or graphemes across writing systems. When helpful and certain, it includes pronunciation, in-context meaning, and a short example.
- **Image notes**: Image-only books can now receive a direct image note without drawing a selection. The annotation hub shows a thumbnail and opens the note in its source chapter.
- **Reader controls and chapter cleanup**: Reader settings can independently disable arrow-key and Space navigation; typing in an annotation never changes chapters. Normal-scroll chapter changes close transient annotation UI and discard the previous chapter's annotation, AI-result, and unrelated hash state.
- **Clearer administration and navigation**: AI administration is split into AI Configuration, AI Permissions, and AI Jobs tabs. Book-management and AI-job tables no longer use nested scrolling. Dynamic Server book pages now include language, account, and permission-aware administration navigation.
- **Five interface and documentation languages**: Traditional Chinese, Korean, and Japanese join the interface. README now provides localized deployment guides for all three and links all five language versions together.
- **Visual corrections**: AI content consistently uses the magic-wand marker while regeneration uses a refresh icon. Reader font choices no longer replace the Font Awesome icon font.

### Upgrade notes

- No SQLite migration, EPUB reconversion, or Server EPUB-content-cache revision is required.
- Regenerate an existing chapter AI result to receive the Feynman explanation and the new vocabulary/rare-character guidance; existing results remain available.
- Image notes, AI reading, accounts, and permissions remain Server-only. SSG output stays static and contains none of their APIs or runtime data.
