# EPUB Browser v2.9.4 — 统一 EPUB 解析管线、精简依赖与 Server 优化

发布日期 / Release date: 2026-08-31

## 中文

v2.9.4 把所有 EPUB 文档解析收敛到统一的 lxml 管线（严格优先、失败才恢复、最后回退到 HTML 解析器），畸形输入从此在单一位置被一致、安全地处理，外部实体与 DTD 始终被禁用。同时移除了实测零收益的 HTML 压缩依赖，输出回归标准 HTML；词典数据库不再写入发布缓存目录；Server 的章节快照与会话刷新完成一轮性能优化；翻页分页布局与移动端跳页、章节按钮位置也做了微调。

### 修复与改进

- **统一 EPUB 解析管线**：container、OPF、NCX、导航与章节 XHTML/SVG 全部经 `epub_browser/epub_parsing.py` 解析。策略为严格优先——先以关闭恢复的模式解析，只有明确失败才启用恢复；仍无法按 XML 解析的 XHTML 回退到 `lxml.html`，以兼容 EPUB 2 遗留内容。任何解析路径都不允许加载外部实体或 DTD，未在 HTML5 实体集内的声明实体一律丢弃，并对 manifest ID 与 spine 引用执行结构校验。过去不同文档因解析器差异产生不同行为的问题不复存在，非法文档在转换前即被拦截或一致降级。
- **移除 minify_html 依赖**：书库页与书籍页的 HTML 压缩实测没有任何收益（CSS/JS 压缩本就因 Kindle 兼容性被关闭），压缩行为还被发现会重排属性顺序、规范化文本实体。现在输出为标准 HTML——带引号的属性、保留模板属性顺序与完整实体。依赖列表少一个带 Rust 扩展的编译轮，Python 3.9+ 安装不再有 sdist 回退构建的风险。
- **词典数据库自动迁移**：早期版本把词典数据库写在发布缓存 `cache/public/data` 之下。升级后会自动迁移到 Server 数据目录（用户运行时数据不应混入静态发布树），并清理遗留的 staging 条目与空的旧目录。
- **更轻的章节快照**：`authorized_chapter_snapshot` 直接从内容缓存的 `metadata.json` 取章节标题，不再为目录快照做完整页面渲染或整章读取，也避免把快照构建放在 ASGI 事件循环上。
- **会话刷新去抖**：滑动过期只在越过刷新窗口后才更新 SQLite，避免单个页面加载几十个资产请求时反复提交写事务、互相串行化。
- **翻页与移动端微调**：分页模式在桌面与移动端的布局更均衡；移动端"跳页"按钮与"书籍/章节"按钮位置调整，减少误触。

### 影响范围

- **受影响版本**：截至 v2.9.3 的部署。
- **部署与格式范围**：统一解析、词典迁移、章节快照与会话刷新仅影响 Server（EPUB）；移除 HTML 压缩同时影响 SSG 与 Server 的输出；翻页布局与移动端控制调整适用于 SSG 与 Server，并覆盖 EPUB/PDF 支持的对应阅读模式。AI 阅读仍仅适用于 EPUB。
- **触发条件**：转换含畸形 XML 的 EPUB；使用旧版词典数据库；高并发资产加载下的会话滑动刷新。

### 升级说明

- **需要重新转换已有 EPUB 书籍**：v2.9.4 将 EPUB 内容缓存 revision 提升至 `server-content-v10`（统一解析改变了清洗输出语义）。Server 升级后，转换缓存校验会自动触发重建；PDF 内容缓存 revision 不变，无需重新处理 PDF。
- **不新增 SQLite migration**：词典数据库会在升级后首次访问时自动迁移到数据目录。
- **依赖精简**：`minify_html` 已从安装依赖移除，重新安装镜像或环境时无需该包；`lxml` 为新依赖，会在安装时一并解析。

## English

v2.9.4 routes every EPUB document through one unified lxml pipeline (strict-first, recovery on failure, with an HTML-parser fallback for legacy content), so malformed input is now handled consistently and safely in a single place, and no parser can ever load external entities or DTDs. It also removes the HTML minifier, which measured zero benefit, restoring standard HTML output; moves dictionary databases out of the published cache tree; tunes Server chapter snapshots and session refreshes; and adjusts paginated layout and mobile page-turning controls.

### Fixes and improvements

- **Unified EPUB parsing pipeline**: container, OPF, NCX, navigation, and chapter XHTML/SVG are all parsed through `epub_browser/epub_parsing.py`. The policy is strict-first — a document is parsed with recovery disabled, and only an outright failure retries with recovery enabled. XHTML that still cannot be parsed as XML falls back to `lxml.html` to support legacy EPUB 2 content. Every path forbids loading external entities or DTDs, drops undeclared entities outside the HTML5 set, and validates manifest IDs and spine references. Documents no longer behave differently depending on which parser happened to handle them; malformed files are rejected or degrade consistently before conversion.
- **minify_html dependency removed**: HTML minification of the library and book pages measured zero benefit (CSS/JS minification was already disabled for Kindle compatibility), and the minifier was observed reordering attributes and normalising text entities. Output is now standard HTML — quoted attributes, template attribute order, and complete entities preserved. The dependency list drops a Rust-extension build step, so Python 3.9+ installs no longer risk sdist fallback builds.
- **Dictionary databases migrate automatically**: Earlier builds stored dictionary databases under the published cache `cache/public/data`. Upgrades now move them into the Server data directory (runtime user data should not live in the static publish tree) and clean up leftover staging entries and the now-empty legacy tree.
- **Lighter chapter snapshots**: `authorized_chapter_snapshot` takes the chapter title straight from the content cache's `metadata.json`, avoiding a full render or chapter read for TOC snapshots and keeping snapshot work off the ASGI event loop.
- **Debounced session refreshes**: Sliding expiry updates SQLite only after the refresh window elapses, so page loads with dozens of asset requests stop hammering write transactions.
- **Page-turning and mobile tuning**: Paginated layout is better balanced across desktop and mobile; the mobile Page Jump and Book/Chapter buttons move to reduce accidental taps.

### Affected scope

- **Affected versions**: Server deployments through v2.9.3.
- **Deployment and format scope**: Unified parsing, dictionary migration, chapter snapshots, and session refreshes are Server-only (EPUB). HTML-minification removal affects both SSG and Server output. Pagination layout and mobile control adjustments apply to both SSG and Server and to the corresponding EPUB/PDF reading modes. AI reading remains EPUB-only.
- **Trigger**: Converting an EPUB with malformed XML; using a legacy dictionary database; sliding session refreshes under concurrent asset loads.

### Upgrade notes

- **Existing EPUB books need reconversion**: v2.9.4 raises the EPUB content-cache revision to `server-content-v10` because unified parsing changes sanitisation semantics. After upgrading the Server, the conversion-cache check rebuilds existing books automatically; the PDF content-cache revision is unchanged, so PDFs need no reprocessing.
- **No new SQLite migration**: Dictionary databases are migrated to the data directory automatically on first access after upgrade.
- **Leaner dependencies**: `minify_html` is removed from install requirements — fresh images or environments do not need it; `lxml` is a new dependency resolved at install time.
