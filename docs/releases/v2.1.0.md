# EPUB Browser v2.1.0

发布日期 / Release date: 2026-08-21

## 中文

v2.1.0 为 Server 模式加入完整账户与访问控制体系，并统一改造 Library、书籍详情、章节阅读、账户设置和管理后台的界面。SSG 继续保持无账户、自包含的纯静态模式。

### Server 账户体系

- **首次管理员设置**：全新 Server 会在首次访问时引导创建管理员。设置完成前不扫描或暴露书库；也支持通过 CLI、环境变量和只读密码文件无人值守初始化。
- **本地账户与会话**：新增管理员/成员角色、Argon2id 密码、HttpOnly 会话 Cookie、CSRF 防护、30 天滑动会话、改密与会话撤销。
- **独立账户数据**：Server 书架、阅读进度和标注固定保存在已登录用户的 SQLite 数据中，不再让用户选择本地存储；SSG 则固定使用浏览器本地存储。
- **书籍访问控制**：管理员可将书籍设为普通或受限，并为受限书籍多选授权用户。书籍目录、详情、章节、封面、资源、进度和标注 API 都执行同一访问判断。
- **可信代理身份**：可在明确的直接代理 CIDR 内接收稳定外部 subject，并关联到本地账户。OIDC 由前置认证代理完成；本地管理员密码始终保留为恢复入口。
- **管理后台分离**：个人账户设置与管理员后台拆分。成员看不到管理模块；管理员可管理用户、角色、密码、会话、外部身份和书籍授权。

### 阅读与界面

- **统一导航**：Library、书籍详情和章节页使用一致导航模型，移除多余面包屑和重复首页按钮，避免 JavaScript 后插入控件造成闪现。
- **现代阅读器**：章节、全书目录和设置统一为玻璃模糊右侧抽屉；小屏使用底部操作栏，不再同时显示侧边栏。
- **阅读体验**：新增阅读宽度档位，连续滚动时禁用无意义的本章目录，并重新设计分页/非连续阅读的底部操作区。
- **响应式行为**：系统性调整媒体查询、回到顶部显示条件、移动端导航和抽屉布局；页面加载时在内容遮罩内应用字体与宽度，减少尺寸抖动。
- **统一视觉语言**：登录、首次设置、账户、后台、空书库、错误提示和成功消息对齐现有设计系统、主题及中英文界面；通知使用标准组件。
- **EPUB 原始排版**：恢复书籍详情与章节内容携带的安全原书样式，同时保留阅读器主题和用户自定义 CSS 的覆盖能力。

### 安全与缓存边界

- 对 Server 中的 EPUB HTML、SVG、元数据和复制资源进行主动内容净化，并为阅读页面应用 CSP，防止恶意书籍在认证同源执行脚本。
- 受保护页面、API、资源和事件流统一应用私有缓存策略；Server 禁用并清退源范围 Service Worker，避免跨账户复用缓存。
- 标注、进度和批量写入同时验证目标书籍及既有记录的所有权与访问权限，撤权后不能通过旧 ID 更新受限数据。
- 启动会验证账户密码哈希结构并对损坏状态失败关闭；会话替换使用原子事务，失败时不会留下部分登录状态。

### Docker、命令行与文档

- Docker 默认启用 `--watch`、`--no-browser` 和 `--book-id-storage embedded`；`/app/Library` 应以读写方式挂载，以便把稳定 ID 写入 EPUB。
- `--no-browser` 现在在 README 中有明确说明：它只阻止服务器在本机打开默认浏览器，不会关闭 Web 界面。
- README 已完整重写，并新增等量维护的 [中文 README](../readme/README.zh-CN.md)，覆盖 SSG、Server、账户、OIDC 代理、Docker、全部公开 CLI 参数、数据位置、迁移与排障。
- 阅读所需 JavaScript、CSS、字体、图标和 EPUB 资源均包含在部署中，不依赖 CDN。页脚版本检查是可选 GitHub API 请求，失败不影响阅读。

### 升级说明与不兼容变化

1. **Server 现在必须登录。** 现有持久化数据会自动迁移，并在首次管理员创建后归属该管理员。升级前请备份源 EPUB 和 `<server-dir>/data`，并保留同一个状态目录或 Docker volume。
2. **Docker 默认把书籍 ID 嵌入 EPUB。** 请把 `/app/Library` 以读写方式挂载。已有有效 sidecar 的相同 ID 会被嵌入，sidecar 不会删除。需要 sidecar 时可覆盖镜像命令并显式选择 `--book-id-storage sidecar`。
3. **SSG 没有账户或云端 Sync。** 书架只提供本地导入/导出，进度和标注只存在当前浏览器源中。
4. **OIDC 部署需要显式可信代理配置。** 必须配置直接代理 CIDR、不可变 subject 头、稳定 issuer，并在 HTTPS 代理后启用 `--cookie-secure`。不要信任公网客户端传入的转发头。
5. 数据库、旧书架 JSON、公开缓存和生成内容的迁移可安全重启并带有备份检查点。损坏或含义不明的状态会停止启动，不会被猜测覆盖。

## English

v2.1.0 adds a complete account and access-control system to Server mode and refreshes the Library, book detail, chapter reader, account settings, and administration interfaces. SSG remains an account-free, self-contained static mode.

### Server accounts

- **First-run administrator setup**: A fresh Server prompts the first visitor to create the administrator. The library is neither scanned nor exposed before setup. CLI, environment, and read-only password-file bootstrap are available for unattended deployments.
- **Local accounts and sessions**: Administrator/member roles, Argon2id passwords, HttpOnly session cookies, CSRF protection, 30-day sliding sessions, password changes, and session revocation are included.
- **Account-owned reading data**: Server bookshelf, progress, and annotations are always stored in the authenticated user's SQLite data. SSG always uses browser-local storage; neither mode exposes a misleading storage selector.
- **Book access control**: Administrators can mark books ordinary or restricted and grant restricted books to multiple selected users. Catalogs, detail pages, chapters, covers, resources, progress, and annotation APIs enforce the same decision.
- **Trusted proxy identity**: A stable external subject can be accepted only from configured direct-proxy CIDRs and linked to a local account. An upstream authentication proxy performs OIDC; local administrator/password login remains the recovery path.
- **Separate administration**: Personal Account settings and the administration console are separate. Members do not see administrative modules; administrators manage users, roles, passwords, sessions, external identities, and book grants.

### Reader and interface

- **Unified navigation**: Library, book detail, and chapter pages share one navigation model. Redundant breadcrumbs and duplicate Home entries are removed, and controls are present in initial HTML instead of flashing in after JavaScript loads.
- **Modern reader surfaces**: Chapter navigation, book contents, and settings use consistent glass-blurred right-side drawers. Small screens use the bottom action bar without a duplicate side rail.
- **Reading controls**: New reading-width presets, a disabled in-chapter outline during continuous scrolling, and redesigned paged/non-continuous footer controls improve flow.
- **Responsive behavior**: Media queries, Back to top visibility, mobile navigation, and drawer layout were reviewed together. Font and width preferences are applied behind the content mask to reduce load-time resizing.
- **Consistent visual language**: Login, first-run setup, Account, Admin, empty library, errors, success messages, themes, and English/Chinese interfaces now share the application design system and standardized notifications.
- **EPUB presentation**: Safe source-book styling is restored on book details and chapter content while reader themes and custom CSS can still override it.

### Security and cache boundaries

- Server sanitizes EPUB HTML, SVG, metadata, and copied resources and applies reader CSP so hostile books cannot execute script in the authenticated origin.
- Protected pages, APIs, resources, and event streams use private cache policy. Server disables and retires the origin-wide Service Worker to prevent cached protected content crossing accounts.
- Annotation, progress, and batch writes validate both requested books and existing-record ownership/access, including after a grant is revoked.
- Startup validates encoded password-hash structure and fails closed on corruption. Session replacement is transactional and cannot leave a partial login state.

### Docker, CLI, and documentation

- Docker defaults include `--watch`, `--no-browser`, and `--book-id-storage embedded`. Mount `/app/Library` read-write so stable IDs can be embedded in EPUB sources.
- `--no-browser` is now documented precisely: it prevents only the local default-browser launch and does not disable the web interface.
- The README has been rewritten and a fully equivalent [Chinese README](../readme/README.zh-CN.md) added, covering SSG, Server, accounts, OIDC proxying, Docker, every public CLI option, data placement, migration, and troubleshooting.
- Required JavaScript, CSS, fonts, icons, and EPUB resources are deployed locally without CDN dependencies. The footer version check is an optional GitHub API request whose failure does not affect reading.

### Upgrade notes and breaking changes

1. **Server now requires authentication.** Existing persistent data migrates automatically and is assigned to the initial administrator after setup. Back up source EPUBs and `<server-dir>/data`, and retain the same state directory or Docker volume.
2. **Docker now embeds book IDs by default.** Mount `/app/Library` read-write. Matching IDs from valid sidecars are embedded without deleting those sidecars. Override the image command with `--book-id-storage sidecar` when sidecars are preferred.
3. **SSG has no account or cloud Sync.** Its bookshelf provides local Import/Export; progress and annotations stay in the current browser origin.
4. **OIDC deployments require explicit proxy trust.** Configure the direct proxy CIDR, immutable subject header, stable issuer, and `--cookie-secure` behind HTTPS. Never trust public-client forwarded headers.
5. Database, legacy bookshelf JSON, public-cache, and generated-output migrations are restart-safe and checkpointed with backups. Corrupt or ambiguous state stops startup instead of being guessed or overwritten.
