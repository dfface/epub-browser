# EPUB Browser v2.8.1 — 更稳的阅读器细节与 PDF 标注

发布日期 / Release date: 2026-08-29

## 中文

v2.8.1 聚焦日常阅读中的细节可靠性：桌面阅读舞台不再因目录而偏移，PDF 标注深链会等待文本层恢复完成再定位，AI 阅读标记也会准确跟随当前界面语言。项目首页同步补充了 AI 原生阅读和个人阅读洞察的直观介绍。

### 阅读体验

- **桌面目录不再挤压舞台**：章节侧栏改为悬浮在阅读器上方，打开后不会占用文档布局宽度或把舞台中心推向一侧；与 Ask AI 并排使用时也保持相同的居中规则。
- **PDF 设置更贴合文档特性**：PDF 设置面板不再显示无效的字号滑块，保留页面宽度、缩放和其他仍然适用的阅读控制。
- **从标注回到 PDF 更可靠**：从标注汇总打开 PDF 章节时，会等待对应页面的文本层和高亮恢复后再判断是否定位成功。高亮已经恢复时不再错误提示“无法定位”；只有恢复完成后仍找不到标注才会提示。

### 多语言与文档

- **AI 阅读标记按当前语言显示**：目录中的 AI readings 标记只会依据当前界面语言的结果出现；切换语言后会刷新标记和无障碍名称，避免中文结果错误标记英文阅读界面。
- **更清楚地介绍 AI 能力**：英文、简体中文及其余本地化 README 都加入 AI 原生阅读和私人阅读洞察的卖点与截图，方便读者快速了解可追溯的文本辅助和个人阅读回顾能力。

### 升级说明

- 不包含 SQLite migration，也不改变 EPUB 内容缓存或 `SERVER_OUTPUT_REVISION`；已有 EPUB 和 PDF 无需重新转换。
- Server 部署新版本并重启即可获得这些运行时界面更新。SSG 站点请使用新版本重新执行 `epub-browser ssg`，以写出更新后的页面与资源。

## English

v2.8.1 focuses on the small details that make everyday reading dependable: the desktop reading stage no longer shifts for the chapter drawer, PDF annotation deep links wait for the text layer before deciding whether they can focus an annotation, and AI-reading indicators now match the active interface language. The project home pages also give AI-native reading and private reading insights the visibility they deserve.

### Reading experience

- **A chapter drawer that does not move the stage**: The desktop chapter drawer now floats above the reader instead of consuming document width, so opening it keeps the reading stage centered—even alongside Ask AI.
- **PDF settings fit PDF documents**: PDF settings no longer show a font-size control that cannot affect a fixed-layout page. Page width, zoom, and the remaining relevant controls stay available.
- **Reliable PDF annotation deep links**: Opening a PDF chapter from the annotation hub now waits for that page’s text layer and restored highlights before determining success. A restored highlight no longer produces a false “could not locate” notice; readers see the notice only when the annotation is genuinely unavailable after restoration completes.

### Language and documentation

- **Language-aware AI-reading markers**: Table-of-contents markers now reflect results in the active UI language only. Changing language refreshes both markers and accessible labels, preventing Chinese results from marking an English reading view.
- **Clearer AI feature story**: The English, Simplified Chinese, and other localized READMEs now introduce AI-native reading and private reading insights with screenshots, making the evidence-grounded reading help and personal reading review easier to discover.

### Upgrade notes

- This release has no SQLite migration and does not change the EPUB content cache or `SERVER_OUTPUT_REVISION`; existing EPUBs and PDFs do not need reconversion.
- Deploy and restart Server mode to pick up the runtime UI updates. For SSG, rerun `epub-browser ssg` with this version to write the updated pages and assets.
