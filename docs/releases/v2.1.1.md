# EPUB Browser v2.1.1

发布日期 / Release date: 2026-08-21

## 中文

v2.1.1 是一次兼容性与体验修复版本，改善 Server 健康检查、部分 EPUB 的处理与导航，以及标注和书架搜索体验。

### 改进

- **书架拼音搜索**：在“添加书籍”面板中，可使用书名或作者的拼音搜索中文书籍；书名、作者和标签的原有直接搜索保持不变。

### 修复

- **Server 健康检查**：完成首次设置后，`/api/health` 和 `/api/ready` 仍允许探针匿名访问，便于 Docker、Doco-CD 等 GitOps 环境正确判断实例状态，避免健康检查因登录重定向而触发容器重启。
- **EPUB 路径兼容**：章节中的根相对网页链接不再被误判为 EPUB 压缩包内部路径，修复部分书籍写入 `book_id` 时出现 `Unsafe EPUB internal path` 的问题；资源和 manifest 路径仍保留严格的目录穿越检查。
- **标注颜色**：恢复标注面板中每条标注的颜色标识，并覆盖真实浏览器布局回归测试。

### 兼容性

- 不需要数据库迁移，也没有配置或命令行破坏性变更。
- Server 与 SSG 的既有书架、进度、标注和 EPUB 数据保持兼容。
- 保留现有 `/book-metadata.json` 兼容行为。

## English

v2.1.1 is a compatibility and experience maintenance release for Server health checks, EPUB processing and navigation, annotation colors, and bookshelf search.

### Improvements

- **Pinyin bookshelf search**: The Add books panel now finds Chinese titles and authors by pinyin. Existing direct matching for titles, authors, and tags is unchanged.

### Fixes

- **Server health checks**: `/api/health` and `/api/ready` remain anonymously accessible after first-run setup, allowing Docker and GitOps systems such as Doco-CD to evaluate instance health without a login redirect and avoiding probe-driven restart loops.
- **EPUB path compatibility**: Root-relative web links in chapters are no longer interpreted as EPUB archive paths, fixing `Unsafe EPUB internal path` failures when embedding a `book_id` in affected books. Strict traversal checks remain in place for resources and manifest paths.
- **Annotation colors**: Annotation color indicators are visible again, with real-browser layout regression coverage.

### Compatibility

- No database migration or breaking configuration/CLI change is required.
- Existing Server and SSG bookshelf, progress, annotation, and EPUB data remain compatible.
- Existing `/book-metadata.json` compatibility behavior is unchanged.
