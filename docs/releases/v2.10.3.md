## 修复

- 在「始终固定」和「向下隐藏、向上显示」导航模式下，选择主题或语言、关闭菜单时，焦点会回到原按钮，正文保持在原来的阅读位置。
- 关闭标注中心、书架、阅读统计和 AI 阅读中心时，同样保留阅读位置。

### 影响范围

EPUB 与 PDF 的共享导航。阅读统计和 AI 阅读中心仅在 Server 模式提供。

### 升级说明

Server 部署新版本后即可使用，无需重新转换书籍。SSG 站点需要重新生成并发布静态输出。

## Fixes

- With either sticky or auto-hide navigation, choosing a theme or language or dismissing its menu now returns focus to the original button without moving the reading position.
- Closing the annotation center, bookshelf, reading insights, or AI reading center also preserves the reading position.

### Affected scope

Shared EPUB and PDF navigation. Reading insights and the AI reading center are available in Server mode.

### Upgrade notes

Deploy the new Server version to pick up the fix with existing book caches. Regenerate and republish SSG sites.
