# EPUB Browser v1.10.7

发布日期 / Release date: 2026-08-12

## 中文

这是一个修正静态部署阅读进度语义的维护版本。

### 修复

- **静态 Pages 不再误报云同步**：在 `--no-server` 构建以及其他纯静态托管环境中，Book 页只会高亮浏览器本地的继续阅读章节，不再显示 `Cloud sync` 标签。
- **云同步标签只代表真实服务器记录**：只有 server 模式成功返回已同步章节时，目录才显示 `Cloud sync · 用户名/shared`，避免本地缓存被误认为云端数据。

### 兼容性

静态站点的本地阅读位置和 Continue Reading 功能保持不变；无需迁移或额外配置。

## English

This maintenance release corrects reading-progress semantics in static deployments.

### Fixes

- **Static Pages no longer implies cloud synchronization**: In `--no-server` builds and other static hosts, the Book page now highlights the browser-local resume chapter without displaying a `Cloud sync` marker.
- **The cloud marker now represents an actual server record only**: The TOC shows `Cloud sync · username/shared` only after server mode successfully returns a synced chapter, so local cache is never mistaken for cloud data.

### Compatibility

Static sites retain their local reading position and Continue Reading behavior. No migration or additional configuration is required.
