# EPUB Browser v2.3.13 — 更稳定的 AI 阅读首次打开体验

发布日期 / Release date: 2026-08-25

## 中文

v2.3.13 进一步修复 AI 阅读功能首次按需加载时的显示时序，让本章总览、问问 AI 和目录阅读标记在慢网络或冷缓存下也能稳定出现。

### 修复

- **本章总览会在图表准备好后再打开**：点击后按钮会显示载入状态，等待 Mermaid 思维导图完成渲染和首次布局后才显示总览，避免首次打开时图表破碎、缩放异常或需要重复进入才能恢复。
- **Book 和 Chapter 的“问问 AI”首次打开更可靠**：对话框样式现在会先完成加载和绘制，按钮同时显示载入状态；不会再短暂以未样式内容出现在页面底部。
- **目录重新标记已生成 AI 阅读的章节**：Book 页目录和 Chapter 页章节目录会以轻量方式恢复 AI 阅读标记，无需先手动打开 AI 阅读汇总；标记样式也会避开旧浏览器缓存。

### 升级说明

- 无需 SQLite migration、无需重新转换 EPUB，也无需提高 Server EPUB 内容缓存修订。
- Server 部署更新并重启后即可生效；SSG 部署请重新生成并完整发布输出目录，以便新的哈希资源一同上线。

## English

v2.3.13 further fixes the first-use loading sequence for AI Reading so Chapter Overview, Ask AI, and reading markers remain reliable on slow connections and cold caches.

### Fixes

- **Chapter Overview opens only after its diagram is ready**: The button now shows a loading state and waits for the Mermaid mind map to render and receive its first layout before opening. This prevents a fragmented or incorrectly fitted first render that previously could require reopening the overview.
- **First use of Ask AI is more reliable on Book and Chapter pages**: The chat stylesheet now finishes loading and painting before the dialog opens, while the trigger shows a loading state. Unstyled dialog content no longer briefly appears at the bottom of the page.
- **AI-reading markers return to both chapter directories**: Book and Chapter tables of contents now restore markers for chapters with generated AI Reading without requiring the AI Reading hub to be opened first. Their styles also bypass stale browser caches.

### Upgrade notes

- No SQLite migration, EPUB reconversion, or Server EPUB-content-cache revision is required.
- Restart an updated Server deployment to apply the change. For SSG deployments, regenerate and publish the complete output directory so the new hashed assets are available together.
