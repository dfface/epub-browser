# EPUB Browser v2.3.15 — 更稳定的章节切换与翻页阅读

发布日期 / Release date: 2026-08-25

## 中文

v2.3.15 修复并完善了阅读器在连续滚动、普通阅读和翻页模式下的章节切换与翻页体验。

### 改进

- **章节切换更连贯**：目录、上一章和下一章现在都会通过 AJAX 在阅读器内更新内容，连续滚动也能在跳转较远章节时重建合适的阅读窗口。
- **翻页模式更准确**：翻页画布不再继承滚动阅读的卡片间距和圆角；目录跳转、键盘翻页与章节边界切换都会对齐到正确页面。
- **移动端翻页更干净**：移动端仅保留底部专属控制栏，不再显示桌面翻页工具栏；阅读画布会锁定在可用视口内，避免页面整体滚动。

### 修复

- 修复了深页翻页时列宽取整与布局稳定时机不一致，导致右侧露出相邻页面内容的问题。
- 修复了翻页模式中目录抽屉与加载遮罩的层级关系，以及从章节末页/首页跨章时未使用 AJAX 的问题。

### 升级说明

- 无需 SQLite migration、无需重新转换 EPUB，也无需提高 Server EPUB 内容缓存修订。
- Server 部署更新并重启后即可生效；SSG 部署请重新生成并完整发布输出目录，以便新的哈希资源一同上线。

## English

v2.3.15 improves chapter transitions and page-turning reliability across continuous, standard, and pagination reading modes.

### Improvements

- **Seamless chapter changes**: The table of contents, previous chapter, and next chapter now update reader content with AJAX. Continuous reading also rebuilds an appropriate chapter window for distant jumps.
- **More accurate pagination**: The page-turning canvas no longer inherits scroll-reading card spacing or rounded corners. TOC jumps, keyboard navigation, and chapter-boundary transitions align to the intended page.
- **Cleaner mobile pagination**: Mobile keeps its dedicated bottom controls without the desktop pagination toolbar. The reading canvas remains within the available viewport, preventing document-level scrolling.

### Fixes

- Fixed a deep-page alignment issue where rounded column widths and late layout settling could reveal content from the adjacent page at the right edge.
- Fixed pagination drawer/loading-overlay stacking and chapter-boundary navigation that did not use AJAX.

### Upgrade notes

- No SQLite migration, EPUB reconversion, or Server EPUB-content-cache revision is required.
- Restart an updated Server deployment to apply the change. For SSG deployments, regenerate and publish the complete output directory so the new hashed assets are available together.
