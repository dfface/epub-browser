# EPUB Browser v1.11.3

发布日期 / Release date: 2026-08-18

## 中文

这是一个为阅读界面带来完整中英文体验、并增强浏览器端安全性与稳定性的功能版本。

### 新功能

- **中英文界面**：浏览器界面现支持 English 和简体中文。首次打开时会跟随浏览器语言，也可以从书库面包屑中的语言选择器切换；选择会跨页面和会话保存。
- **完整本地化覆盖**：书库、书架管理、书籍首页、阅读器设置与动态状态、标注编辑和标注中心均会随界面语言更新。EPUB 的书名、作者、目录和正文仍保持原始内容语言。
- **本地化 PWA 信息**：安装提示和 Web App Manifest 会根据所选界面语言提供对应的名称与说明。

### 改进与修复

- **更清晰的书库顶部信息**：书库面包屑重新梳理了书库身份、统计信息、语言和账户操作的层级；中文 footer 改为“由 epub-browser 强力驱动”。
- **稳定的 API 错误处理**：浏览器 API 错误现在提供稳定错误码并显示本地化提示；服务端 500 响应不再暴露内部异常文本。
- **更安全的元数据渲染**：书库和书架会将 EPUB 与导入数据中的书名、作者、标签和路径作为安全文本/属性渲染，避免恶意元数据被解释为 HTML。
- **阅读与标注可靠性**：清除阅读进度仅在服务器确认成功后才更新界面；标注 API 失败、恢复失败和标注跳转均提供准确的本地化反馈。

### 兼容性

- 不需要迁移。既有书库、书架、阅读进度和标注数据保持兼容。
- 不支持的语言会安全回退到英文；浏览器拒绝 `localStorage` 时会使用缓存、Cookie 和页面内存后备保存语言选择。

## English

This feature release delivers a complete bilingual browser experience and strengthens client-side safety and reliability.

### New Features

- **English and Simplified Chinese UI**: The browser interface now supports English and Simplified Chinese. It follows the browser language on first load, and the library breadcrumb provides a persistent language selector.
- **Complete localized surfaces**: The library, bookshelf management, book home, reader settings and dynamic states, annotation editor, and annotation center update with the UI language. EPUB titles, authors, table of contents, and body content retain their original language.
- **Localized PWA metadata**: Install prompts and Web App Manifests now use localized names and descriptions for the selected UI language.

### Improvements and Fixes

- **Clearer library header**: The library breadcrumb now separates the library identity, statistics, language, and account controls more clearly; the Chinese footer attribution is more natural.
- **Stable API errors**: Browser-facing API failures now expose stable error codes and localized feedback, while server 500 responses no longer reveal internal exception text.
- **Safer metadata rendering**: Library and bookshelf views render EPUB and imported titles, authors, tags, and paths as safe text or attributes rather than interpreting them as HTML.
- **More reliable reading and annotations**: Reading progress is cleared only after server confirmation; annotation API, restoration, and deep-link failures provide accurate localized feedback.

### Compatibility

- No migration is required. Existing library, bookshelf, reading-progress, and annotation data remain compatible.
- Unsupported locales safely fall back to English. If `localStorage` is unavailable, locale persistence falls back through cache, Cookie, and page memory.
