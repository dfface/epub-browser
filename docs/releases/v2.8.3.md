# EPUB Browser v2.8.3 — 刷新后可靠恢复 PDF 标注

发布日期 / Release date: 2026-08-29

## 中文

v2.8.3 修复了 PDF 阅读页刷新时的标注恢复误报。已有高亮现在会等待 PDF 文字层准备完成后再恢复，不会在高亮随后正常出现的情况下提前显示“部分标注无法恢复”。

### PDF 标注

- **刷新后不再误报恢复失败**：刷新含有标注的 PDF 页面时，阅读器会等待当前页面的文字层就绪，再恢复高亮并判断结果。
- **真实失败仍有明确反馈**：如果 PDF 文字层已经完成，而标注确实无法恢复，原有错误提示仍会显示，避免静默隐藏数据或定位问题。
- **EPUB 行为保持不变**：等待逻辑只适用于 PDF 页面，不改变 EPUB 章节的标注恢复与重试方式。

### 升级说明

- 不包含 SQLite migration，也不改变 EPUB/PDF 内容缓存结构或对应 revision；Server 中已有书籍无需重新转换。
- Server 部署新版本并重启即可获得修复。SSG 站点需要使用新版本重新执行 `epub-browser ssg`，以写出新的页面和静态资源。

## English

v2.8.3 fixes a false annotation-restoration error that could appear after refreshing a PDF reader chapter. Existing highlights now wait for the PDF text layer before restoration is judged, so a highlight that appears normally no longer arrives with a misleading failure notice.

### PDF annotations

- **No false restoration error after refresh**: When a PDF chapter with annotations is refreshed, the reader waits for that page's text layer before restoring highlights and deciding the outcome.
- **Genuine failures remain visible**: If the text layer is ready and an annotation still cannot be restored, the existing error notice remains available instead of silently hiding a data or positioning problem.
- **EPUB behavior is unchanged**: The waiting rule is limited to PDF pages and does not alter EPUB annotation restoration or retry behavior.

### Upgrade notes

- This release has no SQLite migration and does not change the EPUB or PDF content-cache schema or revisions; existing Server books do not need reconversion.
- Deploy and restart Server mode to pick up the fix. For SSG, rerun `epub-browser ssg` with this version to emit the updated pages and static assets.
