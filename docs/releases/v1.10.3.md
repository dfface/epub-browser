# EPUB Browser v1.10.3

发布日期 / Release date: 2026-08-12

## 中文

这是一个移动端阅读体验修复版本，让书库、Book 与 Chapter 页的导航在手机上更紧凑、更一致。

### 修复与改进

- **紧凑的移动端面包屑**：在整个移动端宽度范围内，面包屑不再保留上下或左右的外层空白，导航与页面边缘自然对齐。
- **统一的长标题处理**：Book 与 Chapter 页现在使用同一套单行截断规则；长书名或章节名不会换行挤压内容。
- **保留有用的书库信息**：首页的书库统计仍可按需换到第二行，兼顾紧凑布局与信息可读性。

### 升级提示

重新生成并完整部署站点目录即可生效。请确保 `assets/immutable/` 与 HTML 一同发布，避免新页面暂时引用到尚未上传的指纹资源。

## English

This patch release makes mobile navigation more compact and consistent across the library, book, and chapter pages.

### Fixes & improvements

- **Compact mobile breadcrumbs**: Breadcrumbs no longer retain outer top, bottom, or side spacing across the full mobile breakpoint, so navigation aligns naturally with the page edge.
- **Consistent handling for long titles**: Book and chapter pages now share one single-line truncation behavior, preventing long book or chapter names from wrapping and crowding the reader.
- **Library details remain useful**: Library statistics can still move to a second row when needed, preserving both compactness and readability.

### Upgrade note

Regenerate and deploy the complete site directory to apply the update. Publish `assets/immutable/` together with the HTML so a new page never briefly references a fingerprinted asset that has not yet been uploaded.
