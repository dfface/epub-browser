# EPUB Browser v1.10.3

发布日期 / Release date: 2026-08-12

## 中文

这是一个聚焦阅读续读与跨设备布局体验的改进版本，让书库、Book 与 Chapter 页在不同宽度下更紧凑、更一致。

### 新功能

- **继续阅读**：Book 页新增主操作按钮；有阅读记录时会直达上次阅读的章节与位置，没有记录时则从第一章开始。清除阅读进度后，按钮会立即切回“开始阅读”。

### 改进

- **紧凑的移动端面包屑**：在整个移动端宽度范围内，面包屑不再保留上下或左右的外层空白，导航与页面边缘自然对齐。
- **统一的长标题处理**：Book 与 Chapter 页现在使用同一套单行截断规则；长书名或章节名不会换行挤压内容。
- **保留有用的书库信息**：首页的书库统计仍可按需换到第二行，兼顾紧凑布局与信息可读性。
- **更协调的章节阅读列**：章节页的面包屑、正文与底部翻页导航现在共享同一宽度约束；面包屑与正文卡片之间也恢复为与 Book 页一致的呼吸空间。

### 修复

- **不再出现突兀的白色 Footer**：章节页底部现在融入当前主题背景，并通过细分隔线保持层次。

### 升级提示

重新生成并完整部署站点目录即可生效。请确保 `assets/immutable/` 与 HTML 一同发布，避免新页面暂时引用到尚未上传的指纹资源。

## English

This release improves both reading continuation and responsive layout consistency across the library, book, and chapter pages.

### New feature

- **Continue reading**: The Book page now has a primary reading action that returns you to your last chapter and position. Without saved progress, it starts from the first chapter; clearing progress immediately switches the action back to “Start reading”.

### Improvements

- **Compact mobile breadcrumbs**: Breadcrumbs no longer retain outer top, bottom, or side spacing across the full mobile breakpoint, so navigation aligns naturally with the page edge.
- **Consistent handling for long titles**: Book and chapter pages now share one single-line truncation behavior, preventing long book or chapter names from wrapping and crowding the reader.
- **Library details remain useful**: Library statistics can still move to a second row when needed, preserving both compactness and readability.
- **A more coherent chapter reading column**: Chapter breadcrumbs, reading content, and bottom navigation now share the same width constraint, with spacing between the breadcrumb and reading card aligned to the Book page.

### Fixes

- **No more abrupt white Footer**: The chapter footer now blends into the active theme and uses a subtle divider to retain visual structure.

### Upgrade note

Regenerate and deploy the complete site directory to apply the update. Publish `assets/immutable/` together with the HTML so a new page never briefly references a fingerprinted asset that has not yet been uploaded.
