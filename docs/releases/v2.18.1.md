# v2.18.1

## 新增

- 书籍页和章节阅读器的目录现在可以折叠（#84）。有子项的目录行前面会出现三角按钮，展开状态按书保存在浏览器里。跳到当前章节时会自动展开所在的分支，同一章在目录里出现多次时，会按链接锚点和层级选中更精确的那一条。
- 目录里的父级标题如果本身带跳转目标，现在仍然可以点击；纯分组标题（NCX 里没有目标的那种）也会显示出来，不再被丢掉（#84）。

## 修复

- 桌面上也能看到移动工具栏的设置项了，之前被 CSS 隐藏（#95）。
- 用键盘切换章节时，焦点框不再框住整个阅读区域（#96）。

## 影响范围

- 目录折叠和两个 CSS 修复都在共享页面模板里，SSG 和 Server 都生效；目录目标的解析变化只影响 EPUB。
- EPUB Server 缓存需要升到 `server-content-v13`，PDF 缓存修订没变。
- 没有新增服务端 API，也没有数据库迁移。

## 升级说明

- Server：部署重启后会自动重转 EPUB（v12 → v13），源 EPUB 要留在监控目录。重转期间相关章节可能短暂不可用。建议先备份 `data/`。
- SSG：重新生成并发布整站，静态输出里有新的 `toc-tree.css`、更新后的 `reader-layout.js` 和翻译文案。
- 浏览器里保存的目录展开状态不会丢。

## English

### Added

- Contents on the book page and in the chapter reader can now be collapsed (#84). Rows with children get a disclosure button, and the expanded state is saved per book in the browser. Jumping to the current chapter reveals its branch; when one chapter appears several times in the contents, the link anchor and depth pick the more precise match.
- A parent heading with its own target stays clickable, and group headings without a target (as found in NCX files) are kept in the contents instead of dropped (#84).

### Fixed

- Mobile toolbar settings are visible on desktop again; a CSS rule had hidden them (#95).
- Keyboard chapter navigation no longer draws a focus frame around the whole reading surface (#96).

### Affected scope

- The collapsible contents and both CSS fixes live in shared page templates, so they apply to SSG and Server. The TOC target changes affect EPUB only.
- The EPUB Server cache revision is now `server-content-v13`. The PDF cache revision is unchanged.
- No new server API and no database migration.

### Upgrade notes

- Server: EPUBs are reconverted automatically after restart (v12 → v13). Keep source EPUBs in the watched directory; chapters may be briefly unavailable during reconversion. Back up `data/` first.
- SSG: regenerate and republish the static site to pick up the new `toc-tree.css`, the updated `reader-layout.js` and translation bundles.
- Contents expanded states already saved in the browser are kept.
