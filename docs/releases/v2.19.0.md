# v2.19.0

## 新增

- 阅读时可以保存位置书签了（#97）。EPUB 记的是章节里的文字位置，PDF 记的是页码和页内相对位置，重新打开时会回到原处。书签可以命名、改名、删除，也能从列表直接跳转；位置找不到时会提示打开对应的章节或页，而不是静默失败。Server 把书签存在账户里，换设备也能用；SSG 只存在当前浏览器。Kindle 精简阅读器暂不支持，入口会给出说明。
- 连续滚动现在可以选加载方向（#97）：双向会同时自动加载上一章和下一章，仅向下只加载下一章，上滑只看已加载的内容。选择按浏览器保存，设置项只在连续滚动开启时出现。
- 通知位置可以按喜好调整（#97）：自动、上/下居中或四个角，窄屏一律居中，还可以先预览一条通知。设置按浏览器保存。

## 修复

- 初始化和登录页改用与客户端相同的语言包，17 种语言的页面文案和错误提示不再各维护一份。
- 目录折叠按钮在书籍页和阅读器里都居中了；桌面目录侧栏自动隐藏时，阅读区也保持居中。

## 影响范围

- 位置书签覆盖 EPUB 和 PDF；Server 部分包含 4 个需登录的 `/api/bookmarks/*` 接口和 SQLite `bookmarks` 表（schema 34 → 35），SSG 不发布 Server 专属的书签适配脚本。
- 连续滚动方向和通知位置都是共享页面上的浏览器本地偏好，SSG 与 Server 都生效。
- EPUB `content/` 与 PDF 缓存修订都没变，不需要重转书籍；没有 CLI 参数变化。

## 升级说明

- Server：部署重启后会自动创建 `bookmarks` 表并把 `user_version` 升到 35，无需手工 SQL。升级前建议备份 `data/`；回退到旧版本需要恢复升级前的数据库。
- SSG：重新生成并发布整站，静态输出里有新的 `bookmarks.js`、`bookmarks.css`、通知样式和翻译文案。SSG 上的书签只保存在当前浏览器。
- 浏览器里已有的阅读偏好不会丢；连续滚动仍会关闭滚动进度的保存与恢复。

## English

### Added

- Reading positions can be saved as bookmarks (#97). EPUB positions point to text inside a chapter; PDF positions store the page and a relative position on it, so reopening returns to the same place. Bookmarks can be named, renamed, deleted and opened from a list. If a saved position no longer resolves, the reader offers to open its chapter or page instead of failing silently. Server stores them per account across devices; SSG keeps them in the current browser. The Kindle reader does not support them yet and says so at the entry point.
- Continuous scrolling gains a loading direction (#97): both directions loads the previous and next chapters, while down only loads the next chapter and scrolling up shows already loaded content. The choice is saved per browser and the setting appears only when continuous scrolling is on.
- Notification placement can be set to automatic, top/bottom center or any corner, with a preview button (#97). Narrow screens always center notifications; the choice is saved per browser.

### Fixed

- Setup and login pages now use the same locale packs as the client, so page copy and error messages in all 17 languages no longer need a separate translation table.
- TOC disclosure buttons are centered on both the book page and reader, and the reading column stays centered when the desktop sidebar auto-hides.

### Affected scope

- Position bookmarks cover EPUB and PDF. The Server side adds four session-protected `/api/bookmarks/*` endpoints and a SQLite `bookmarks` table (schema 34 → 35); SSG does not publish the Server-only bookmark adapter.
- Continuous-scroll direction and notification placement are browser-local preferences on shared pages, active in both SSG and Server.
- Neither the EPUB `content/` nor the PDF cache revision changed, so no books need reconversion. No CLI flags changed.

### Upgrade notes

- Server: deploy and restart. The `bookmarks` table is created automatically and `user_version` advances to 35, with no manual SQL. Back up `data/` first; rolling back to an older release requires the pre-upgrade database.
- SSG: regenerate and republish the static site to pick up `bookmarks.js`, `bookmarks.css`, notification styles and the locale bundles. SSG bookmarks stay in the current browser.
- Existing reading preferences in the browser are kept; continuous scrolling still disables scroll-progress save and restore.
